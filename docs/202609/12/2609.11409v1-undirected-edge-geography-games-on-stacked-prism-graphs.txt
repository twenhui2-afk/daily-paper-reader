Abstract 

The undirected edge geography is a two-player combinatorial game on an undirected graph. The players start at the root vertex and alter-nately move the root along an incident edge to its other endpoint and then delete that edge. The first player who has no remaining move is the loser. For positive integers m and n where m ≥ 3, the stacked prism graph is SP (m, n ) = CmPn. In this paper, we completely determine the winner of the game on SP (2 m, n ) for m ≥ 2 and SP (m, 2) for m ≥ 3, and provide a winning strategy for the winner. 

Keywords: Combinatorial game, Undirected edge geography, Prism graph, Stacked prism graph, Winning strategy 

2020 Mathematics Subject Classification: 91A46, 05C57, 05C38 

# 1 Introduction 

The geography game was first introduced in [2] as a two-player game on a directed graph. It starts at a vertex v and players alternately move to another vertex along an arrow (a directed edge) and then delete the previously visited vertex. The first player who has no legal move is the loser. Later, the game is extended to an undirected graph and the previously visited edge is removed instead of a vertex. This version of the game is called the Undirected Edge Geography (UEG) [1]. In [3], the undirected edge geography game on a grid is considered. The winner at each root vertex is completely determined and a strategy for the winner is provided. In this work, we consider the game on the stacked prism 

graph SP (m, n ) := CmPn where m ≥ 3. The graph is considered as a grid

For a graph G with a starting vertex v, denoted by a game ( G, v ), we try to find its position , which determines which player has a winning strategy. A game (G, v ) is an N-position if the first player has a winning strategy. Otherwise, it is a P-position . The main tool that we use to determine the position of a game in this work is an even kernel .

Definition 1 ([1]) . An even kernel for a simple graph G is a nonempty set 

S ⊆ V (G) such that 1. S is independent and 2. for any vertex u /∈ S, the number of its neighbors in S is even, i.e., 

|N (u) ∩ S| is even. 

Theorem 2 ([1]) . If S is an even kernel for a simple graph G and v ∈ S,then (G, v ) is a P-position. Moreover, if G is a bipartite graph, then (G, v ) is a P-position if and only if v is in an even kernel for a graph G.

For the rooted undirected edge geography game on grid graphs, we have the following result. 

Theorem 3 ([3]) . Let δ = gcd( m + 1 , n + 1) and v = ( a, b ). Then (Gm×n, v ) is a P-position if and only if δ ∤ a and δ ∤ b.

In this paper, we consider the rooted undirected edge geography game on 

SP (2 m, n ) and SP (m, 2). We get the following main results. 2Theorem 4. For positive integers m, n where m ≥ 2, let G = SP (2 m, n ),

v = ( a, b ) ∈ V (G) and d = gcd(2 m, n + 1) . Then (G, v ) is a P-position if and only if d ∤ b.

Theorem 5. Let m ≥ 3. The game on SP (m, 2) is a P-position if and only if

# 2 Main results 

## 2.1 Games on stacked prism graphs 

We first give the condition for the P-positions. 

Theorem 6. For m ≥ 2 and n ≥ 1, let G = SP (2 m, n ), v = ( a, b ) ∈ V (G),

d′ = gcd( m, n + 1) , and d = gcd(2 m, n + 1) . Then (G, v ) is a P-position if d ∤ b

and d = d′.Proof. Let v = ( a, b ). Assume that d ∤ b and d = d′. Let 

S := {(i, j ) ∈ V (G) : d′ ∤ j and i ≡ ± j (mod 2 d′)}.

We will show that S is an even kernel for G.Extend the cylindrical grid to all integer rows, keeping the first coordinate modulo 2 m. Define the extension of S using symmetric difference as 

˜S = A+△A− where A± = {(i, j ) : i ≡ ± j (mod 2 d′)}.

These congruences are well defined because d′ | m. Since j ≡ − j (mod 2 d′)exactly when d′ | j, the restriction of ˜S to V (G) is precisely S. For any vertex of the extended grid, its neighbors in A+ occur in pairs: east with south, and west with north. Likewise, its neighbors in A− pair east with north, and west with south. Consequently, 

|N (u) ∩ ˜S| ≡ | N (u) ∩ A+| + |N (u) ∩ A−| ≡ 0 (mod 2) .

Moreover, ˜S contains no vertices in rows 0 and n+ 1, since d′ | n+ 1. Restricting to G therefore preserves these neighbor counts. Every vertex of S has i + j even, so S is independent. Finally, the hypotheses imply d′ ∤ b, hence d′ > 1 and (1 , 1) ∈ S. Thus S is a nonempty independent set with even neighbor counts, and hence an even kernel. Figure 2 shows an example of S for SP (12 , 8). If v ∈ S, then ( G, v ) is a P-position by Theorem 2. Otherwise, if v / ∈ S,there is a graph automorphism f such that f (a, b ) = ( a′, b ) ∈ S. Then f −1(S) is an even kernel of G containing ( a, b ). By Theorem 2, ( G, v ) is a P-position.

## 2.2 Games on prism graphs 

Since SP (2 m, n ) is a bipartite graph, by Theorem 2, we can ensure that there exists an even kernel for determining a position for this graph. However, for the case of SP (m, n ) where m is odd, the graph is not bipartite. So it might not be possible to find an even kernel even though it is a P-position, which makes it not easy to determine the position of the game. CmP2 for m ≥ 3. To simplify the proof, we draw a graph SP (m, 2) and label vertices as shown in Figure 7. Since the graph is vertex-transitive, we can consider only the game that starts at Vertex 1.
