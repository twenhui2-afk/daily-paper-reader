POWER QUASINORMAL OPERATORS AND THE ROOT PROBLEM 

JING-BIN ZHOU AND SHIHAI YANG 

Abstract. In this paper, we construct an n-power quasinormal operator T such that T n is not quasinormal for some positive integer n, thereby providing a counterexample to [14, Lemma 3.1]. We then investigate the relationships among the n-power quasinormality of T , the normality of 

T n, and the quasinormality of T n, and show that these three conditions are equivalent in finite-dimensional spaces. We also provide a new proof that n-power quasinormal operators have the single-valued extension property [14, Theorem 3.2]; unlike the original proof, our argument does not rely on [14, Lemma 3.1] and thus closes the gap in the original argument. In addition, for a fixed operator T , we characterize all positive integers n for which T is n-power quasinormal. As consequences, several results of Sid Ahmed [20] are extended. Finally, we prove that every paranormal n-power quasinormal operator is quasinormal. Closely related to this, we also give an affirmative answer to the root problem of Stanković and Kubrusly [22, Question 2.11]. 

1. Introduction 

Let B(H) denote the algebra of all bounded linear operators on a complex Hilbert space 

(H, 〈· , ·〉 ). We denote the adjoint, norm, null space, and range of T ∈ B(H) by T ∗, ‖T ‖, ker T

and ran T , respectively. For any T, S ∈ B(H), we write [S, T ] = ST − T S for the commutator. An operator T is called normal if [T, T ∗] = 0 . Largely owing to the development of the Spec-tral Theorem, normal operators have been studied extensively and systematically, and various generalizations of normal operators have become one of the main directions in operator theory. Specifically, Brown [3] called an operator T quasinormal if [T, T ∗T ] = 0 . A closed subspace M

of H is said to be invariant under T if T M ⊆ M . If both M and its orthogonal complement 

M ⊥ are invariant under T , then M is called a reducing subspace for T . Halmos [11] called T

subnormal if T ∈ B(H) is the restriction of a normal operator N on some Hilbert space K ⊇ H to an invariant subspace H, i.e., N |H = T . If S, T ∈ B(H) and 〈(S − T )x, x 〉 ≥ 0 for all x ∈ H , we write S ≥ T . Halmos [11] called T hyponormal if T T ∗ ≤ T ∗T . If T ≥ 0, then T is called positive .The square root of the positive operator T ∗T is denoted by |T |. Furuta, Ito and Yamazaki [10] called T of class A if |T |2 ≤ | T 2|. Istrăţescu [12] called T paranormal if ‖T x ‖2 ≤ ‖ T 2x‖‖ x‖ for all x ∈ H . It is well known that these generalized normal operators satisfy the following strict inclusions: normal ⊊ quasinormal ⊊ subnormal ⊊ hyponormal ⊊ class A ⊊ paranormal . (1.1) Besides the above generalized normal operators, n-power quasinormal operators also form a generalization of normal operators, and this is the main object of study in this paper. Let N

denote the set of positive integers. Sid Ahmed [20] called an operator T n -power quasinormal 

if [T n, T ∗T ] = 0 for some n ∈ N. A closely related class is that of n-power normal operators, introduced by Jibril [13]: an operator T is called n-power normal if [T n, T ∗] = 0 for some 

n ∈ N. Jibril proved that T is n-power normal if and only if T n is normal [13, Proposition 2.1]. Furtado and Johnson [9, Theorem 5.2] gave the structure of n-power normal matrices in finite-dimensional spaces.

Recently, in the theory of generalized normal operators, the following problem has attracted renewed attention. Let A be a class of operators and B a subclass of A . For n ∈ N, if T ∈ A

and T n ∈ B, does it follow that T ∈ B? This problem is known as the n-th root problem (for the class B) [22]. In this direction, Stampfi first proved the following result. 

Theorem 1.1. [21, Theorem 5] If T is hyponormal and T n is normal for some n ∈ N, then T

is normal. 

Subsequently, Ando extended this result. 

Theorem 1.2. [2, Theorem 6] If T is paranormal and T n is normal for some n ∈ N, then T is normal. 

Curto et al. recently initiated the study of the n-th root problem for quasinormal operators. 

Theorem 1.3. [6, Theorem 2.3] If T is a left-invertible subnormal operator and T 2 is quasi-normal, then T is quasinormal. 

Pietrzycki and Stochel removed the left invertibility assumption in the above result and ob-tained a more general version. 

Theorem 1.4. [18, Theorem 1.2] If T is subnormal and T n is quasinormal for some n ∈ N,then T is quasinormal. 

Later, the same authors extended the above result and established the following. 

Theorem 1.5. [19, Theorem 1.2] If T is of class A and T n is quasinormal for some n ∈ N,then T is quasinormal. 

Motivated by (1.1) and the preceding results, Stanković and Kubrusly naturally raised the following question in [22, Question 2.11]. 

Question 1.6. If T is paranormal and T n is quasinormal for some n ∈ N, does it follow that T

is quasinormal? We also pose the following question. 

Question 1.7. If T is n-power quasinormal and T n is quasinormal for some n ∈ N, does it follow that T is quasinormal? Note that Ko and Lee recently used the following result in their proof of the single-valued extension property for n-power quasinormal operators on Hilbert spaces of arbitrary dimension. 

Theorem 1.8. [14, Lemma 3.1] If T ∈ B(H) is n-power quasinormal, then T n is quasinormal. Conversely, if T n is quasinormal and ker( T ∗)n ⊆ ker T n, then T is n-power quasinormal. 

In view of this theorem, the condition T n is quasinormal in Question 1.7 appears to be superfluous. In fact, however, we give an example of an n-power quasinormal operator T in infinite dimensions for which T n is not quasinormal (Example 2.1). This motivates us to study the relationship between an n-power quasinormal operator T and the quasinormal operator T n.In particular, in Theorem 2.10 we prove that, in finite dimensions, the following are equivalent: 

T is n-power quasinormal; T n is quasinormal; T n is normal; T is n-power normal. It is also well known that quasinormal matrices and normal matrices coincide in finite dimensions. Therefore, by taking a non-normal nilpotent matrix, we obtain a negative answer to Question 1.7. From the finite-dimensional perspective, another natural question arises by replacing “ T n is quasinormal” in Question 1.6 with “ T is n-power quasinormal”, leading to the following question. 

Question 1.9. If T is paranormal and T is n-power quasinormal for some n ∈ N, does it follow that T is quasinormal? POWER QUASINORMAL OPERATORS AND THE ROOT PROBLEM 3
