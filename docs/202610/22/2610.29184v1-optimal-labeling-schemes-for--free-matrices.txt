Abstract 

We study labeling schemes for p×q Γ-free binary matrices, which do not contain a submatrix of the form Γ = 1 11 0

!

. We give a labeling scheme that uses O(log 2 N )-bit labels for rows and columns, where N = p + q, such that any matrix entry can be determined from the corresponding two labels in constant time in the word RAM model. The worst-case label size matches the counting lower bound up to constant factors. We also show that the entrywise least Γ-free supermatrix of an arbitrary p × q binary matrix, together with its labels, can be constructed in O(pq ) time. Our construction represents a Γ-free matrix by a sequence of rooted forests, where each column corresponds to a node and the 1-entries of each row form a root path in its corresponding forest. For n-vertex strongly chordal and chordal bipartite graphs, our result gives asymptotically optimal 

O(log 2 n)-bit adjacency labeling schemes with constant-time queries. These results answer both representation questions posed by Spinrad in 1995. arXiv:2610.29184v1 [cs.DS] 21 Oct 2026 1 Introduction 

A binary matrix M is said to be Γ -free if it does not contain a 2 × 2 submatrix of the form Γ = 1 11 0

!

,where the submatrix is obtained by selecting two rows and two columns without changing their order. Γ-free matrices are closely related to several well-studied graph classes. In particular, a binary matrix is totally balanced if and only if its rows and columns can be permuted independently to make it Γ-free [AF84]. This characterization applies to the biadjacency matrices of chordal bipartite graphs [GG78, AF84]. Moreover, a graph is strongly chordal if and only if its closed-neighborhood matrix can be made Γ-free by applying the same vertex ordering to its rows and columns [Far83, HHCHL21]. An adjacency labeling scheme assigns a binary label to each vertex of a graph such that the adjacency of two vertices can be determined using only their labels [KNR92]. The number of labeled n-vertex graphs in a class gives an information-theoretic lower bound on the label size, but a matching upper bound does not necessarily exist. For example, Hatami and Hatami [HH22] showed that some hereditary graph classes (closed under taking induced subgraphs) with 2 O(n log n) labeled graphs require nΩ(1) -bit labels. More recently, Bonnet, Duron, Sylvester, Zamaraev, and Zhukovskii [BDS +24] showed that some monotone graph classes (closed under taking subgraphs) with 2 O(n log 2 n) labeled graphs require Ω(log 3 n)-bit labels. We refer to Section 11 for a more detailed discussion of previous results on adjacency labeling schemes. Spinrad [Spi95] showed that the number of m × m Γ-free matrices is 2 Θ( m log 2 m) and gave an asymptotically optimal space representation for these matrices. However, this representation does not provide efficient access to individual matrix entries, nor does it directly yield an adjacency labeling scheme. Spinrad [Spi95, Section 6] also asked whether strongly chordal and chordal bipartite graphs admit O(n log 2 n)-bit representations supporting efficient adjacency queries and O(log 2 n)-bit adjacency labeling schemes. Dahlhaus [Dah97] studied representations of chordal and strongly chordal graphs and proposed an additional data structure supporting polylogarithmic-time adjacency queries. Otachi, Okamoto, and Yamazaki [OOY07] showed that every P6-free chordal bipartite graph is a unit grid intersection graph and discussed the connection between grid intersection representations and adjacency labeling for chordal bipartite graphs. However, neither work resolved Spinrad’s adjacency-labeling question for the corresponding graph class. 

Our results. Our main result is an asymptotically optimal labeling scheme for Γ-free matrices, stated in the following theorem. 

Theorem 1.1. Every p × q Γ-free matrix admits row and column labels of O(log 2 N ) bits, where N = p + q,such that any matrix entry can be determined from the corresponding two labels in O(1) time in the word RAM model. The label size is asymptotically optimal in the worst case. 

Our construction processes the matrix row by row, updating a forest after each row. The support of each nonempty row forms a root path in the resulting forest. However, an earlier row’s support need not remain a root path in the final forest. The main challenge is to encode the forest history within the row and column labels, using only O(log 2 N ) bits per label. The labeling scheme also gives asymptotically optimal O(log 2 n)-bit adjacency labels for n-vertex strongly chordal and chordal bipartite graphs, supporting constant-time adjacency queries. Notably, these natural graph classes have superfactorial but subquadratic speed 2 Θ( n log 2 n), for which matching labeling bounds do not follow from counting alone. Consequently, we answer both representation questions posed by Spinrad [Spi95]. 12 Overview of Techniques 

In this section, we outline the main ideas behind our labeling scheme. We first describe how a Γ-free matrix can be represented by a sequence of rooted forests, and then explain how a rank-based path decomposition allows us to encode the forest history using short labels. 

# 2.1 Forest representation of Γ-free matrices 

We process the rows of a Γ-free matrix from top to bottom, maintaining a rooted forest in which each column corresponds to a node. For a rooted forest F , let Anc F (x) and Desc F (x) denote the set of ancestors and descendants of a node x, respectively, both including x. Two nodes are said to be comparable if one is an ancestor of the other. We consider forests in which each parent has a larger index than its children. For two forests F and F ′ on the same nodes, we write F ⪯ F ′ if every ancestor relation in F is preserved in F ′.Let Fi denote the forest after processing the first i rows, where F0 consists of isolated nodes. For each row i, we define its support as Si = {x : M (i, x ) = 1 }. For each nonempty row i, let si = min Si. We aim to construct the forests so that 

Si = Anc Fi (si),

and they form an ancestor-monotone sequence 

F0 ⪯ F1 ⪯ · · · ⪯ Fp.

The following theorem shows that such a representation exists if and only if the matrix is Γ-free. 

Theorem 2.1. A binary matrix is Γ-free if and only if it admits an ancestor-monotone sequence of forests satisfying the above properties. 

A brief proof sketch is as follows. For each nonempty row i, we arrange the nodes of Si and their ancestors in Fi−1 into a path in increasing column order, leaving all other parent pointers unchanged. Since M is Γ-free, these ancestors already belong to Si, and all previous ancestor relations are preserved. Conversely, if every nonempty row support is a complete root path in an ancestor-monotone forest sequence, the matrix is Γ-free. The detailed proof is given in Section 4. # 2.2 Rank-based path decomposition 

To determine whether M (i, x ) = 1, we need to check whether x ∈ Anc Fi (si). One might consider using persistent data structures [DSST89] to retain the intermediate forests. However, this requires shared access, which is unavailable to a decoder using only two labels. Directly storing parent histories is also too costly: for example, when Si = {1} ∪ { q − i + 1 , . . . , q } for 1 ≤ i < q , node 1 changes its parent Θ( q) times. Instead, we use a rank-based path decomposition to encode the forest sequence compactly. For each node x in Ft, we define its rank as ⌊log | Desc Ft (x)|⌋ .1 An edge is called solid if its endpoints have the same rank, and dashed otherwise. The solid edges form vertex-disjoint paths, called solid paths ,including singleton nodes. For two forests F ⪯ F ′, a node is stable if its rank is the same in F and F ′. We assign an identifier to each solid path, where distinct solid paths in the same forest have distinct identifiers. We will show that these identifiers can be assigned so that a stable node retains its solid-path identifier across each update.

Ft−1 but the same solid path in Ft. Then they were incomparable in Ft−1, so their descendant sets were disjoint, each containing at least 2 r nodes. # 2.3 Construction of the labeling scheme 

We now describe how to construct the row and column labels using the rank-based path decomposition. For each t ∈ { 0, . . . , p }, we call t the timestamp of the forest Ft. For each column x, we store a list of triples (t, r, h ), called records , where t is the timestamp, r is the rank of x, and h is the identifier of the solid path containing x in Ft. The first record is stored at timestamp 0, and a new record is added whenever the rank of x or the identifier of its solid path changes. By Theorem 2.2, the identifier can change only when the rank increases. Since the rank increases at most O(log( q + 1)) times, each column stores O(log( q + 1)) records. For each nonempty row i, its support Si forms a complete root path in Fi. Since the ranks are nondecreasing along a root path, Si intersects at most one solid path of each rank. Thus, the label of row i stores the identifier of each intersected solid path and the smallest node of Si on that path. Since there are O(log( q + 1)) possible ranks, each row stores O(log( q + 1)) such pairs. To answer M (i, x ), we first find the most recent record of column x whose timestamp is at most i. Let r

and h be the rank and solid-path identifier stored in this record, respectively. We then check whether the row label stores the same identifier h for rank r, and whether x is at least the smallest node stored for that rank. This determines whether M (i, x ) = 1, since the intersection of a root path with a solid path is a suffix of the solid path, whose nodes are ordered by their column indices. Each column label stores O(log( q + 1)) records, and each row label stores O(log( q + 1)) pairs of identifiers and boundaries. Since each record or pair requires O(log N ) bits, the total label size is O(log 2 N ) bits. The predecessor search on the column records can be performed in constant time in the word RAM model with multiplication, using an additional data structure stored within the column label without increasing its asymptotic size. Together with the forest representation in Theorem 2.1, this establishes the upper bound of Theorem 1.1. The detailed construction and proof are given in Section 6. Our forest representation is related to Spinrad’s prefix-reachability construction [Spi95]. In particular, each forest Fi is the transitive reduction of the corresponding reachability relation (see Section A.2). However, our labeling scheme uses persistent solid-path identifiers to encode the forest history, allowing each matrix entry to be determined using only two labels.

Definition 3.2. A matrix-labeling scheme assigns a binary label ρM (i) to each row i and a binary label 

κM (x) to each column x of a matrix M . A fixed decoder D, independent of M , determines any matrix entry using only the corresponding two labels, such that 

D(ρM (i), κ M (x)) = M (i, x ).

The decoder receives the row label first and the column label second, and is not given the matrix dimensions or any other information depending on M . The label size is the maximum length of a row or column label. We use the word RAM model with word size w = c⌈log N ⌉ for a sufficiently large constant c, supporting standard word operations, including multiplication, in constant time. Each label is stored as an array of 

w-bit words, and the decoder can access any word of the two given labels in constant time. # 5 Rank Stability and Persistent Identifiers

Read ( r, h ) = ( rj , h j ) from record ( vj , r j , h j ). 4. Return 1 iff Hi[r] = h and x ≥ Bi[r]. The binary-search decoder gives the following theorem.

# 6.2 Constant-Time Decoding 

The binary-search decoder spends O(1 + log log( q + 1)) time finding the state of a column at the queried version. We use the predecessor structure described in the following theorem to replace binary search and obtain constant-time decoding. 10 Theorem 6.7 (Static fusion-tree predecessor [FW93]) . On a word RAM with multiplication and w-bit words, a static set of k ≥ 1 distinct w-bit keys with associated w-bit values can be stored in O(k) words, supporting predecessor queries in O(1 + log w k) worst-case time. 

We now complete the proof of Theorem 6.1. 

Proof of Theorem 6.1. For each column x, we build a predecessor structure on the version numbers in its change list H(x). By Theorem 5.5, the number of records satisfies k ≤ L + 1 = O(b). The version numbers and their associated rank-identifier pairs fit in b bits, where b = Θ(log( q + 1)) is chosen sufficiently large. We apply Theorem 6.7 with word size b. The resulting predecessor structure occupies O(k) b-bit words and supports predecessor queries in 

O(1 + log b k) = O(1) time. We store the structure, including its auxiliary information, entirely in the column label. Its space usage is O(kb ) = O(log 2(q + 1)) bits. Since b ≤ w, operations on b-bit words, including multiplication, can be simulated in constant time on our word RAM. Packing these words into w-bit words adds O(w) = O(log N ) bits per label. Thus, the total label size remains O(log 2(q + 1) + log N ) bits. Replacing binary search in Algorithm 6.5 with predecessor search retrieves σi(x) in constant time. The remaining steps take constant time and are correct by Theorem 6.3. Section B gives a complete example of the forest construction, label assignment, and decoding.

# 9 Construction Time 

We analyze the time required to construct the canonical forest and the labels of Theorem 6.1. The forest construction also computes the Γ-free closure of an arbitrary binary matrix, as established in Theorem 8.2. 

Theorem 9.1. Given a p × q binary matrix M 0 with fixed row and column orders, its Γ-free closure and

N = p + q. The labels support entry queries in O(1) time on the word RAM. Proof. Since Γ is symmetric, taking the transpose preserves Γ-freeness and commutes with Γ-free closure. We may therefore orient the input so that it has r = max {p, q } rows and s columns. We store one orientation bit in each label indicating whether the input was transposed. If so, the decoder exchanges the roles of the two input labels before applying the matrix decoder. For each row i, let Si be its support. To compute Ai, traverse the ancestor paths of nodes in Si in Fi−1,marking visited nodes with the current row timestamp and stopping each traversal at the first marked vertex. Each node is visited at most once during the row, so Ai is found in O(s) time. Scanning the column order then installs Ai as an increasing root path. # 10 Applications 

We apply our labeling scheme to graph and hypergraph classes whose associated matrices admit Γ-free orderings. These orderings are needed to construct the labels, but not to answer queries. The corresponding centralized representations follow by concatenating the labels, as in Theorem 7.4. 

# 10.1 Totally Balanced Matrices 

A cycle matrix of order k ≥ 3 is a k × k matrix whose ones, after row and column permutations, occur exactly at ( j, j ) and ( j, j + 1), with column indices taken modulo k. A binary matrix is totally balanced if it contains no such submatrix. 

Theorem 10.1 (Anstee–Farber [AF84]) . A binary matrix is totally balanced if and only if its rows and columns can be permuted independently to make it Γ-free. 

Corollary 10.2. Every totally balanced p × q matrix admits O(log 2 N )-bit row and column labels supporting entry queries in O(1) time on the word RAM, where N = p + q. The labels can be constructed in O(pq ) time. Proof. Permute the rows and columns as in Theorem 10.1 and apply Theorem 1.1 to the resulting Γ-free matrix. Assign the resulting labels to the corresponding rows and columns of the original matrix. A doubly lexical ordering of a p × q matrix can be computed in O(pq ) time [Spi93], and every such ordering of a totally balanced matrix is Γ-free [Lub87]. The construction time then follows from Theorem 9.1. 

# 10.2 Chordal Bipartite Graphs 

For a bipartite graph G = ( U, V, E ), its biadjacency matrix has entry ( u, v ) equal to one exactly when uv ∈ E.The graph is chordal bipartite if it has no induced cycle of length at least six. 

Theorem 10.3 (Golumbic–Goss [GG78]; Anstee–Farber [AF84]) . A bipartite graph G = ( U, V, E ) is chordal bipartite if and only if the rows and columns of its biadjacency matrix can be permuted independently to make it Γ-free. 

Corollary 10.4. Every n-vertex chordal bipartite graph admits O(log 2 n)-bit adjacency labels supporting adjacency queries in O(1) time on the word RAM. The labels can be constructed in O(n2) time. This label-size bound is asymptotically optimal in the worst case. Proof. Choose the vertex orders as in Theorem 10.3 and apply Theorem 1.1 to the biadjacency matrix. For each vertex, we store its corresponding row or column label and one bit indicating its side of the bipartition. If the queried vertices belong to the same side of the bipartition, we return zero; otherwise, we use the matrix decoder. By Theorem 10.2 and Theorem 9.1, the labels can be constructed in O(n2) time. For the lower bound, fix a bipartition into two sets of m labeled vertices. Every m × m Γ-free matrix defines a chordal bipartite graph on these vertices, and different matrices define different graphs. By Theorem 7.1 and Theorem 7.2, the worst-case label length is Ω(log 2 n). 14 10.3 Strongly Chordal Graphs and Digraphs

# 11 Related Work 

Γ-free matrices and matrix orderings. Forbidden matrix patterns are used to characterize strongly chordal graphs [Far83], totally balanced matrices [AF84], chordal bipartite graphs [GG78], and β-acyclic hypergraphs [Fag83]. Related work on matrix orderings includes Lubiw’s study of doubly lexical order-ings [Lub87] and the work of Hell, Hern´ andez-Cruz, Huang, and Lin [HHCHL19, HHCHL21] on strong chordality in graphs and digraphs through Γ-free orderings. As discussed in Section 1, Spinrad [Spi95] established the counting bound for Γ-free matrices and gave an asymptotically optimal global representation. However, his representation does not provide efficient access to individual matrix entries. Dahlhaus [Dah97] studied compact representations of chordal and 16 strongly chordal graphs specified by ordered graphs with n vertices and m edges, using O(n + m) words, and proposed an auxiliary data structure supporting adjacency queries in polylogarithmic time. Otachi, Okamoto, and Yamazaki [OOY07] showed that every P6-free chordal bipartite graph is a unit grid intersection graph and asked whether all chordal bipartite graphs are grid intersection graphs. Chandran, Francis, and Mathew [CFM11] answered this negatively by showing that chordal bipartite graphs have unbounded boxicity. 

Adjacency labeling and counting bounds. Kannan, Naor, and Rudich [KNR92] studied implicit graph representations and their connection to induced-universal graphs; see also the survey of Gavoille and Peleg [GP03]. An induced-universal graph for a class contains every graph in the class as an induced subgraph. Such a graph with U vertices gives adjacency labels of ⌈log U ⌉ bits, although this does not necessarily imply efficient decoding. For general n-vertex graphs, Alon [Alo17] constructed asymptotically optimal induced-universal graphs with (1 + o(1))2 (n−1) /2 vertices, while Alstrup, Kaplan, Thorup, and Zwick [AKTZ19] obtained n/ 2 + O(1)-bit adjacency labels. For restricted graph classes, stronger bounds are known. Alstrup, Dahlgaard, and Knudsen [ADK17] obtained log n + O(1)-bit adjacency labels for forests, equivalently giving induced-universal graphs with O(n) vertices. Alon and Nenadov [AN19] constructed induced-universal graphs with O(n∆/2)vertices for graphs of maximum degree at most any fixed ∆ ≥ 2. The number of labeled graphs in a hereditary class as a function of n, called its speed , has been studied by Scheinerman and Zito [SZ94] and Balogh, Bollob´ as, and Weinreich [BBW00]. Atminas et al. [ACLZ15] investigated implicit representations of graph classes with factorial speed. For general hereditary classes, Bonamy, Esperet, Groenland, and Scott [BEGS21] showed that every hereditary graph class C admits labels of 

μC (n) + o(n) bits, where μC (n) = n−1 log |C n| and Cn denotes the set of its n-vertex graphs up to isomorphism. For strongly chordal and chordal bipartite graphs, μC (n) = Θ(log 2 n). However, the additional o(n) term prevents this bound from establishing O(log 2 n)-bit labels. As discussed in Section 1, counting bounds alone do not always give matching labeling schemes. Hatami and Hatami [HH22] constructed hereditary classes with 2 O(n log n) labeled graphs that require nΩ(1) -bit labels. Bonnet, Duron, Sylvester, Zamaraev, and Zhukovskii [BDS +24] established a logarithmic separation between counting bounds and label sizes for certain monotone graph classes. For hereditary classes with at most 

n!cn labeled n-vertex graphs, Bonnet, Duron, Sylvester, and Zamaraev [BDSZ25] obtained polylogarithmic adjacency labels. 

Structural approaches to adjacency labeling. Gavoille and Labourel [GL07] gave (1 + o(1)) log n-bit labels for graphs of bounded treewidth. For planar graphs, Bonamy, Gavoille, and Pilipczuk [BGP22] obtained (4 /3 + o(1)) log n-bit labels using graph product structure, subsequently improved to (1 + o(1)) log n

bits [DEG +21]. The latter bound has recently been extended to all fixed proper minor-closed graph classes [DGJ +26]. Strongly chordal graphs contain all cliques, while chordal bipartite graphs contain all complete bipartite graphs. Thus, neither class has bounded treewidth or belongs to a fixed proper minor-closed class. 

Ancestry labeling, dynamic trees, and persistence. Ancestry labeling for static rooted trees has been studied extensively [AAK +06]. Fraigniaud and Korman [FK16] obtained log n + O(log log n)-bit ancestry labels with constant-time decoding. Korman, Peleg, and Rodeh [KPR04] studied labeling in dynamic trees, while Cohen, Kaplan, and Milo [CKM10] considered online ancestry labeling with immutable labels. Solid-path decompositions are classical in dynamic-tree data structures [ST83], while persistence allows 17 access to earlier versions of shared data structures [DSST89]. 

# 12 Conclusion and Further Directions 

We have shown that Γ-free matrices admit asymptotically optimal row and column labels supporting constant-time entry queries. The main ingredient is a monotone forest representation whose historical paths can be encoded using persistent path identities. 

Succinct representations and navigation. An open question is whether strongly chordal and chordal bipartite graphs admit succinct representations supporting efficient queries beyond adjacency. For either graph class, let H(n) denote the logarithm of the number of labeled n-vertex graphs. Can adjacency be supported in H(n) + o(H(n)) bits with constant query time? Another question is whether an O(n log 2 n)-bit representation can support neighbor reporting in O(1 + deg( v)) time, constant-time distance queries, or shortest-path reporting in O(1 + ℓ) time, where ℓ is the number of edges in the reported path. 

Multiple historical paths. Our forest characterization suggests a parameter for binary matrices based on the number of historical root paths needed to represent each row. For fixed row and column orders, let k be the minimum integer for which an ancestor-monotone forest history represents every row as a union of at most k complete root paths. By Theorem 2.1, k ≤ 1 exactly for Γ-free matrices. Minimizing k over suitable row and column orders also gives parameters for the corresponding graph classes. It would be interesting to characterize matrices and graphs with small k, determine the complexity of computing these parameters, and investigate labeling bounds in terms of k.More generally, it would be interesting to identify other evolving structures in which local identities change only a small number of times, allowing compact labels for historical queries.

# A.2 Relationship to Spinrad’s Construction 

Spinrad [Spi95] considers a directed graph on the columns induced by their co-occurrence in row prefixes. For each i ∈ { 0, . . . , p }, let Gi be the digraph on [ q] containing an arc x → y if x < y and some row h ≤ i

contains both x and y.22 Proposition A.2. For every Γ-free matrix M and every prefix i, the reflexive ancestor relation of Fi equals the reflexive-transitive closure of Gi. Equivalently, Fi is the transitive reduction of the reachability relation of 

Gi.Proof. By Theorem 4.3, every parent edge x → y of Fi has a witness row h ≤ i containing both x and y.Hence every ancestor relation in Fi is a reachability relation in Gi.Conversely, suppose x → y is an arc of Gi, witnessed by a row h ≤ i. By Theorem 4.4, the support of row 

h is a complete increasing root path in Fh. Since x < y , the node y is an ancestor of x in Fh. By Theorem 4.2, this relation also holds in Fi.Thus, the two reflexive-transitive relations coincide. Since a forest is the transitive reduction of its ancestor relation, the proposition follows.
