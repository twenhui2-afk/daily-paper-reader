# RECURSIVE SELF -I MPROVEMENT ON A BUDGET :SCORING CODE EDITS BEFORE THEY RUN 

Erfan Darzi 1,2, Sree Bhargavi Balija 3, Sheng He 11Harvard University 2Massachusetts Institute of Technology 3UC San Diego 

## ABSTRACT 

A coding agent that rewrites its own scaffold has to choose which proposed edit to expand before that edit has been evaluated, and the search then has to return one agent. Each run fits one linear readout on the parent’s steering-split solve rate and eight coordinates of the proposed diff, from 96 scaffold edits labeled by four eval-uations of a 16-instance fit split, and then freezes the coefficients. HumanEval+ reserves 48 instances as the steering split and Polyglot reserves 64. That split scores parents and keeps an archive of four nodes. Huxley–Gödel Machine selec-tion draws a parent by Thompson sampling on the steering counts of nodes that have already been evaluated, and it expands the child that parent proposes. Every method then returns the earliest evaluated node whose steering-split solve count is maximal. The tables report the held-out score of that node on the other 100 Hu-manEval+ instances and the other 145 Polyglot instances, next to the root scaffold and the calibration edit with the highest fit-split label. Twelve runs of GPT-4o re-turn a node at 87.0% on held-out HumanEval+, against 84.2% for the parent-rate ablation. On that split Huxley–Gödel Machine selection returns 85.1%, the root is at 81.2%, and the calibration-best edit is at 82.8%. On the same split Claude Son-net 4.5 returns 86.6%, beside 86.5% for Huxley–Gödel Machine selection, 85.3% for the parent-rate ablation, and 85.1% for the calibration-best edit. 

## 1 INTRODUCTION 

A coding agent that rewrites its own scaffold has to rank the edits it proposes before any of them has been evaluated, because the checker runs on one child per keep step and the child that is kept becomes a parent of the edits that follow. The Darwin Gödel Machine adds a child to its archive only after that child has been evaluated, and it samples parents from observed scores (Zhang et al., 2026). The Huxley–Gödel Machine draws a parent by Thompson sampling on the success and fail-ure counts of evaluated nodes and expands the child that parent proposes (Wang et al., 2026). AIDE scores a candidate after the evaluator has run it (Jiang et al., 2025). Surrogate-assisted evolution fits a predictor of fitness from earlier evaluations of similar individuals (Jin, 2011). The readout is that kind of predictor, applied to the diff before the child is expanded. It is a linear score on the parent’s steering-split solve rate and eight coordinates of the diff. The ablation uses the same archive and expands by the parent’s steering rate alone. When the keep steps end, the readout, the parent-rate ablation, and Huxley–Gödel Machine selection each return the earliest evaluated node whose steering-split solve count is maximal. The held-out score of that node is the comparison, to-gether with the root and the calibration edit whose fit-split label is highest. Huxley–Gödel Machine selection draws θ from Beta(1 + ns, 1 + nf ) for each evaluated node, using that node’s steering counts, and expands the child of the parent with the largest draw. Every run of every method spends the same number of checker evaluations: the readout and the ablation label 96 calibration edits and then expand 24 children, and Huxley–Gödel Machine selection expands 144 children on Polyglot and 176 on HumanEval+. Claude Sonnet 4.5 and GPT-4o ( gpt-4o-2024-08-06 ) are fit separately (OpenAI, 2024). The held-out splits are 100 HumanEval+ instances and 145 Polyglot instances (Liu et al., 2023; Gauthier, 2024). ## 2 METHOD 

2.1 BIRTH -TIME READOUT 

The root is a scaffold: a system prompt and a loop that writes a solution, runs the unit tests, and retries once. A proposal is a unified diff of that scaffold. The readout scores that diff from the parent’s steering-split solve rate and from eight coordinates of the diff, before the diff is expanded. The diff is embedded by text-embedding-3-small as a vector in R1536 . Each run draws its own projection, with i.i.d. standard normal entries and rows scaled to unit length, and it maps that vector onto the coordinates e. The birth feature of the full readout is X = ( Rpar , e ) ∈ R9. Both Rpar and the label R are solve rates in [0 , 1] .Before the search, each run calibrates its own readout. It proposes 96 scaffold edits, 48 of the root and two from each of 24 first-generation children of the root, and labels each edited child by its mean solve rate over four evaluations of a fixed 16-instance split of the benchmark being run. Each of those 24 parents is evaluated once on the steering split, so Rpar is measured for every calibration parent. Because those parents do not share one rate, the least-squares slope on Rpar is identified, and on these pairs that slope is positive. Each generator is fit separately on each benchmark. When those steps end, every method returns the earliest evaluated node whose steering-split solve count is maximal, and the root remains eligible. ## 4 RELATED WORK 

Gödel machines accept a self-rewrite only after a proof of higher expected utility (Schmidhuber, 2007). Good (1966) and Clune (2019) discuss ultraintelligent machines and AI-generating algo-rithms. The Self-Taught Optimizer (STOP), Automated Design of Agentic Systems (ADAS), and the Self-Improving Coding Agent (SICA) edit a scaffold or a codebase; SICA reports 17% to 53% on a random SWE-bench Verified subset (Zelikman et al., 2023; Hu et al., 2024; Robeyns et al., 2025). The Gödel Agent searches a space of agent designs (Yin et al., 2025). With Claude 3.5 Sonnet (new), DGM reports 20.0% to 50.0% on a staged SWE-bench subset (Zhang et al., 2026). Wang et al. report 56.7% on SWE-Verified-60 with a different generator (Wang et al., 2026). In Table 1 that parent draw runs for the full horizon, and the reported node is the earliest evaluated node whose steering-split solve count is maximal. Liu et al. report 78.3% on SWE-Verified-60 and 93.3% on Polyglot with Qwen3.6-35B-A3B (Liu et al., 2026). Lai et al. aggregate descendant out-comes into clade-level Beta beliefs and select nodes by Thompson sampling (Lai et al., 2026). AIDE scores a candidate only after an evaluator runs it, and AIDE 2 keeps a self-rewrite only after a hidden evaluation (Jiang et al., 2025; Srikanth et al., 2026). 

## 5 CONCLUSION 

The readout ranks scaffold diffs by the parent’s steering-split solve rate and by eight coordinates of the diff, and every method returns the earliest evaluated node whose steering-split solve count is 6maximal. On held-out HumanEval+ with GPT-4o, that node scores 87.0%, against 84.2% for the same rule after parent-rate expansion. Huxley–Gödel Machine selection returns 85.1% on that split, the root is at 81.2%, and the calibration-best edit is at 82.8%. On the same split Claude Sonnet 4.5 returns 86.6%, beside 86.5% for Huxley–Gödel Machine selection, 85.3% for parent-rate expansion, and 85.1% for the calibration-best edit (Table 1, Figure 1). 

## 6 LIMITATIONS 

The readout is linear in eight coordinates of one projection per run, and the coefficients stay fixed through the 24 keep steps. The fit uses 96 scaffold edits labeled on 16 instances, and the archive keeps four nodes. The generators are Claude Sonnet 4.5 and GPT-4o ( gpt-4o-2024-08-06 ), on HumanEval+ and Polyglot.
