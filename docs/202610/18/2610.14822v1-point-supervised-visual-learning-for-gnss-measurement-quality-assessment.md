## Abstract
Multipath and non-line-of-sight (NLOS) propagation degrade global navigation satellite system (GNSS) positioning accuracy in urban environments. Although fisheye sky segmentation identifies obstructions along satellite directions, binary visibility does not fully characterize observation quality. This study proposes a point-supervised visual framework that predicts GNSS observation faults from fisheye images using supervision derived from GNSS observations. During offline labeling, a vision-assisted differential GNSS procedure selects multiple reference satellites based on sky visibility and elevation constraints. Double-difference pseudorange residuals automatically generate fault labels and sample importance weights at satellite projection locations. A residual-weighted loss is computed only at valid labeled points, enabling learning from sparse supervision without manual pixelwise fault annotations. The trained network generates dense fault probability maps, which are sampled at satellite projection locations to weight observations in weighted least squares positioning, reducing the influence of potentially faulty observations. The framework is evaluated using U-Net, DeepLabv3+, DINOv3, and SAM3 on urban vehicle data collected on a different day from the training data. All four models reduce horizontal root mean square error (RMSE) by 29.51% to 36.07% compared with SAM binary sky segmentation, with U-Net achieving the lowest RMSE of 0.78 m. The framework also provides positioning solutions during some intervals when the segmentation baseline fails. These results demonstrate the framework's generalization ability and show that GNSS-derived point supervision enables fisheye images to provide observation quality information beyond binary sky visibility, supporting GNSS fault detection.
