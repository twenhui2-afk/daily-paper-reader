## ABSTRACT 

LLM planning research has traditionally focused on discrete-state domains, where actions form a finite, enumerable set. Existing LLM planning frameworks largely assume actions are enumerable, modeling planning as a search process over candi-date actions. However, in continuous-state domains, where actions form a contin-uum and cannot be enumerated, this assumption breaks down. We find a remedy in Newell and Simon’s Means-Ends Analysis (MEA), a general problem-solving technique rooted in heuristics from human psychology. We develop M EDAKA ,an MEA-inspired structured prompting framework that encourages recursive goal decomposition, algebraic derivation, and per-step state tracking. To evaluate native LLM planning abilities in continuous-state domains, we develop L IQUID WORLD ,a systematic testbed on liquid mixing. On L IQUID WORLD , M EDAKA can improve performance across model families, suggesting that classical means-ends analysis elicits LLM-native reasoning abilities that are helpful for continuous-state planning. 

## 1 INTRODUCTION 

Large language models (LLMs) have shown remarkable abilities across diverse domains, including commonsense reasoning (Zellers et al., 2019), mathematics (Wei et al., 2022), and code genera-tion (Chen et al., 2021). These successes have prompted interest in applying LLMs to more complex cognitive tasks, such as planning (Valmeekam et al., 2023). Existing methods for LLM planning are primarily developed for tasks with discrete states and enumerable actions (Valmeekam et al., 2023). These methods mainly build on an enumerate-and-rank assumption, where they model planning as searching actions over a discrete, enumerable space, and use techniques like state-aware backtracking (Sel et al., 2025) or external tree structures (Yao et al., 2023; Hao et al., 2023) to aid the search process. However, in many scenarios such as biochemical experimentation, states are continuous, and actions are no longer enumerable. Such a distinction requires LLM capabilities beyond search: while actions cannot be enumerated, they can often be derived algebraically, given a faithful representation of the current state and its deviation from the goal state. In this case, planning natively in such domains requires an LLM to (1) decompose goals into tractable subgoals, (2) faithfully track states across steps, and (3) perform accurate derivations at each step. An answer to this challenge comes from classical Means-Ends Analysis (MEA) (Newell & Simon, 1995), a general problem-solving technique rooted in human psychology. MEA is structurally well-suited to continuous action spaces because it treats undetermined parameters not as candidates to be enumerated and ranked, but as gaps to be closed by reasoning about the constraints relevant to the current subgoal. Concretely, at each step, MEA (1) identifies a gap between the current state and subgoal, (2) proposes an operator (i.e., an action with potentially undetermined parameters) that would close it, (3) recursively resolves any precondition or parameter the operator leaves undetermined, treating each as a new subgoal, and (4) terminates when every parameter is determined. Because the gap is evaluated at each step, MEA also encourages state tracking: the state must be updated and re-examined after every operator application before the next subgoal is identified. In MEA, an 1arXiv:2610.24928v1 [cs.AI] 18 Oct 2026 undetermined parameter is a gap to be closed by accurately deriving a small system of equations linking the operator’s parameters to a local subgoal, rather than requiring the LLM to reason about all constraints simultaneously. Inspired by MEA, we develop M EDAKA , a structured prompting framework for LLM planning in continuous-state domains that encourages recursive goal decomposition and per-step state tracking. To isolate and evaluate LLM native planning abilities in continuous-state domains, we develop LIQUID WORLD , a systematic testbed grounded in fluid mixing, a primitive operation to which numerous standard laboratory protocols (e.g., serial dilution, growth medium preparation, and buffer preparation) can be reduced. LIQUID WORLD problems cover diverse structural characteristics, isolating key reasoning capabilities for planning in continuous-state domains (Table 1): nonlinearity of the mixing constraints, coupling of action parameters, and context length (number of goals and distractor vessels). On L IQUID WORLD , M EDAKA can yield performance improvement over existing prompting frameworks for LLM planning across both closed-source (Claude (Anthropic, 2026), GPT (Hurst et al., 2024; Singh et al., 2025), Gemini (Google, 2025)) and open-source model families (Llama (Grattafiori et al., 2024), Gemma (Team et al., 2026)), suggesting that the enumerate-and-rank assumption shared by existing methods is mismatched with continuous-state planning, and that classical means-ends analysis offers a better structural fit. We make our code available at 

https://anonymous.4open.science/r/medaka_code-FFD0 .Our contributions are as follows: • We identify continuous-state planning as a distinct challenge for LLM planning and charac-terize the enumerate-and-rank assumption as an architectural mismatch with this setting. • We introduce L IQUID WORLD , a systematic testbed for isolating and evaluating LLM native planning in continuous domains, covering diverse problem structures in fluid mixing. • We propose M EDAKA , a structured prompting framework for LLM planning grounded in Means-Ends Analysis that encourages recursive goal decomposition and per-step state tracking, that can better elicit LLM native planning abilities on L IQUID WORLD .

## 2 RELATED WORK 

LLM planning frameworks. Current LLM planning frameworks mainly elicit LLM native plan-ning behavior via prompting. Chain-of-Thought (CoT) (Wei et al., 2022) prompting instructs the model to articulate intermediate reasoning steps before committing to an action and is the default planning framework for modern LLMs. Tree-of-Thoughts (ToT) (Yao et al., 2023) extends CoT with explicit branching and value-guided search over partial solutions. RAP (Hao et al., 2023) casts the LLM as a world model and runs Monte Carlo Tree Search over its predicted transitions. Algorithm of Thoughts (AoT) (Sel et al., 2024) embeds a simulated search trace inside the prompt, while AoT+ (Sel et al., 2025) augments this with periodic state memoization to mitigate state hallucination. Another line of research in LLM-Modulo (Kambhampati et al., 2024) frameworks equips LLMs with external solvers or verifiers to offload parameter derivation. For example, LLM3 (Wang et al., 2024) uses a motion planner to validate LLM-proposed parameterized actions, and PRoC3S (Curtis et al., 2025) uses the LLM to output a constraint-satisfaction program whose parameters are filled in by a constraint-satisfaction solver. The goal of our work is to isolate and elicit native LLM planning abilities in continuous-state domains, not to build a deployable planner. Hence, we do not compare with LLM-Modulo methods, since their external solvers perform the parameter derivations that we aim to measure natively in LLMs. 

LLMs in the laboratory. A growing body of research employs LLMs as agents in scientific laboratories. Coscientist (Boiko et al., 2023) equips GPT-4 with tools in internet search, code execution, and robotic instrumentation to autonomously design and run chemistry experiments. ChemCrow (M. Bran et al., 2024) augments GPT-4 with 18 expert-designed tools spanning organic synthesis, drug discovery, and materials design, demonstrating the ability to automate the synthesis of small molecules. Reinforcement learning has also been applied to protocol planning for robotic liquid handlers, a problem that is NP-complete (Ferdosi et al., 2023). These systems show that continuous quantities arise naturally when LLMs operate in laboratory settings. They rely on external tools, agentic orchestration, or task-specific training, whereas we study the planning ability of the LLM itself. 2Classical planning and Means-Ends Analysis. Classical planning provides the formal vocabulary (e.g., operators, preconditions, decomposition) that our framework adapts to LLM-based reasoning. The General Problem Solver (Newell & Simon, 1995) introduces Means-Ends Analysis as a recursive difference-reduction procedure. STRIPS (Fikes & Nilsson, 1971) formalized symbolic operators with preconditions and effects, and PDDL (Aeronautiques et al., 1998) standardized this representation as a planning language. PDDL 2.1 (Fox & Long, 2003) extended the language with numeric fluents, and Metric-FF (Hoffmann, 2003) provided a heuristic solver for the resulting numeric planning problems. HTN (Erol et al., 1994) planning introduced hierarchical task networks that recursively decompose compound tasks into primitives. Together, these works supply the symbolic substrate that M EDAKA 

imports into LLM prompting. 

## 3 METHODS 

3.1 PROBLEM FORMULATION 

From discrete to continuous-state planning. LLM planning has been studied predominantly in 

discrete-state domains such as BlocksWorld (Valmeekam et al., 2023), where state transitions are symbolic, not algebraic. LLM planning frameworks, e.g., Chain-of-Thought (Wei et al., 2022), Tree-of-Thoughts (Yao et al., 2023), RAP (Hao et al., 2023) and AoT + (Sel et al., 2025) have advanced the state of the art on this classic benchmark, but their core mechanisms (tree search, beam search, in-context simulated search) presuppose a finite action space. However, many planning domains in biochemical laboratories, e.g., liquid handling, involve states governed by continuous numerical quantities. Whether LLM planning methods designed for discrete action selection transfer to such continuous-state domains has not been formally investigated. 

Planning formulation. Let S be a state space, A an action space, and T : S × A ⇀ S a transition function. A planning problem is a tuple P = ( S, A, T , s 0, g ), where s0 ∈ S is the initial state and g : S → { 0, 1} is a goal predicate that identifies goal states (Ghallab et al., 2004). We denote 

A(s) = {a ∈ A : T (s, a ) is defined } as the set of actions applicable in s. A plan is a sequence 

(a1, . . . , a T ) such that, setting st = T (st−1, a t) for each t, every action is applicable ( at ∈ A (st−1))and the final state satisfies the goal ( g(sT ) = 1 ). When the planner is an LLM π, each generated step implicitly performs two sub-tasks: • Action selection : choosing at ∈ A (st−1) to reduce the gap between st−1 and g;• State prediction : computing ˆst ≈ T (st−1, a t), i.e. simulating the transition in natural language. This decomposition is central to our analysis: existing methods differ primarily in how they handle action selection, while leaving state prediction to the LLM’s unstructured generation. In discrete domains A(s) is finite for every s, and planning reduces to a search over a finite graph. In continuous-state domains, A(s) is a continuum, thus enumerating candidate actions is no longer possible; a valid plan may require parameter values that no finite discretisation of A contains. The planner must derive 

the correct v from the current state and goal, not select it from a finite list. On the state-prediction side, once at is fixed, computing ˆst = T (st−1, a t) becomes a numerical task that existing LLM planning frameworks leave unstructured. We study continuous-state LLM planning along two axes: • LiquidWorld (§3.2), a systematic testbed for LLM continuous-state planning, grounded in fluid mixing tasks with varying structural characteristics. • MEDAKA (§3.3), a structured prompting framework for LLM continuous-state planning, in-spired by Means-Ends Analysis (Newell & Simon, 1995). An equivalent textual rendering is then presented to the LLM to generate plans. Figure 1 shows an example instance in structured text. To measure reasoning capabilities key to planning in continuous-state domains, we develop problems with five structural characteristics (Table 1): (1) whether to allow direct pouring from source to target (“linear”) or (2) require sources to always route through intermediate pools (“nonlinear”); (3) whether the underlying algebraic system has heavy coupling across different sources (“coupling”); (4) whether there is a large number of targets (“multi-goal”); and (5) whether there are excess vessels that are neither targets nor necessary for use (“distractors”). Each L IQUID WORLD instance exhibits one or more such characteristics, which function as difficulty tags: (1) While pouring actions can be read out iteratively, one liquid at a time, when there is no coupling between the sources, algebraically solving a linear system is required for “coupling” problems. (2) “linear” problems are solvable under a single linear program (LP), which we use only to construct instances with verifiable ground truth, while “nonlinear” ones are more mathematically and structurally complex, since the compositions of the intermediate pools are unknown, resulting in bilinear goal constraints (to and from the pool). “nonlinear” instances are derived from the pooling problem (Haverly, 1978), which is an NP-hard process optimization problem (Alfaki & Haugland, 2013; Haugland, 2016). (3) Problems tagged with “multi-goal” and “distractors” have longer context length than those that are not. For “linear”-tagged problems, we apply a parametric generator, whose input includes the grammar of the problem specification language (Figure 2) and the parameters for the start and goal states (number of source vessels, target vessels, and liquids). “nonlinear”-tagged problems also conform to the above grammar but are hand-designed to account for the constraints of intermediate pools.

Section 3.1 argued that continuous-state planning requires deriving action parameters rather than selecting actions from an enumerable set. To facilitate planning in the continuous-state domain, we adopt a primitive from Means-Ends Analysis (MEA) (Newell & Simon, 1995), a general problem-solving approach rooted in human psychology that is built around parameter derivation instead of search. MEA identifies the gap between the current state and the goal and proposes an operator that closes that gap. Here, an “operator” is an action but potentially with underspecified parameters. For example, an operator in L IQUID WORLD can be “Pour to V3” but with the exact amount unknown. If the operator’s preconditions are not satisfied, or parameters are not yet derived, a recursive subgoal is created to meet these preconditions or derive these parameters. Recursive goal decomposition. At each planning step, M EDAKA instructs the LLM to (1) compute 

D = DIFF (st−1, g ), the set of unsatisfied goal conditions, (2) propose an operator o that would reduce one of these gaps, and (3) test whether o is applicable , i.e., all of o’s preconditions satisfied and all of its numerical parameters determined. If o is not applicable, then the LLM recursively sets up subgoals whose satisfaction makes o applicable. Recursion terminates when a fully parameterized, precondition-satisfying operator is reached, and only then does the LLM commit to an action a.This scheme encourages every undetermined parameter to be made an explicit subgoal and fully specified before an action is committed, rather than guessed and incrementally amended. It places reasoning effort before commitment, reducing the propagation of errors into the generated plan. This marks a deviation from the workflow established by planning frameworks like AoT (Sel et al., 2024) and AoT+ (Sel et al., 2025), which place emphasis on backtracking when the plan goes awry. 

Per-step state tracking. Per-step state tracking governs all numerical computation in M EDAKA ,encouraging faithful algebraic derivations at every planning step. It instructs the LLM to evaluate the transition equations (Eq. 1) against the tracked state in both directions (Appendix B.1): backward, by setting up and solving equations for action parameters; forward, by deriving the complete successor state st = T (st−1, a t) after every committed action at, listing the volume and composition of every vessel, not only those affected by the action. This contrasts with AoT+, which caches states only at heuristically chosen intervals during its in-context simulated search. In M EDAKA , the state output is instead a computational mechanism that constrains subsequent reasoning: because the next step’s DIFF is computed from the recorded st, a hallucinated state either produces an inconsistent gap or surfaces as a contradiction in later steps. 64 EXPERIMENTS 

4.1 SETUP 

We compare M EDAKA against two prompting-based LLM planning methods: Chain-of-Thought (CoT) (Wei et al., 2022) and AoT+ (Sel et al., 2025). CoT is the standard sequential rea-soning baseline that represents the default LLM reasoning behavior, while AoT+ is a recent state-of-the-art prompting framework for LLM planning that augments reasoning with in-context search and periodic state memoization. Both methods were originally developed and evalu-ated primarily in discrete symbolic planning domains. We do not compare with LLM-Modulo methods since external solvers confound native parameter derivation abilities key to planning. We evaluate across seven LLMs spanning both proprietary and open-weight families across different model sizes: Claude-Sonnet-4.6, Gemini-3-Flash, GPT-5.4, GPT-4o, LLaMA-3.3-70B, Gemma4-4B , and Gemma4-2B . Since our question is which reasoning struc-ture helps continuous-state planning, we disable thinking mode for all models so that their pretrained reasoning patterns do not override the tested prompting methods’ intended behavior. For each (model, method, problem) triplet, we perform three repeated rollouts and measure pass@1 (accuracy) and

In summary, these results suggest that M EDAKA can elicit LLM reasoning capabilities, e.g., resolving nonlinear constraints, faithful algebraic derivation, and long-context management/reasoning, that are crucial for planning in continuous-state domains.

We perform an ablation study on M EDAKA ’s two core components (recursive goal decomposition and per-step state tracking) using Claude-Sonnet-4.6 and Gemini-3-Flash , the two models with the best M EDAKA performance and largest improvement over CoT. We develop two ablated versions: “ − State Tracking” drops the per-step state-tracking module, which includes all numerical computation instructions, and “ − Recursive Module” drops all instructions related to recursive goal decomposition, retaining per-step tracking as an ‘algebra-aware’ CoT. As shown in Table 3, removing either module reduces performance, suggesting that the recursive decomposition (even without any numerical computation instructions) and state tracking modules each help LLMs on continuous-state planning. Note that since each ablation retains one module, their contributions need not be additive. 

## 5 DISCUSSION 

We studied LLM planning in continuous-state domains, where actions form a continuum and do not satisfy the enumerate-and-rank assumption of existing LLM planning frameworks. We developed MEDAKA , a structured prompting framework for LLM planning inspired by classical Means-Ends Analysis, and L IQUID WORLD , a systematic testbed for LLM continuous-state planning grounded in fluid mixing, covering diverse scenarios and measuring key LLM reasoning capabilities through structural difficulty tags. MEDAKA can outperform existing prompting-based baselines across difficulty tags, surpass CoT’s oracle-selected pass@3 on four of seven models, and retain gains over 9baselines when either M EDAKA component is ablated. All these results corroborate that recursive goal decomposition and per-step state tracking, as encouraged by Means-Ends Analysis, both help LLMs plan in continuous-state domains. While set in fluid mixing, L IQUID WORLD is designed as a controlled testbed rather than a benchmark: it isolates parameter derivation with deterministic, fully specified transitions, so that failures can be attributed to LLM reasoning. Though L IQUID WORLD already exposes systematic failures under CoT using a simple transition function, it could be extended with stochastic transitions, partial observability, or additional constraint types. Finally, pairing M EDAKA with external solvers or verifiers is a separate direction from ours: we restrict comparisons to single-turn prompting methods because our goal is to characterize the native planning abilities of LLMs.
