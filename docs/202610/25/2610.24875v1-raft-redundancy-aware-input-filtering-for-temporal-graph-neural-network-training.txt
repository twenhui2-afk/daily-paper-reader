## ABSTRACT 

Temporal graph neural networks (TGNNs) have shown strong performance on dy-namic graph learning tasks by continuously updating node memories from evolv-ing interactions (i.e., events) and leveraging these memories for downstream pre-dictions. As graphs grow rapidly in modern applications, training requires pro-cessing an increasing number of events; meanwhile, each event can update node memories used by later events, creating dependencies that constrain parallel exe-cution and limit the benefits of additional computing resources. These costs mo-tivate an upstream question: are all events, and the dependencies they introduce, necessary for learning? We investigate this question through two roles of tempo-ral events: prediction targets and historical events sampled as inputs. We observe that targets involving stable node memories tend to exhibit lower prediction loss, while filtering historical events associated with stable memories can retain simi-lar training-loss trajectories in several evaluated settings. Together, these observa-tions suggest an opportunity to identify input redundancy through changes in node memories. Building on this opportunity, we propose RAFT, a redundancy-aware input-filtering framework for TGNN training. RAFT tracks memory changes dur-ing training and uses them to guide two filters: a root-event filter removes selected prediction targets before training, and a support-event filter excludes selected his-torical context during sampling. Filtering inputs before their downstream prepa-ration and processing reduces the work they trigger. Across three TGNN models and five datasets, RAFT reduces training inputs by 35.23% on average and up to 97.11%, while reducing recorded training time by up to 52.56% with negligible changes to model precisions. 

## 1 INTRODUCTION 

Dynamic graphs are central to applications such as recommendation, social interaction analysis, and temporal knowledge reasoning (Trivedi et al., 2019; Kumar et al., 2019; Rossi et al., 2020; Zhang et al., 2023; You et al., 2022; Wang et al., 2021; Zhou et al., 2022; Kazemi et al., 2020; Xu et al., 2020; Sankar et al., 2020; Wang & Mendis, 2024). In these applications, relationships evolve over time, requiring learning models to capture both structural patterns and temporal dependen-cies. Temporal graph neural networks (TGNNs) address this need by learning from evolving events, where each event describes a temporal interaction between a source node and a destination node, such as adding an edge or a node to existing graphs (Kumar et al., 2018; 2019; Rossi et al., 2020; Belli et al., 2020; Chen et al., 2019; Jia et al., 2018; Chaintreau et al., 2007). In particular, recent TGNNs maintain per-node states—often called node memories—that summarize historical interac-tions that occurred around these nodes (Kumar et al., 2019; Rossi et al., 2020; Wang et al., 2021; 1arXiv:2610.24875v1 [cs.LG] 17 Oct 2026 A PREPRINT 

Zhou et al., 2022; Dai et al., 2025b; Zhou et al., 2023; Dai et al., 2025a). Each incoming event can update the memories of its participating nodes, which then support subsequent predictions. These memory-based designs allow TGNNs to capture changing interaction histories and achieve strong performance on dynamic graph learning tasks. As graphs grow rapidly in modern applications, TGNN training must process an increasing number of events. However, scaling TGNN training is challenging because events cannot always be pro-cessed independently. An earlier event may update a node memory needed by a later prediction; for example, successive interactions involving the same user may require the later prediction to incorpo-rate the earlier memory update. These dependencies constrain parallel execution and limit the ben-efits of additional computing resources (Dai et al., 2025b; Gao et al., 2024). Meanwhile, processing events requires fetching node and edge features and moving data between CPUs and GPUs, adding substantial preparation costs. Existing systems address these challenges through dependency-aware batching and scheduling (Dai et al., 2025b; Gao et al., 2024), efficient data preparation and execu-tion (Zhou et al., 2022; Wang & Mendis, 2024), and distributed training (Zhou et al., 2023). Yet their efficiency is still significantly bounded by the natural dependency of input events. If processing an event introduces both preparation costs and memory-update dependencies, determining whether that event needs to participate in training could address these costs at their source. We therefore raise a fundamental question: 

Are all events from the training dynamic graphs, and the dependencies they intro-duce, necessary for learning? 

To answer this question, we examine two roles of an event, a temporal interaction between a source node and a destination node. A root event is a prediction target that contributes to the training loss, whereas a support event is a historical interaction sampled as input for that prediction. The same interaction can serve both roles at different times. At the root-event level, we observe that targets whose endpoint memories are stable (i.e., changing little during updates) tend to have lower predic-tion loss, suggesting that the model already predicts these targets well. At the support-event level, we observe that omitting historical interactions associated with stable memories can retain similar training-loss trajectories, suggesting that some historical context provides limited additional benefit. Together, these observations reveal an opportunity to use memory stability to identify redundancy in both prediction targets and their historical inputs. Reducing unnecessary inputs at these two levels could avoid the data preparation and computation they would otherwise trigger. Building on this opportunity, we propose RAFT, a redundancy-aware input-filtering framework for efficient TGNN training. RAFT tracks memory changes during executed updates and uses the result-ing stability information to guide two filters. First, a root-event filter removes selected root events whose source and destination memories are stable, before these targets enter subsequent training stages. Second, a support-event filter excludes selected support events during temporal sampling, reducing the historical context returned for retained targets. Both filters use information from al-ready executed memory updates, avoiding an additional prediction pass merely to decide whether an input should be filtered. By making these decisions before downstream feature preparation and model computation, RAFT reduces the work triggered by selected training inputs. Our evaluation across three TGNN models and five datasets shows that RAFT reduces training inputs by 35.23% on average and up to 97.11%. The training time decreases by 17.80% on average and up to 52.56%, with mean absolute relative changes in validation AP and AUC of 0.13% and 0.14%, respectively. We summarize our contributions as follows: • We investigate input redundancy in memory-based TGNN training and identify two filter-ing opportunities through observations of prediction targets and sampled historical inputs. • We propose RAFT, a redundancy-aware input-filtering framework that uses shared memory-stability information to select prediction targets before training and historical con-text during sampling, reducing downstream preparation and computation. • We evaluate RAFT across three TGNN models and five datasets, demonstrating substan-tial input reduction and training-time savings while assessing the associated changes in prediction quality. 2A PREPRINT Time

## 2 BACKGROUND 

2.1 DYNAMIC GRAPHS AND MEMORY -BASED TGNN S

Dynamic graphs describe interactions that evolve over time. They are commonly represented as either discrete-time dynamic graphs (DTDGs), which organize graph evolution into snapshots, or 

continuous-time dynamic graphs (CTDGs), which represent it as an ordered stream of timestamped events (Trivedi et al., 2019; Kumar et al., 2019; Rossi et al., 2020; Zhang et al., 2023; You et al., 2022; Wang et al., 2021; Zhou et al., 2022; Kazemi et al., 2020; Xu et al., 2020; Sankar et al., 2020; Wang & Mendis, 2024). By preserving the timing and ordering of individual interactions, CTDGs capture fine-grained temporal information and naturally represent asynchronous graph evolution. We focus on memory-based TGNNs for this setting. Formally, we represent a CTDG as an event stream: 

E = {ei = ( ui, v i, t i, xi)}Ni=1 , (1) where ui and vi are the interacting nodes, ti is the timestamp, and xi contains the available interac-tion features. For example, a purchase connects a user to an item at a particular time. Temporal link prediction uses the preceding interaction history to predict whether two nodes will interact. To encode this evolving history, a memory-based TGNN maintains a vector mv for each node v (Ku-mar et al., 2019; Rossi et al., 2020; Wang et al., 2021; Dai et al., 2025b; Gao et al., 2024; Dai et al., 2025a; Zhou et al., 2022). As events are processed, their information is incorporated into node memories and carried forward to subsequent predictions. For prediction, the model computes an 

embedding , a vector representation derived from the available node memory and, in models with temporal neighborhood aggregation, sampled historical interactions. These embeddings are then used to score candidate interactions. Node memories therefore provide the evolving historical con-text on which predictions depend. 2.2 TGNN TRAINING AND MEMORY DEPENDENCIES 

TGNN training typically processes events in chronological mini-batches. The prediction targets in the current batch B are called root events . For models that use temporal neighborhoods, a sampler retrieves earlier interactions S(B) as inputs for these predictions; these historical inputs are called 

support events . In the purchase example, the purchase being predicted is a root event, while sampled earlier purchases provide support. The same interaction can serve as a root when it is processed and as support for later predictions. Figure 1 illustrates the training pipeline. The trainer first samples support events and fetches the required node and edge features. The model uses the available memories and sampled context to compute embeddings and predict the root events. Training compares scores for observed interactions with those for sampled noninteractions, computes the loss, and updates model parameters through backpropagation. Memory updates carry information from processed interactions forward to subse-quent predictions. Such dependencies restrict which events can be grouped or executed concurrently, so enlarging batches or adding computing resources does not automatically yield pro-portional throughput gains. Meanwhile, both root and support events incur feature preparation and computation costs. Existing systems seek greater parallelism through dependency-aware batching and scheduling, grouping compatible events or selectively relaxing memory dependencies (Dai et al., 2025b; Gao et al., 2024). Other frameworks improve sampling, data preparation, and distributed execution (Zhou et al., 2022; Wang & Mendis, 2024; Zhou et al., 2023). These approaches improve how events are executed. We examine an earlier decision: whether each event needs to generate that work in the first place. Determining which prediction targets and historical inputs are necessary offers an oppor-tunity to avoid their associated preparation and computation before scheduling and execution. This motivates our investigation of input redundancy as a way to reduce training costs at their source. 

## 3 MOTIVATION : WHICH TEMPORAL INPUTS ARE NECESSARY ?

Since memory updates create dependencies between events, we investigate whether changes in node memories can reveal redundancy in training inputs. 

Redundancy in root events Root events provide supervision, but targets that the model already predicts well contribute less to the training loss. To quantify this effect, we evaluate the contribution of each root event to the training loss by training TGN (Rossi et al., 2020) on the Wikipedia (WIKI), Reddit (REDDIT) (Kumar et al., 2019), and Wikipedia-talk(WIKI-TALK) (Paranjape et al., 2017) datasets. At first, we divide the root events into stable and unstable sets based on the stability of their source and destination nodes. We classify a root event as stable when, for each of its endpoints, the cosine similarity between the node’s memories before and after its most recent update exceeds 0.9; otherwise, the event is unstable . Figure 2(a) shows that stable root events have lower average training loss on all three datasets. Their share of training loss is also smaller than their share of root-event counts, as shown in Figure 2(b). For example, on WIKI-TALK, stable events account for 17.69% of root events but only 0.56% of training loss. These results suggest that memory stability can identify targets the model already predicts well, creating an opportunity to filter selected roots before they trigger historical sampling, feature preparation, and training. 

Redundancy in sampled support events Even when a root event is retained, its prediction may not require all of the sampled history. Node memories already summarize previous interactions, suggesting that some historical inputs repeat information the model has captured. We examine this opportunity by removing support events whose source nodes are stable while retaining the prediction targets. To quantify this effect, we evaluate the impact of support events on training convergence in TGN (Rossi et al., 2020) and APAN (Wang et al., 2021) on the WIKI and REDDIT datasets (Kumar et al., 2019). ## 4 RAFT DESIGN 

4.1 OVERVIEW 

Building on these opportunities, we propose RAFT, a redundancy-aware input-filtering framework for TGNN training. Guided by node memory changes, RAFT reduces training inputs at two levels. The root-event filter removes stable prediction targets, which tend to have low prediction loss, before they enter downstream training stages. The support-event filter prunes sampled historical inputs associated with stable source nodes, reducing the context processed for retained targets. An adaptive controller maintains node stability information and uses training-loss feedback to determine when these filters operate. The controller initially enables the filters applicable to the model; support filtering applies only when the model samples historical interactions. It then compares each executed batch’s loss with that of the preceding executed batch. While filtering is enabled, K consecutive batches without a loss decrease disable the filters, where unchanged and increased loss both count as non-decreases. While filtering is disabled, K consecutive batches with decreasing loss re-enable them. We empirically set K = 5 . An opposite trend resets the corresponding consecutive count, and each state transition resets the counts. Otherwise, the controller retains its current state. Disabled filters pass their inputs through unchanged, while normal memory updates continue to refresh node stability flags.

RAFT addresses training efficiency by selecting the events that enter the training pipeline. Its benefit therefore depends on how much input can be omitted, what this changes for learning, and how the reduction translates into saved work. We organize the evaluation around four research questions:

Benchmark and Testbed. We evaluate TGN (Rossi et al., 2020), APAN (Wang et al., 2021), and JODIE (Kumar et al., 2019) on five datasets: WIKI and REDDIT (Kumar et al., 2019), WIKI-TALK and STACK-OVERFLOW (abbreviated as SX-FULL) (Paranjape et al., 2017), and GDELT (Leetaru & Schrodt, 2013; Zhou et al., 2022). Our primary comparison adds RAFT to a state-of-the-art efficient training framework, Cascade (Dai et al., 2025b) while retaining the underlying model; we also evaluate integration with TGL (Zhou et al., 2022). Experiments use an AMD EPYC 7742 64-core CPU and an NVIDIA A100 40 GB GPU with CUDA 11.6. 

Input reduction. Depending on the experiment, N counts prediction targets or sampled historical-event occurrences. An interaction sampled multiple times contributes multiple occurrences.

These large-graph comparisons show that sub-stantial input reduction can coexist with prediction quality close to the baseline. Across all comparisons with Cascade, recorded training time decreases by 17.80% on aver-age and up to 52.56% . Among TGN’s five datasets, the two largest event streams yield its largest input and training-time reductions, illustrating the benefit of avoiding redundant work as event-processing workloads grow. 5.3 CONTRIBUTION OF THE TWO FILTERS (RQ3) To study the contribution of the two filters, we evaluate their individual and combined performance and compare them with the baseline models. Root filtering removes selected prediction targets and avoids their sampling requests, while support filtering reduces the historical context supplied to retained targets. Comparing Base, Root only, Support only, and Both reveals how these two selection points contribute to training efficiency. As shown in Table 2, combining the filters achieves the largest sampled-input reduction in all four settings. For TGN/REDDIT, root-only and support-only filtering remove 50.42% and 56.02% of sampled inputs, respectively, while their combination reaches 67.68%. The larger contributor varies across workloads: root filtering removes more input on TGN/WIKI and both APAN settings, whereas support filtering contributes more on TGN/REDDIT. Discussion. The results highlight three implications for efficient TGNN training. First, large in-teraction histories offer substantial opportunities for input reduction. TGN achieves its largest input and training-time reductions on SX-FULL and GDELT, showing the practical value of redundancy-aware selection on large graphs. Second, redundancy exists in both supervision and historical con-text: combining root and support filtering removes more inputs than either filter alone in all four component settings. Selecting targets and selecting their context therefore provide complementary benefits. Third, input selection can complement existing training optimizations. The additional training-time reductions when integrating RAFT with Cascade (Dai et al., 2025b) and TGL (Zhou et al., 2022) show that redundancy remains after improvements to batching and execution. Together, these findings motivate jointly optimizing which events participate in training and how the retained events are processed. Future work could combine memory-guided input selection with dependency-aware batch formation and explore its benefits in distributed training. 9A PREPRINT 

## 6 CONCLUSION 

In this work, we examine whether all temporal events are necessary for TGNN training. We pro-pose RAFT, which uses node memory changes to identify redundancy in prediction targets and sampled historical context. Its root-event and support-event filters reduce inputs before they trigger downstream processing, avoiding work in the dependency-constrained training pipeline. Evalua-tions across three TGNN models and five datasets demonstrate substantial input and training-time reductions, with validation quality remaining close to the baseline. The gains on large event streams highlight input selection as a practical approach to improving TGNN training efficiency as temporal graphs grow.
