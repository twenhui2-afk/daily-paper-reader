Abstract 

We introduce sub-connectivity logic , denoted by FO +subconn , an extension of first-order logic for graphs with a specified set Z of admissible edges. Its additional atom subconn (x, y ; ¯ z) asserts that x

and y are connected by a path using only edges of Z and avoiding the vertices in ¯z.Our main structural result states that, for every weakly sparse graph class C , the class of all expansions of graphs in C by rooted spanning forest orders has bounded twin-width if and only if C

excludes a fixed minor. When C excludes a fixed minor, we can also compute an additional linear order that preserves bounded twin-width in polynomial time. We translate FO +subconn into first-order logic over an expansion by a depth-first spanning forest order of the admissible-edge graph. Combining this translation with our structural result, we obtain a model checking algorithm for FO +subconn with running time f (|φ|, h (G)) · | G|c, where f

is computable, c is an absolute constant, and h(G) is the Hadwiger number of G. The translation and model-checking algorithm extend to binary relational structures, with the Hadwiger number measured on the Gaifman graph. For a graph class C let CZ := {(G, Z ) : G ∈ C , Z ⊆ E(G)}. We show that for every weakly sparse graph class C , the class CZ is monadically dependent for FO +subconn if and only if C

excludes a fixed minor. For monotone classes that admit efficient minor encodings, a corresponding hardness result makes this frontier computationally tight. We give applications to combinatorial reconfiguration and solution discovery problems, and study a guarded extension of FO +subconn 

motivated by database queries.

Appendix A Dependence of separator logic on monotone graph classes excluding a topological minor 63 1. Introduction 

Bridging algorithmic graph theory and finite model theory, a central line of research seeks efficient graph algorithms on well-behaved classes, together with logical and structural characterizations of the tractable problems and the underlying classes. The resulting statements are commonly expressed as algorithmic meta-theorems of the following form. 

Every problem expressible in ⟨logic ⟩ can be solved in time ⟨runtime ⟩ on every structure satisfying ⟨tameness condition ⟩.

Two prototypical examples of this pattern are the following. • Model checking monadic second-order logic ( MSO ) can be done in time f (|φ|, t ) · | G| on graphs 

G of tree-width at most t. This is known as Courcelle’s theorem. [2, 25, 26] • Model checking first-order logic ( FO ) can be done in time fC (|φ|, ε ) · | G|1+ ε on all graphs G

from every fixed nowhere dense graph class C . [56] In both of these examples, the involved structural tameness condition coincides with the notion of 

monadic dependence , a key notion from model theory that we will define later. For every graph class C that is monotone (i.e., closed under taking subgraphs), we have that C is monadically dependent . . . • . . . for MSO if and only if C has bounded tree-width; [57] • . . . for FO if and only if C is nowhere dense. [1] In this paper, we investigate the connection between efficient model checking and monadic dependence for minor-free graph classes. As minor-free graph classes are strictly sandwiched between bounded tree-width and nowhere dense classes, this calls for a logic that is less expressive than MSO and more expressive than FO .We introduce an extension of first-order logic, called sub-connectivity logic and denoted by 

FO +subconn . Formulas are evaluated on a graph G with a specified set Z ⊆ E(G) of admissible edges . In addition to the usual first-order atoms, the logic has an atom subconn (x, y ; ¯ z) asserting that x and y are not among the vertices in ¯z and are connected by a path using only edges of Z and avoiding those vertices. We translate FO +subconn on (G, Z ) into first-order logic on an expansion by a forest order induced by a rooted depth-first spanning forest of the graph (V (G), Z ). Combining this translation with our structural results, we show that there are a computable function f and an absolute constant c

such that an FO +subconn -sentence φ can be model-checked on (G, Z ) in time 

f (|φ|, h (G)) · | G|c,

where h(G) is the Hadwiger number of G, that is, the largest order of a clique minor of G. Thus, 

FO +subconn model checking is fixed-parameter tractable on every graph class excluding a fixed minor. The algorithm extends to binary relational structures M, with running time f (|φ|, h (Gaif( M))) ·∥ M∥c,where Gaif( M) is the Gaifman graph of M.For a graph class C , let CZ := {(G, Z ) : G ∈ C , Z ⊆ E(G)}. We call C weakly sparse if it excludes some complete bipartite graph as a subgraph. For every weakly sparse class C , we prove that CZ is monadically dependent for FO +subconn if and only if C excludes a fixed minor. 11.1. Context 

Model checking. For a logic L and a class C of finite structures, the associated computational problem in the broader program of algorithmic meta-theorems is the model checking problem: given M ∈ C

and a sentence φ ∈ L , decide whether M |= φ. Reformulated from above, algorithmic meta-theorems assert that model checking for a logic is tractable 1 on classes satisfying suitable structural tameness conditions, thereby linking logical definability, (graph) structure, and efficient computation in a uniform way. Classical milestones of this program include tractable model checking for MSO on bounded tree-width graphs [2, 25, 26] and for FO on sparse graph classes such as bounded degree, excluded minor, bounded expansion, and nowhere dense classes [82, 44, 37, 56]. More recently, 

twin-width has led to model-checking algorithms that also apply to dense graphs [13]. In particular, and particularly important for this paper, FO model checking is fixed-parameter tractable on classes of linearly ordered binary structures of bounded twin-width [10]. Beyond unifying large families of tractable problems, such results repeatedly lead to new structural viewpoints and algorithmic techniques. It has therefore become one of the central problems in algorithmic model theory to determine the exact tractability frontier of efficient model checking for various logics. 

The limits of tractability. The limits of tractability for model checking are closely related to 

dependence , one of the main dividing lines in classical model theory. A formula φ(¯ x; ¯ y) is independent on a class C if, for every n ∈ N, there are a structure M ∈ C , tuples ¯ai ∈ M |¯x| for i ∈ [n], and tuples ¯bJ ∈ M |¯y| for J ⊆ [n] such that 

M |= φ(¯ ai; ¯bJ ) ⇐⇒ i ∈ J. 

Intuitively, this means there are arbitrarily large sets, from which φ can pick out all the subsets. A formula is dependent on C if it is not independent on C , and a class is dependent for a logic if every formula of that logic is dependent on it. A class is monadically dependent if every expansion of the class by finitely many arbitrary unary predicates is dependent. For hereditary classes (i.e., classes closed under taking induced substructures), the notion of monadic dependence for FO is known to imply fixed-parameter tractable FO model checking for: • weakly sparse classes of graphs [37, 56], • edge-stable 2 classes of graphs [32, 31], • classes of linearly ordered graphs [10], • tournaments [49]. Moreover, model checking is known to be AW [⋆]-hard on every hereditary graph class that is not monadically dependent [34]. Strikingly, in many cases, monadic dependence corresponds to a graph-theoretic notion: • nowhere-denseness for weakly sparse classes [1], • flip-flatness for edge-stable classes [33], • bounded twin-width for linearly ordered graphs and tournaments [10, 49]. The connection between monadic dependence of linearly ordered structures, twin-width, and model checking will be central to our results for graphs equipped with forest orders. We refer to the recent survey [72] for a broader overview.

2First-order logic with connectivity and the quest for a logic for classes with excluded minors. A basic limitation of first-order logic is that it cannot express connectivity. Several natural extensions of first-order logic were introduced to address this gap. A recent example is separator logic , also denoted by FO +conn , which extends FO on graphs by allowing the use of the atomic predicate conn (x, y ; ¯ z),which evaluates to true if there is a path in the graph from x to y that avoids the vertices of ¯z [5, 81]. The following theorem summarizes the resulting frontier on monotone classes. 

Theorem 1.1. Let C be a monotone class of graphs. Then the following are equivalent: (1) C excludes some graph as a topological minor; (2) C is monadically dependent (for FO +conn ); (3) C is dependent (for FO +conn ). Moreover, any of these conditions imply that FO +conn model checking is FPT on C , while if C

is independent and admits efficient encoding a of graphs, then model checking on C is AW [∗]-hard.    

> aFor logics more expressive than first-order logic, independence alone need not rule out fixed-parameter tractable model checking, even on hereditary graph classes. Such phenomena occur for monadic second-order logic [46, 61] and separator logic [73]. To obtain hardness, we therefore impose an efficiency condition on the encoding. An efficient encoding of graphs
> consists of a polynomial-time construction that maps every finite graph to a monadic expansion of a structure in the class, from which a fixed simple interpretation in the logic recovers the input graph. Problem 1. Is there a natural logic L such that a monotone or weakly sparse class of graphs is monadically dependent for L if and only if it excludes a minor? 

Understanding the structure of monadically dependent classes. A complementary approach to monadically dependent classes studies tree-ordered weakly sparse (TOWS) representations of such graph classes. Many successful structural representations come with an underlying tree order. Exposing this order as a part of the structure makes global structure accessible to first-order logic. This viewpoint is central in the study of classes of many tameness notions for graph classes [10, 13, 14, 19, 21, 23, 27, 35, 45, 47, 48], and has very recently led to new characteri-zations of minor exclusion through tree-ordered weakly sparse graphs [20], which is a first step toward a solution of Problem 1 and the departure point of the present paper. Let us give the background. Let G be a graph. A spanning forest of G is an acyclic subgraph F ⊆ G with V (F ) = V (G).Following [58], we call F full if F and G induce the same partition of V (G) into connected components. A rooted spanning forest has one distinguished vertex, called a root , in each component. It defines a forest order ⪯F on V (G) by x ⪯F y if x lies on the unique path from y to the root of its component. For a graph class C , let 

C Υ := {(G, ⪯F ) : G ∈ C , F is a full rooted spanning forest of G},

C F := {(G, ⪯F ) : G ∈ C , F is a rooted spanning forest of G}.

3These are the classes of graphs in C expanded by full and arbitrary rooted spanning forest orders, respectively. Two results established a logical characterization of minor exclusion in this setting. 

Theorem 1.2 ([20, Theorem 1.4]) . Let C be a weakly sparse class of graphs. Then the following are equivalent: (1) C excludes some graph as a minor; (2) C Υ is monadically dependent (for FO ); (3) C F is monadically dependent (for FO ). 

The equivalence of the first two conditions is [20, Theorem 1.4]. The equivalence of (2) and (3) is an easy observation, see Remark 3.1 in the preliminaries. 

Theorem 1.3 ([12, Theorem 2]) . Let C be a monotone class of graphs. Then the following are equivalent: (1) C excludes some graph as a minor; (2) C has bounded spanning twin-width , that is: there exists a constant t such that every graph G ∈ C has a full rooted spanning forest F such that tww( G, ⪯F ) ⩽ t.

As an algorithmic application, we consider combinatorial reconfiguration and solution discovery for vertex-deletion problems whose feasibility conditions are expressible in separator logic FO +conn . The idea behind combinatorial reconfiguration is to transform one configu-ration of a system into another while keeping the system running throughout the transformation. For vertex-subset problems on graphs, we can imagine a token placed on each vertex of a solution. We change the configuration by moving one token at a time to an unoccupied vertex, either by sliding it along an edge or by allowing it to jump to any unoccupied vertex. The requirement that the system keeps running means that the vertices occupied by tokens must form a feasible solution after every move. The algorithmic question is whether two given feasible solutions can be transformed into one another by a sequence of such moves. This viewpoint has been applied to a wide range of graph problems. We refer for example to the surveys [17, 70, 88]. A particularly relevant family of examples arises from reconfiguring vertex sets that hit or separate prescribed structures. For instance, Feedback Vertex Set Reconfiguration asks to transform one deletion set into another while maintaining that the remaining graph is acyclic. Parameterized algorithms and kernels for several such vertex-set reconfiguration problems were studied in [68]. More recently, Feedback Vertex Set Reconfiguration has been studied in its own right on planar graph classes [15]. Vertex Separator Reconfiguration under the token addition/removal, token jumping, and token sliding rules has been studied in [29], while [52] considers the reconfiguration of minimum s-t separators. Since individual reconfiguration problems often require tailored arguments, there has also been substantial interest in algorithmic meta-theorems for reconfiguration. Mouawad, Nishimura, Raman, and Wrochna gave an MSO -based meta-theorem parameterized by treewidth and the length of the reconfiguration sequence [69]. Gima, Ito, Kobayashi, and Otachi obtained meta-theorems for reconfiguration under other structural parameters, such as neighborhood diversity and treedepth [50]. Further meta-algorithmic and structural results are known for sparse graph classes, for example for independent set and dominating set reconfiguration on sparse graphs [64, 83]. Our logic provides a new meta-algorithmic viewpoint. We consider modulator reconfiguration 

problems in which the current token set S is a deletion set and feasibility is expressed by a logical condition on the remainder G − S. By using FO +conn as the specifying logic, this captures, among others, Vertex Cover Reconfiguration , Feedback Vertex Set Reconfiguration , and 

s-t-Cut Reconfiguration . Let us stress again that we use separator logic to specify the property of G − S, problem, while we use the methods for subconnectivity logic to resolve the algorithmic reconfiguration problem. 7Theorem 7.1 (see page 49) . There exist a computable function f and an absolute constant c

such that, given a possibly unary-colored graph G, sets S, T ⊆ V (G), a budget b ∈ N, and a sentence ψ ∈ FO +conn , one can decide the ψ-Modulator-Reconfiguration problem in time 

f (|ψ|, h (G), b ) · | G|c.

The same method applies to solution discovery , where the initial token set need not be feasible and feasibility is required only at the end of the sequence. We refer to Section 7 for the precise definitions and the corresponding meta-theorem for Modulator Discovery .

Extending to regular path queries is not possible. The logic FO +subconn can be further extended by introducing a recursive scheme while keeping the fixed-parameter tractability property on every class of graphs excluding a minor; see Section 8.1. We investigate how far one can push this line of ideas. In database theory and graph querying, 

connectivity with regular constraints on the witnessing path is a central notion. It appears in regular path queries, conjunctive regular path queries, and their extensions with regular relations on tuples of paths [28, 66, 4, 63, 43, 90, 77]. One might therefore hope to strengthen FO +subconn by requiring the connecting paths to satisfy simple regular constraints. We show that already with two colors and very simple regular constraints, the corresponding extension has, on monotone classes, bounded tree-width as its exact dependence frontier. The hardness direction additionally requires that the relevant grid-minor encodings, including their minor models, can be constructed efficiently.

The proof of this derivation as well as the proof of Theorem 5.3 will be the subject of Section 5. We now give an outline of the proof of Theorem 5.3. Our proof is organized around transductions . Informally, a transduction is a uniform logical transformation between classes of structures. It may take a bounded number of copies of the input, add finitely many unary colors and then define the universe and relations of the output by formulas. Transductions therefore allow us to encode the desired structures inside a better-behaved auxiliary class. 8Two preservation results are central. First, on classes of linearly ordered binary structures, monadic dependence is equivalent to bounded twin-width. Second, bounded twin-width is preserved under fixed transductions, with a computable change in the bound. We therefore do not prove bounded twin-width directly for every desired tree-ordered expansion. Instead, we construct an auxiliary linearly ordered class that is monadically dependent, and hence has bounded twin-width, and recover the desired structures from it by a fixed transduction. Fix t ∈ N, and let Ht be the class of connected graphs with Hadwiger number at most t. For every graph G ∈ Ht and every rooted spanning tree Y of G, we construct an auxiliary graph H,together with a rooted spanning tree YH and a linear order <, and we write the resulting tree- and linearly ordered structure as (H, ⪯YH , < H ). The construction is designed so that the class 

Mt = {(H, ⪯YH , < H ) | G ∈ Ht, Y is a rooted spanning tree of G}

is monadically dependent. At the same time, (H, ⪯YH , < H ) is constructed so that it contains enough information to recover, by one fixed transduction, the original graph G together with the spanning-tree order defined by Y and a linear order <G. We denote this expansion by (G, ⪯Y , < G).It follows qualitatively that Mt has bounded twin-width, because it is a linearly ordered monadi-cally dependent class of binary structures. Since the class of the desired structures (G, ⪯Y , < G) is obtained from Mt by a fixed transduction, preservation of twin-width under transductions then gives a qualitative bound for the desired class as well. To obtain the computable bound required by the algorithmic theorem, we additionally use the effective quantitative content of the tree-ordered weakly sparse characterization: the auxiliary spanning trees have maximum degree 3, and the graph reducts of all their tree-ordered minors exclude a biclique whose order is computable from t. This yields a computable twin-width bound for Mt. The constructive linearization and recovery transductions then preserve computability of the final bound. In Phase I, starting from the pair (G, Y ), we construct the auxiliary linearly ordered tree-ordered structure (H, ⪯YH , < H )

and prove that the class Mt of obtained structures forms a monadically dependent class. 2.2. Sketch of the proof of Theorem 2.1 

Let us sketch how we prove Theorem 2.1. We first give an informal introduction to tree decompositions and the structure theorem of Robertson and Seymour for graphs excluding a fixed graph as a minor, on which the proof of the theorem is based. Very roughly, a tree decomposition represents a graph by arranging overlapping pieces in the shape of a tree. These pieces are called bags . The bags cover the graph: every vertex occurs in a bag, and every edge has both endpoints together in some bag. Moreover, the bags containing a fixed vertex induce a connected subtree of the decomposition tree. Thus, a vertex may occur in several bags, but those bags form one contiguous region. If the decomposition tree is rooted, every non-root bag has a parent. For a bag x, its intersection with the parent bag is the adhesion of x. The vertices in x but not in its adhesion form the margin 

of x. Intuitively, the margin is the new part contributed by the bag, while the adhesion is the part shared with its parent. These overlaps are separators that control how the local pieces interact. The Robertson-Seymour graph minor structure theorem states, informally, that every graph excluding a fixed minor has a tree decomposition of bounded adhesion whose pieces are almost embeddable in a surface of bounded Euler genus. Up to deleting a bounded number of exceptional vertices, called apices , and handling a bounded number of controlled local complications, called 

vortices , each piece behaves like a graph drawn on a surface. We begin with a connected graph G ∈ Ht. 4. Rearranging tree orders 

We present two useful general transductions allowing to rearrange tree orders. 

4.1. Rewiring a tree order 

We introduce a small transduction that will be used several times below to modify a tree order locally. The intuitive operation is the following. We mark some vertices as roots of subtrees that should no longer stay attached to their old parents. In each relevant part of the tree, we also mark one attachment vertex. The operation then cuts every marked root from its old parent and attaches it as a new child of the corresponding attachment vertex. Let X = ( X, ⪯) be a tree-ordered set. We use the unary marks S, A, Rold with the following intended meaning. The vertices marked by S are called stop vertices . They determine the parts of the tree in which rewiring is performed. Formally, we require that S is an antichain. For s ∈ S, we write Us := {x ∈ X : s ⪯ x}. Note that the sets Us are pairwise-disjoint. We call them the universes 

of the rewiring. The vertices marked by A are called attachment vertices . We require that every universe Us

contains exactly one vertex marked by A. We denote this vertex by as.The vertices marked by Rold are the old roots of the pieces that will be moved. We require that every r ∈ Rold belongs to a unique universe Us and that ¬(r ⪯ as). In particular, r̸ = as, the vertex r is not a root of the original tree, and as does not belong to the piece rooted at r. Thus, deleting the cover edge from the parent of r to r and adding the edge asr is well defined and creates no cycle. The rewired tree is obtained from the cover tree of ⪯ as follows. For each r ∈ Rold ∩ Us, delete the edge between r and its old parent and add the edge between as and r. All other cover edges are kept. Note that the vertices marked by Rold need not form an antichain. If two marked vertices lie on the same root-to-leaf path, then both are cut from their old parents and both are attached separately below the same attachment vertex. Thus, the lower marked vertex is no longer considered part of the piece moved with the higher marked vertex. A tree-ordered set obtained in this way from X is called a rewiring of X.23 s1

7.1. Reconfiguration variants and solution discovery 

Our algorithm for the ψ-Modulator-Reconfiguration problem (Theorem 7.1) reduces the problem to model checking a FO +subconn formula. This approach is highly flexible and shows the power of algorithmic meta-theorems: with simple modifications to the constructed formula, we can easily adapt the algorithm to other variations of the reconfiguration framework. A common variation is to change the rules for how one token set Si can be transformed to the next set Si+1 . Popular models include • the token sliding model, where in each step a token is moved along a single edge [70], • the token jumping model, where in each step a token moves to an arbitrary vertex [70], • the token addition and removal model, where in each step either a token is added to an arbitrary vertex, or an existing token is removed [70], and • the token sliding along a path 4 model, where in each step a token moves along an arbitrarily long path of unoccupied vertices [22, 24]. We have given the proof of Theorem 7.1 for the token sliding model, but it can be easily adapted to the other models. Especially the last model fits FO +subconn perfectly. Another emerging variant of the reconfiguration framework is the solution discovery framework, which was recently introduced in [41] and further studied in [16, 53, 54, 76, 89]. Here S is viewed as a tentative solution that may fail to satisfy the target property and should be transformed into an a priori unknown solution T . Dealing with RPQs not expressible in the guarded fragment of the logic. There is no known Guarded -FO +subconn formula expressing that a set is bipartite, or a path to be of even length, and these properties are likely not expressible, similarly to FO +conn [81, Theorem 3.12]. However, we can always use the following technique. First compute in linear time a bounded amount of unary 54 (or 0-ary) predicates, second use Theorem 8.1 on the graph equipped with these new predicates. We now showcase this reasoning on the parity-restricted endpoint relation without vertex deletions, and show that it is still tractable. Indeed, given the admissible-edge graph, mark by a fresh unary predicate N all vertices lying in non-bipartite connected components, and choose one bipartition class in every bipartite connected component and mark one side by a fresh unary predicate B. Then the existence of an even-length admissible-edge walk is expressed by 

Even Z (x, y ) := subconn (x, y ) ∧  N (x) ∨ (B(x) ↔ B(y)) .

Then the following are equivalent: (1) C excludes some graph as a topological minor; (2) C is monadically dependent (for FO +conn ); (3) C is dependent (for FO +conn ). Moreover, any of these conditions imply that FO +conn model checking is FPT on C , while if C

is independent and admits efficient encoding a of graphs, then model checking on C is AW [∗]-hard.    

> aFor logics more expressive than first-order logic, independence alone need not rule out fixed-parameter tractable model checking, even on hereditary graph classes. For example, sufficiently long subdivisions can make the encoded graph small relative to the input, leaving enough time to evaluate a sentence by brute force on the encoded instance. Such phenomena occur for monadic second-order logic [46, 61] and separator logic [73]. To obtain hardness, we therefore impose an efficiency condition on the encoding. An efficient encoding of graphs
> consists of a polynomial-time construction that maps every finite graph to a monadic expansion of a structure in the class, from which a fixed simple interpretation in the logic recovers the input graph. The interpretation then gives an AW [⋆]-hardness reduction for model checking on these monadic expansions. Our hardness theorem uses a specific efficient minor-encoding hypothesis, stated below.

For (1) ⇒ (2) , graphs in C admit tree decompositions that can be encoded by rooted trees equipped with their ancestor order and auxiliary structures on sibling sets. For each fixed FO +conn -formula, Lemma 8.3 and Remark 7.1 of the full version of [73] provide such an encoding, with finitely many unary colors, on which the formula is equivalent to a plain first-order formula, preserving all assignments to its free variables. The auxiliary structures belong to a fixed bounded-expansion class and are therefore monadically dependent. More generally, trees augmented in this way with structures from any fixed monadically dependent class are monadically dependent. The counting argument follows the same principle as the tree-automata argument of Paszke and Pilipczuk [71, Section 3], who bound the VC density of definable set systems on trees and, through tree encodings, on graphs of bounded clique-width. We briefly sketch the argument using Theorem 7.1 of the full version of [73]. Every first-order formula on these augmented trees can be translated into an equivalent automaton, independently of any structural assumptions on the auxiliary structures. The automaton depends only on the formula, its transitions are specified by first-order formulas evaluated on the auxiliary structures colored by the states already computed at their vertices. By the standard one-object-variable criterion for NIP [84], it suffices to consider formulas ψ(x; ¯ y)

with x a single variable and ¯y an arbitrary tuple. Note that this criterion also applies to classes of finite structures. Fix such a formula, its automaton, and a nonempty finite parameter set A. The 

ψ-type of a vertex over A records precisely which tuples from A|¯y| make the automaton accept when that vertex is marked as x and the tuple is marked as ¯y. Thus, counting types amounts to counting the different acceptance patterns obtained by moving the x-mark. Consider the union of the paths from the root to A. Retaining the root and the vertices of A and suppressing all other vertices with only one child leaves O(|A|) vertices and connecting paths. Color the auxiliary structures by the states of the automaton run with no free-variable markers. Along each connecting path, the effect of the x-mark is described by one of finitely many transformations of automaton states. At a retained vertex, a parameter tuple changes the states of at most |¯y|

children. The interaction with the child containing the x-mark is therefore described by finitely many first-order formulas on the colored auxiliary structure. Monadic dependence bounds the number of resulting patterns over the children leading to A by O(|A|d), where d depends only on the formula 63 and the class of auxiliary structures. These local patterns determine the state passed towards the root and hence acceptance for every parameter tuple. Including the O(|A|) possibilities where x is itself a retained vertex and summing over all vertices and paths gives O(|A|d+1 ) possible ψ-types over A|¯y|.The argument allows arbitrary unary colors and therefore establishes monadic dependence of the augmented trees.
