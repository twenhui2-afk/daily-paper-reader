Abstract 

We study Max k-Weight CSP , where Boolean constraints carry nonnegative rational weights and the goal is to maximize the satisfied weight using at most k variables set to 1. Each constraint uses at most d pairwise distinct variables and a relation from a finite Boolean constraint language Γ. The framework includes Partial Vertex Cover , Densest 

k-Subgraph , bounded-frequency Maximum Coverage , and cardinality-constrained 

Max-SAT .We give a complete classification of the fixed finite Boolean constraint languages Γ of arity at most d for which this problem admits an efficient parameterized approximation scheme (EPAS) parameterized by k + d. Only nonempty relations that exclude the all-zero tuple affect the classification. In such a relation, a coordinate is a unit witness if the tuple with a single 1 in that coordinate is accepted, and a control otherwise. A relation is 

Direct if setting a selected control to 0, with all other coordinates unchanged, preserves satisfaction. It is Rooted if every satisfying tuple has a selected unit witness such that keeping this witness, setting all other unit witnesses to 0, and setting any subset of the selected controls to 0 preserves satisfaction. If all the relations are Direct, or all are Rooted, we give a deterministic (1 − ε)-approximation for every rational ε ∈ (0 , 1) in time 2 O(d+k log(1+ dk/ε )) ℓO(1) in , where ℓin is the total input length. The same algorithms work for every value of d and give an EPAS with parameter k + d, provided that relation membership can be tested in polynomial time. If neither condition holds, no EPAS exists unless FPT = W[1], even for unweighted instances where no two constraints involve the same set of variables. 

# 1 Introduction 

We study Boolean constraint satisfaction problems (CSPs). An instance consists of a finite set 

X of variables, each taking a value in {0, 1}, and a finite collection C of constraints. Let d

be an upper bound on all constraint arities. A constraint C of arity r ≤ d is specified by a tuple ( x1, . . . , x r) of variables and a relation RC ⊆ { 0, 1}r. We call the positions 1 , . . . , r the coordinates of the relation and of the constraint. An assignment τ : X → { 0, 1} satisfies C

if ( τ (x1), . . . , τ (xr)) ∈ RC . We write 0r and 1r for the all-zero and all-one tuples in {0, 1}r,omitting the subscript when the arity is clear. Throughout this paper, the variables x1, . . . , x r

of every constraint C are pairwise distinct. This assumption affects the classification; see Remark 2.3. We write sc( C) := {x1, . . . , x r} for the set of variables of C and call it the 

underlying scope set of C; thus |sc( C)| = r. A Boolean constraint language Γ is a finite set of relations, and an instance is over Γ if RC ∈ Γ for every C ∈ C .The input to Max k-Weight CSP is a CSP instance ( X, C) together with a nonnegative rational weight w(C) for every constraint C ∈ C and a nonnegative integer budget k. The 1arXiv:2610.39751v1 [cs.DS] 29 Oct 2026 Hamming weight wt( τ ) := |τ −1(1) | of an assignment τ is the number of variables it sets to 1. The goal is to find an assignment τ with wt( τ ) ≤ k that maximizes the total weight of the constraints it satisfies. The unweighted case has w(C) = 1 for every C ∈ C . For a constraint language Γ, Max k-Weight CSP (Γ) is the restriction to instances over Γ. For an instance, let n := |X| and m := |C| . All accuracy parameters are rational. Let ℓin 

be the total number of bits used to encode the input, including the weights, budget, accuracy parameters when present, and any relation descriptions supplied as part of the input. All running times count bit operations. An efficient parameterized approximation scheme (EPAS ) for Max k-Weight CSP (Γ), for a fixed Γ, parameterized by k, is an algorithm that, given an instance and ε ∈ (0 , 1), returns an assignment τ with wt( τ ) ≤ k of value at least (1 − ε) times the optimum, in time 

f (k, ε )ℓO(1) in for a computable function f . When d varies, an EPAS parameterized by k + d uses one algorithm running in time f (k, d, ε )ℓO(1) in .

Max k-Weight CSP contains Partial Vertex Cover [19,23], Maximum Coverage [1, 29, 30], cardinality-constrained Max-SAT [16, 21], and Max Cut with at most k vertices on one side [2] as special cases (Section 1.2). Earlier work also gives approximation schemes for several of these problems through common frameworks [14–16, 18]. Can the parameterized approximability of these problems be determined uniformly by the permitted relations alone? More precisely, for every d ≥ 1, for which Boolean constraint languages Γ of arity at most d

does Max k-Weight CSP (Γ) admit an EPAS ? Theorem 1.1 gives a complete classification. It also shows that two languages can each admit an EPAS while their union admits none. 

1.1 Our results 

Fix d ≥ 1 and a finite Boolean constraint language Γ whose relations have arity at most d.Throughout, d denotes this global arity bound, while r denotes the arity of an individual relation. Only the nonempty relations that exclude the all-zero tuple affect the classification. A relation R ⊆ { 0, 1}r is zero-valid if 0 ∈ R and zero-free otherwise. Let Γ+ := {R ∈ Γ : R̸ = ∅, 0 /∈ R}.

Constraints with an empty relation are never satisfied and can be discarded. The all-zero assignment satisfies every constraint whose relation contains 0, although selecting variables may later falsify such constraints. The zero-valid lifting argument handles this possible loss. The dichotomy therefore depends only on Γ +.Fix R ∈ Γ+, and let r ≤ d be its arity. Let ei be the tuple whose only 1 is in coordinate 

i. Coordinate i is a unit witness if ei ∈ R and a control otherwise. The classification is determined by two repair rules , that is, two ways of deleting 1s from a satisfying tuple. • R is Direct if, for every α ∈ R and every control coordinate i with αi = 1, setting αi

to 0 while leaving all other coordinates unchanged produces another tuple in R.• R is Rooted if every α ∈ R has a unit-witness coordinate u with αu = 1 for which the following operation preserves satisfaction. First keep u at 1, set every other unit-witness coordinate to 0, and leave all controls unchanged. From this modified tuple, set any subset of its 1-valued controls to 0. Every tuple obtained in this way must belong to R.Both rules can also be described by what they exclude. A control coordinate c is helpful if some β / ∈ R with βc = 0 satisfies β + ec ∈ R. A pinned conjunction consists of disjoint sets 

A, T ⊆ [r], where |A| ≥ 2 and T contains only controls: after fixing the coordinates in T to 1 and those outside A ∪ T to 0, a tuple is accepted exactly when every coordinate in A is 1. The set T may be empty. Then R is Direct exactly when it has no helpful control, and Rooted 

2exactly when it has no pinned conjunction (Lemma 7.3). Thus the hard case occurs when Γ +

contains both obstructions, possibly in different relations. In the hardness part of the following theorem, an instance has multiplicity one if no two of its constraints have the same underlying scope set. 

Theorem 1.1 (Fixed-arity dichotomy) . Let d ≥ 1, and let Γ be a fixed finite Boolean constraint language whose relations have arity at most d. The following statements hold. 1. If every relation in Γ+ is Direct , then Max k-Weight CSP (Γ) admits a deterministic 

EPAS that, for every ε ∈ (0 , 1) , runs in time 

2O(d+k log(1+ dk/ε )) ℓO(1) in .

2. If every relation in Γ+ is Rooted , then Max k-Weight CSP (Γ) admits a deterministic 

EPAS that, for every ε ∈ (0 , 1) , runs in time 

2O(k log(1+ dk/ε )) ℓO(1) in .

3. If neither of the preceding conditions on Γ+ holds, then Max k-Weight CSP (Γ) admits no EPAS unless FPT = W[1], even on unweighted multiplicity-one instances. Remark 1.2 . The deterministic algorithms in Theorem 1.1 also apply when relation descriptions are supplied as part of the input and the arity bound d varies. Assume that membership in each relation can be tested in time polynomial in ℓin , with a fixed exponent for all inputs. If every relation in Γ + is Direct , or every relation in Γ + is Rooted , the corresponding algorithm satisfies the running-time bound in the theorem. This gives an EPAS parameterized by k + d. The algorithm assumes the corresponding condition on Γ +; the time needed to check that condition is not included. The two rules capture two ways in which control coordinates are redundant for satisfaction. In a Direct relation, a 1-valued control can be set to 0 while every other coordinate, including every unit witness currently set to 1, remains unchanged. Since R is zero-free, every satisfying tuple must set some unit witness to 1; otherwise, repeatedly deleting its 1-valued controls would produce 0 ∈ R. In a Rooted relation, the definition explicitly chooses a unit witness set to 1. It keeps this witness, removes all competing unit witnesses, and then permits any subset of the remaining 1-valued controls to be deleted. Call a relation R ∈ Γ+ accessible if every tuple in R has a 1 in some unit-witness coordinate, and inaccessible otherwise. Thus every Direct relation and every Rooted relation is accessible. Neither rule implies the other, and the EPAS side requires the same rule for all relations in Γ+. The relation

It is Direct because (1 , 1, 1) is its only tuple with β3 = 1, and setting β3 to 0 gives (1 , 1, 0) ∈ Rdir . 1.2 Problems covered by the framework 

We briefly survey several special cases of our framework and the known approximation results for these problems. In the problems below, k bounds the number of selected vertices, sets, or true variables. All our EPAS consequences use the Rooted case of Theorem 1.1 and its uniform version: they are deterministic, allow nonnegative rational weights, and run in time (1 + dk/ε )O(k)ℓO(1) in , parameterized by k + d. The relations below have polynomial-time membership tests. For graphs, d = 2. 

Partial Vertex Cover. The goal is to select at most k vertices maximizing the weight of edges with a selected endpoint. Each vertex is a variable, and each edge gives ROR =

{(0 , 1) , (1 , 0) , (1 , 1) }. Both coordinates are unit witnesses, so the relation is both Direct and 

Rooted . Thus Theorem 1.1 recovers an EPAS for this problem. Marx gave an EPAS [23], and Manurangsi later obtained the faster bound (1 /ε )O(k) for the weighted version [19]. 

Maximum Coverage . Viewing each vertex as the set of its incident edges makes Partial Vertex Cover a coverage problem in which every element belongs to two sets. Allowing arbitrary set systems gives Maximum Coverage : select at most k sets maximizing the weight of covered elements. An element belonging to r sets gives the relation OR r := {β ∈{0, 1}r : |β| ≥ 1}. This relation is both Direct and Rooted , so frequency at most d gives an EPAS , recovering the unweighted result of Skowron and Faliszewski [30]. For the weighted problem, Sellier’s scheme gives the faster bound ( d/ε )O(k) [29]. Without a frequency bound, the polynomial-time (1 − 1/e )-approximation [27] is optimal unless P = NP [12]. Under Gap-ETH, for every fixed δ > 0, no (1 − 1/e + δ)-approximation runs in FPT time parameterized by k [5]; under randomized Gap-ETH, none runs even in time f (k)ℓo(k)in for any computable f [20]. 

Cardinality-constrained Max-SAT . The OR constraints above are clauses with only positive literals. Allowing negative literals gives cardinality-constrained Max-SAT : maximize the total weight of satisfied clauses with at most k variables set to 1. A clause with a negative literal gives a zero-valid relation, while a clause with only positive literals gives OR r. Thus, formulas with at most d variables per clause admit an EPAS .More generally, Jain et al. gave an EPAS for unweighted formulas whose variable-clause incidence graph is Kt,t -free for fixed t [16]. Faster randomized and deterministic schemes were subsequently obtained independently by Inamdar et al. and Manurangsi [15, 21]. 4Biclique-freeness can be further weakened to bounded semi-ladder index: Kundu et al. give deterministic schemes for weighted Maximum Coverage and cardinality-constrained Max-SAT in this setting [18]. More generally still, bounded VC-dimension suffices for Maximum Coverage [1] and unweighted cardinality-constrained Max-SAT [18]. For unrestricted formulas, a polynomial-time (1 − 1/e )-approximation is known [31], and the coverage lower bounds above also apply. 

Balanced Set Cover. One can also reward leaving some elements uncovered. In a cardinality-constrained, weighted version of Balanced Set Cover [13, Definition 4.6], select at most 

k sets maximizing covered blue weight plus uncovered red weight. Blue elements give OR constraints, and a red element in r sets gives the zero-valid relation {0r}. Thus frequency at most d gives an EPAS .

Maximum Unique Coverage. Changing the coverage rule to reward only elements contained in exactly one selected set gives Max Unique Coverage [8, 25]. Each element gives EO r := {β ∈ { 0, 1}r : |β| = 1 }. All coordinates are unit witnesses, so these relations are both 

Direct and Rooted . Frequency at most d therefore gives an EPAS . For unweighted instances, the scheme of Cervenjak et al. [4] gives ( d log( d + 1) /ε )O(k) time by enumerating subsets of its approximate kernel. 

Graph and hypergraph Max Cut. For a graph G = ( V, E ) and S ⊆ V , an edge crosses the cut ( S, V \ S) if and only if it has exactly one endpoint in S. Thus selecting at most k vertices to maximize the total weight of crossing edges gives the cardinality-constrained version of 

Max Cut [25], with each edge represented by RXOR := EO 2 = {(0 , 1) , (1 , 0) }. For unweighted graphs with the requirement |S| = k, Bonnet et al. gave an EPAS [2], and Fomin et al. later improved the running time to (1 /ε )O(k) [14]. These schemes also apply to the version with 

|S| ≤ k: after adding k isolated vertices, any set of at most k original vertices can be extended to a set of exactly k vertices without changing the cut value. Conversely, removing the added vertices from a solution preserves its cut value. In a hypergraph with vertex set V and S ⊆ V , a hyperedge crosses ( S, V \ S) if and only if it contains a vertex of S and a vertex of V \ S. A hyperedge of size r ≥ 2 is therefore represented by NAE r := {β ∈ { 0, 1}r : 1 ≤ | β| < r }. Every coordinate is a unit witness, so each NAE r is both Direct and Rooted . By Theorem 1.1, weighted hypergraph Max Cut with at most k vertices on one side and hyperedges of size at most d admits an EPAS 

parameterized by k + d.

Threshold coverage. Raising the coverage requirement from one selected set to at least t

selected sets gives threshold coverage. An element in r sets gives the relation TH t,r := {β ∈{0, 1}r : |β| ≥ t}. For 2 ≤ t ≤ r ≤ d, this relation has no unit witness and is inaccessible. Hence threshold coverage with frequency at most d and any fixed threshold 2 ≤ t ≤ d admits no EPAS unless FPT = W[1]. 

1.3 Related CSP classifications 

Several earlier classifications of Boolean CSPs concern different objectives. Creignou [6] classified the polynomial-time approximability of Max-CSP . Khanna, Sudan, Trevisan, and Williamson [17] classified Min-Ones , Max-Ones , and Min-CSP . Max-CSP maximizes the weight of satisfied constraints without limiting the number of ones. Min-Ones minimizes the number of ones while satisfying every constraint. Schaefer’s satisfiability classification [28] and later classifications with cardinality constraints [7] also require every constraint to be satisfied. Our problem combines the Max-CSP objective with a budget of at most k ones, allowing some constraints to remain unsatisfied. Bonnet, Egri, Lin, and Marx [11] gave a parameterized approximation classification for Min-CSP . They determined which finite Boolean languages admit a constant-factor approximation in fixed-parameter time. Min-CSP minimizes the number of unsatisfied constraints, and its 5parameter bounds that number. Here, the parameter instead bounds the number of ones. The approximation guarantee also differs: they study constant-factor approximation, while we seek an EPAS , which allows arbitrarily small error. Their classification therefore does not determine which languages admit a scheme for our problem. The distinction between exactly k ones and at most k ones is also important. Marx [22] showed that satisfying all constraints with exactly k ones is either fixed-parameter tractable or W[1]-complete, depending on the Boolean language. Bulatov and Marx [3] studied related questions over finite domains. Under our upper bound of k ones, however, satisfying all constraints is fixed-parameter tractable for every fixed arity [22, Section 11, p. 181]. Our classification addresses the remaining optimization question: which languages admit an EPAS 

for maximizing the satisfied weight when not every constraint can be satisfied within the budget?

Section 4 develops the classification of zero-free relations and the common ingredients for the algorithms. Sections 5 and 6 give the Rooted and Direct algorithms, respectively. Section 7 proves hardness. Section 8 completes the classification and proves the arity-two boundary. Section 9 concludes with open questions. 

# 2 Notation and Preliminaries 

Throughout this paper, X denotes a finite set of Boolean variables. 

Assignments and Hamming weight. A truth assignment (or simply an assignment) is a function τ : X → { 0, 1}. The Hamming weight of an assignment τ , denoted wt( τ ) := |τ −1(1) |,is the number of variables set to 1. We denote the all-zero assignment by 0. For a subset of variables S ⊆ X, its indicator assignment is denoted by τS , where τS (x) = 1 if x ∈ S and 0 otherwise. A partial assignment is a function ρ : Y → { 0, 1} for some Y ⊆ X. If ρ1 : Y1 → { 0, 1} and 

ρ2 : Y2 → { 0, 1} are partial assignments with Y1 ∩ Y2 = ∅, then ρ1 ⊔ ρ2 : Y1 ∪ Y2 → { 0, 1} is the partial assignment that agrees with ρ1 on Y1 and with ρ2 on Y2.

Definition 2.1 (Boolean constraints and constraint languages) . For a positive integer r, let [r] := {1, . . . , r }. A Boolean relation of arity r is a set R ⊆ { 0, 1}r, and a Boolean constraint language Γ is a finite set of Boolean relations. A constraint C over X is specified by a relation RC ⊆ { 0, 1}rC and an ordered tuple (x1, . . . , x rC ) of pairwise distinct variables from X. This tuple is the scope tuple of C, and sc( C) := {x1, . . . , x rC } is its underlying scope set . The same relation and scope tuple may occur more than once; each occurrence is treated as a separate constraint. For an assignment τ , write 

τ [C] := ( τ (x1), . . . , τ (xrC )) .

C of Γ-constraints over X, whether there is an assignment satisfying every constraint. We instead maximize the weight of the satisfied constraints subject to a Hamming-weight budget.

Feasible completions and residual instances. Let I = ( X, C, w, k ) be an instance and let ρ : H → { 0, 1} be a partial assignment with |ρ−1(1) | ≤ k. A feasible completion of ρ is an assignment σ : X \ H → { 0, 1} that selects at most k − | ρ−1(1) | variables. Together, ρ and σ

give the feasible assignment ρ ⊔ σ to the original instance, with value F I (ρ ⊔ σ). The residual instance under ρ is obtained by substituting the values prescribed by ρ into every constraint and keeping the remaining variables in their original coordinate order. The remaining budget is k − | ρ−1(1) |. Constraints that become always unsatisfied are discarded. The weights of constraints that become always satisfied are kept as a constant contribution to the objective. The remaining constraints keep their original weights. The resulting relations need not belong to Γ. An algorithm can also require its output to extend ρ while keeping the original constraints unchanged. Our algorithms for zero-free constraints use this form, because substituting fixed values need not preserve zero-freeness or the repair rules.

# 3 Technical Overview 

We explain the proof of Theorem 1.1 in four parts: the treatment of zero-valid constraints, the 

Rooted algorithm, the Direct algorithm, and the hardness reduction. The full proofs are in Sections 4–8. Selecting a variable means setting it to 1; all other variables are set to 0. For 

S ⊆ X, write τS for the assignment that selects exactly S, as in Section 2. Throughout the overview, OPT is the optimum of the original instance. Since weights are nonnegative, the value of any feasible assignment on just the zero-free constraints is also at most OPT. 

Zero-valid lifting. A zero-valid constraint accepts the all-zero assignment; a zero-free constraint rejects it. Our treatment of zero-valid constraints adapts Manurangsi’s degree-threshold idea for clauses with negative literals [21]. We fix the variables that can affect a large weight of these constraints and bound the loss caused by the others. If k = 0, return the all-zero assignment. Otherwise fix ξ ∈ (0 , 1), eventually chosen as ε/ 2. Let w0 be the total weight of zero-valid constraints, and let D0(v) be the total weight of those containing v. The all-zero assignment shows that w0 ≤ OPT. Call v heavy 

if D0(v) > ξw 0/(2 k), and let H contain these variables. Each constraint contains at most 

d variables, so ∑

D0(v) ≤ dw 0. If H is nonempty, adding the defining inequalities for all heavy variables gives |H|ξw 0/(2 k) < ∑

D0(v) ≤ dw 0. Dividing by ξw 0/(2 k) > 0 gives

For each ρ, run the appropriate zero-free algorithm to obtain a feasible completion σ on X \ H. Evaluate the combined assignment ρ ⊔ σ on all original constraints. There are at most ( |H| + 1) k guesses, since each is determined by at most k selected variables. Keep the best answer. The initial fixing imposes requirements on the returned assignment; it does not substitute values into the Boolean relations, which could destroy their repair properties. Consider the guess agreeing with an optimal solution. That solution and the returned assignment agree on H and each select at most k variables. Any constraint whose satisfaction 8changes contains a variable on which the two assignments differ. Since they agree on H, every such variable is nonheavy. Moving from the optimal assignment to the returned assignment can change at most k variables from 1 to 0 and at most k variables from 0 to 1. Thus at most 2 k

variables change. Each belongs to zero-valid constraints of total weight at most ξw 0/(2 k), so the loss is at most 2 k · ξw 0/(2 k) = ξw 0 ≤ ξOPT. The Rooted case. The Rooted algorithm builds on the branching and exchange ideas of Jain et al. [16]. The scores mK and the bounds on the loss from adding variables extend these ideas to general Rooted relations, where adding a variable can destroy satisfaction. Assume every nonempty zero-free relation is Rooted . For a constraint C, let UC contain its unit-witness variables: selecting any one of them alone satisfies C. Let NC contain its remaining variables, called controls. These roles depend on C. α − ec ∈ R. There are at most r such tests per tuple, giving O(r2r) queries. For Rooted , for each α ∈ R, try every unit-witness coordinate u with αu = 1. For each such u and every B ⊆ supp( α) consisting only of control coordinates, query the tuple whose support is {u} ∪ B. The rule holds exactly when every α ∈ R has a choice of u for which all these queries succeed. There are at most r choices of u and 2 r subsets B per tuple, giving 

O(r4r) queries. Summing over Γ gives O(|Γ| d 4d) queries. For fixed Γ and d, this bound is constant.

7.2 A fixed constraint family with a switch 

We now consider the remaining case, where every nonempty zero-free relation in Γ is accessible. We first examine a relation that fails Rooted to identify a requirement we can use in the reduction. The next lemma shows that we can leave at least two coordinates free, prescribe a nonempty set of control coordinates as 1, and prescribe all other coordinates as 0. Among tuples with these prescribed values, a tuple belongs to the relation exactly when the entry in every free coordinate is 1. Here, the prescribed values specify which tuples of the relation we examine. In the reduction, every coordinate contains a Boolean variable, and every constraint uses a relation from Γ. We add constraints so that reaching the target score requires selecting the variables corresponding to coordinates prescribed as 1. The proof also considers assignments that select variables corresponding to coordinates prescribed as 0, and bounds the resulting score while accounting for their budget cost. 

Lemma 7.3 (A condition equivalent to Rooted ). Let R be a nonempty zero-free relation of arity r. Then R is Rooted if and only if it has no pinned conjunction. If R is accessible, this is equivalent to the following condition: for every set T ⊆ [r] of control coordinates and every 

A ⊆ [r] \ T , if R contains a tuple with support A ∪ T but no tuple with support A′ ∪ T for any 

A′ ⊊ A, then |A| = 1 .In particular, if R is accessible but not Rooted , there are disjoint sets A, T ⊆ [r], with 

|A| ≥ 2 and T a nonempty set of control coordinates, such that the following holds: when the entries in T are 1 and those outside A ∪ T are 0, a tuple belongs to R if and only if every entry in A is 1.Proof. Assume first that R is accessible. If R is Rooted , then for any sets A, T with the stated support property, its definition gives a unit-witness coordinate u ∈ A and a tuple in R

with support {u} ∪ T , so the condition on proper subsets forces A = {u}.Conversely, suppose the stated condition holds. Take any α ∈ R. Let W be the set of unit-witness coordinates in supp( α), and let N be the set of control coordinates in supp( α). Thus supp( α) = W ∪ N .48 Choose a set A ⊆ W of minimum size such that R contains a tuple with support A ∪ N .Such a set exists because α ∈ R. No proper subset of A has this property, so the assumed condition gives A = {u} for some u ∈ W .Let B ⊆ N be arbitrary. Choose a set A′ ⊆ { u} ∪ (N \ B) of minimum size such that 

R contains a tuple with support A′ ∪ B. Such a set exists because R contains a tuple with support {u} ∪ N . Again, no proper subset of A′ has this property, so the assumed condition gives |A′| = 1. If u / ∈ A′, every coordinate in A′ ∪ B would be a control coordinate, contrary to accessibility. Hence A′ = {u}.Thus, for every B ⊆ N , the relation R contains a tuple with support {u} ∪ B. The same unit-witness coordinate u therefore satisfies the requirement of Rooted for α. Since α was arbitrary, R is Rooted .Finally, suppose R is not Rooted . The condition in the lemma then fails, so there are a set T ⊆ [r] of control coordinates and a set A ⊆ [r] \ T with |A|̸ = 1 such that R contains a tuple with support A ∪ T , but no tuple with support A′ ∪ T for any A′ ⊊ A.By accessibility, the tuple with support A ∪ T has a 1 in a unit-witness coordinate u. Since 

T contains only control coordinates, u ∈ A. Thus A is nonempty, and |A|̸ = 1 gives |A| ≥ 2. If 

T = ∅, then eu ∈ R and supp( eu) = {u} ⊊ A, contradicting the condition on proper subsets. Therefore T is nonempty. Under these prescribed entries, every possible tuple has support 

A′ ∪ T for some A′ ⊆ A. The support condition therefore gives the stated equivalence. A pinned conjunction violates the condition on proper subsets. The preceding argument therefore proves that an accessible relation is Rooted if and only if it has no pinned conjunction. If R is inaccessible, choose a satisfying tuple whose support A consists only of controls and is minimal under inclusion. Since R is zero-free and every coordinate in A is a control, |A| ≥ 2. No tuple with support properly contained in A belongs to R. Hence A, together with T = ∅,is a pinned conjunction. Such an R is also not Rooted .We now use this requirement to build a fixed family of constraints. The following definition specifies its variables and the score bounds needed for the reduction.

7.5 The hardness theorem 

Theorem 7.6 (Unweighted multiplicity-one hardness) . Let Γ be a fixed finite Boolean constraint language of maximum arity d. Suppose Γ+ contains a relation that is not Direct and a relation that is not Rooted .Then Max k-Weight CSP (Γ) admits no EPAS on unweighted multiplicity-one instances unless FPT = W[1].Proof. If Γ + contains an inaccessible relation, apply Lemma 7.2. Otherwise, every relation in Γ + is accessible. Choose P, Q ∈ Γ+ such that P is not Direct 

and Q is not Rooted , and apply Lemma 7.5. Both reductions produce unweighted multiplicity-one instances satisfying (33). Their output budgets and targets are bounded by functions of the clique parameter k and the arity bound d. Since Γ is fixed, d is constant. Every feasible score is a nonnegative integer. Lemma 7.1 therefore excludes an EPAS unless 

FPT = W[1]. 

# 8 Completing the classification 

Proof of Theorem 1.1. If every relation in Γ + is Direct , Theorem 6.13 gives the claimed EPAS 

and running time. If every relation in Γ + is Rooted , Theorem 5.8 gives the claimed EPAS and running time. Both results use Lemma 4.5 to extend the corresponding zero-free algorithm to instances that also contain zero-valid constraints. The zero-free algorithms respect prescribed variable values, as required by that lemma. If both conditions hold, either algorithm applies. 59 If neither condition holds, Γ + contains a relation that is not Direct and a relation that is not Rooted . Theorem 7.6 therefore excludes an EPAS unless FPT = W[1], even on unweighted multiplicity-one instances. It remains to justify Remark 1.2. Both algorithms access the original relations only through membership tests. Testing the all-zero tuple identifies zero-valid relations. Testing the at most 

d unit tuples identifies the unit-witness coordinates. Under either sufficient condition on Γ +,Lemma 4.4 implies that a zero-free relation with no unit-witness coordinate is empty. Its constraints can therefore be discarded without enumerating satisfying tuples. The running-time proofs of Theorems 5.7 and 6.12 bound the number of membership tests and show that the intermediate rational numbers have polynomial bit length in ℓin .Thus polynomial-time membership tests, with a fixed exponent across all inputs, and exact arithmetic preserve the claimed running-time bounds. The proof of Lemma 4.5 establishes the same guarantee for the steps handling zero-valid constraints. This proves the remark. 

8.1 Relations of arity at most two 

Proposition 8.1. Every nonempty zero-free relation of arity at most two other than RAND =

{(1 , 1) } is both Direct and Rooted . The relation RAND satisfies neither rule. Proof. The only nonempty zero-free unary relation is {1}, which satisfies both rules. Let R be nonempty, zero-free, binary, and different from RAND . Every α ∈ R has a selected unit witness u: this is immediate for a unit tuple, and for α = (1 , 1) it follows because R

contains a unit tuple eu. Deleting a selected control gives eu, proving Direct . Keeping only u

among the unit witnesses and any subset of the selected controls gives either eu or α, proving 

Rooted . Finally, RAND has no unit witness and deleting a control from (1 , 1) gives a tuple outside the relation, so it satisfies neither rule. 

Proof of Corollary 1.3. If RAND /∈ Γ, Proposition 8.1 and the Rooted case of Theorem 1.1 with d = 2 give the stated deterministic EPAS and running time. If RAND ∈ Γ, it belongs to Γ + and satisfies neither rule, so the hardness case of the same theorem excludes an EPAS 

unless FPT = W[1]. 

# 9 Conclusion 

We give a complete classification of the fixed finite Boolean constraint languages of arity at most d that admit an EPAS for Max k-Weight CSP , parameterized by k + d, when variables within each constraint are distinct (Theorem 1.1). An interesting open question is whether the running time of these approximation schemes can be improved, particularly the dependence on k, d, and ε. Another natural open question is whether an analogous classification holds over larger finite domains, with a distinguished value 0 and a budget of at most k variables assigned a nonzero value.
