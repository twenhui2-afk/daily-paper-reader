# A continuous kernel method for affine Motzkin paths: boundary traces, height shifts, and secant-power hierarchies 

## Alexander Omelchenko 

Constructor University Bremen, Campus Ring 1, 28759 Bremen, Germany

## June 16, 2026 

Abstract 

We introduce a continuous analogue of the kernel method for boundary-interrupted affine tridiagonal production rules arising in weighted lattice paths and related models. In the classical kernel method, an unknown catalytic boundary series is eliminated by substituting an algebraic root of the kernel. Here affine height dependence turns the kernel into a differential kernel: the catalytic boundary trace is selected instead by following a characteristic to the boundary and imposing regularity there. This produces a first-kind Abel–Volterra equation and a re-construction formula for height-refined generating functions. For affine Motzkin triangles, the framework identifies the balanced case as the exact locality condition, explains integer imbal-ance through height shifts and finite operator compression, and yields closed shifted-Pearson collapses for arbitrary real boundary index, including the secant-power hierarchy interpolating Euler and higher-order Euler numbers. The same boundary index also appears naturally in Jacobi recurrence data and affine birth–death models, showing that the theory is intrinsically continuous rather than purely integral. 

Keywords: kernel method; catalytic variables; weighted Motzkin paths; boundary divided differences; Abel–Volterra equations; height shifts; Euler numbers 

# Introduction 

Many combinatorial and probabilistic models governed by tridiagonal production rules have a simple affine bulk rule which is interrupted at a boundary. In lattice-path language this boundary prevents paths from crossing below height 0; in Jacobi-matrix language it changes the first levels of the recurrence data; in birth–death language it forbids death from the boundary state. In all these cases the same catalytic obstruction appears: the generating function contains an unknown boundary trace. For algebraic lattice-path kernels, this trace is often eliminated by substituting a root of the kernel. Here the kernel is not algebraic. It is differential. The resulting cancellation condition is a first-kind Abel–Volterra equation for the boundary trace, together with a reconstruction formula for the full solution. The principal combinatorial source and test case is the affine weighted Motzkin triangle. Lattice paths are classical objects of enumerative combinatorics [5, 6, 7]. Motzkin paths start at height 0, use up-, level-, and down-steps, and never go below the horizontal axis. The corresponding triangle records paths by length and terminal height. Weighted versions of this triangle are central in the theory of continued fractions and orthogonal polynomials: through the Flajolet–Viennot correspondence, the bottom row is a moment sequence, while the full triangle refines that moment sequence by terminal height [1, 2, 3, 4].

These connections have different roles in the paper: affine Motzkin triangles provide the principal enumerative source, while the Jacobi and birth–death interpretations explain why the same boundary index is natural beyond integer multiplicities. First, in lattice-path enumeration, the kernel method and the theory of catalytic variables control boundary series by algebraic kernel cancellation [12, 13, 14, 15]. For walks in the quarter plane, the algebraic kernel leads to boundary-value problems [16]. In the present exponential-generating-function setting, affine height dependence turns the kernel into a differential operator, so there is no algebraic root to substitute. To the best of our knowledge, this gives the first instance in which a kernel-method problem of this type is solved by boundary-hitting characteristics and Abel–Volterra cancellation rather than by substitution of an algebraic kernel root. Fourth, as a more distant contextual parallel, boundary perturbations of tridiagonal data also occur in non-equilibrium statistical mechanics. At the analytic level, the closest comparison is the renewal equation obtained from the McKendrick– von Foerster transport equation [28, 29]. There too, characteristics lead to a Volterra equation for a boundary function. The last part of the paper records the boundary regime map. When S(0) > 0, regularity gives Abel–Volterra cancellation. When S(0) = 0, there is no singular mode and the boundary trace satisfies a second-kind Volterra equation by direct evaluation. When Q(0) = 0, the boundary is characteristic; the constant-weight Motzkin model is then solved by ballot numbers and Bessel functions. If Q has a positive zero, as in probability generating functions where x = 1 expresses mass conservation, the boundary flow covers only one characteristic component. The collapse axis α0 = A

crosses these regimes algebraically.
