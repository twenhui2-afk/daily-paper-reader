## 摘要
We prove that 用于 every fixed λ>0 与 all sufficiently large n，any z_1,\dots,z_n\in\C 结合 |z_j|\geq1 sat。

核心做法：Consequently，nth root 的 optimal maximum tends to 1，so no constant C>1 in Erdős 973 can exist。

主要结果：proof combines truncated exponential factorization 结合 overconvergence on open set outside unit disk。

值得关注的点在于：这篇文章的价值在于把《Exterior power sums》这个问题讲清楚。

## Abstract
We prove that for every fixed $λ>0$ and all sufficiently large $n$, any $z_1,\dots,z_n\in\C$ with $|z_j|\geq1$ satisfy $\max_{2\leq k\leq n+1}|\sum_j z_j^k|>e^{-λn}$. Consequently, the $n$th root of the optimal maximum tends to $1$, so no constant $C>1$ in Erdős 973 can exist. The proof combines a truncated exponential factorization with overconvergence on an open set outside the unit disk and a normal-family obstruction for Cauchy transforms.
