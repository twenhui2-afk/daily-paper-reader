Abstract 

Let G be a digraph with vertex set {1, 2, ..., n } and H1, H 2, ..., H n be n digraphs. The generalized join digraph −→

G = G[H1, H 2, ..., H n] is a digraph obtained from G by replacing each vertex i with Hi and for any u ∈ V (Hi) and v ∈ V (Hj ), ( u, v ) ∈ E(−→

G ) if and only if ( i, j ) ∈ E(G). In this paper we express the number of oriented spanning trees in −→

G in terms of Laplacian eigenvalues of H1, H 2, ..., H n and oriented spanning trees of 

G. Furthermore, we consider the number of oriented spanning trees with a fixed root in 

−→

G . First, we introduce the biclique-directed star transformation formula for counting oriented spanning trees with a fixed root in digraphs. Using it, we give the formula for the total number of oriented spanning trees with roots in a certain Hi (1 ≤ i ≤ n) of 

−→

G in terms of Laplacian eigenvalues of H1, H 2, ..., H n and oriented spanning trees of G.As applications, when each Hi is a given digraph, the enumerative formulas for oriented spanning trees with a fixed root of −→

G are derived from our work. 

Keywords: generalized join digraph; spanning tree; Laplacian matrix; biclique-directed star transformation
