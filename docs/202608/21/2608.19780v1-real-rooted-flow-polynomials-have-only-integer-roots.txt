# Real-rooted flow polynomials have only integer roots 

Meiqiao Zhang ∗1 and Fengming Dong †21School of Mathematical Sciences, Xiamen University, China

Abstract 

In this article, we show that for any bridgeless graph G, if its flow polynomial 

F (G, x ) has real zeros only, then G is the dual of a chordal plane graph and each zero of F (G, x ) is an integer in the set {1, 2, 3}.

# 1 Preliminaries 

All graphs considered in this paper are finite and undirected, and may have loops and parallel edges. For any graph G, let V (G) and E(G) be the vertex set and edge set of 

G, respectively. In 1912, Birkhoff introduced the chromatic polynomial as a tool to attack the Four-Color Conjecture [1] . For any graph G, the chromatic polynomial P (G, λ ) of G counts the number of proper λ-colorings of G for each positive integer λ. Thus, the Four-Color Conjecture is equivalent to the assertion that P (G, 4) > 0 for all planar graphs G. It is then well known, from the deletion-contraction formula, that this counting function is in fact a polynomial in λ with integer coefficients, hence the name. Over the years, the chromatic polynomial has become one of the fundamental graph polynomials and an important object of study, due to the close connections between its algebraic properties and the structural properties of the underlying graph. See [5, 7, 12, 13] for reference. In particular, the roots of P (G, λ ) are called the chromatic roots of G. Clearly, 0 is a chromatic root of every graph. Also, it can be easily verified that all chromatic roots of a chordal graph are nonnegative integers, where a graph is chordal if it contains no

Meanwhile, there exist non-chordal graphs whose chromatic roots are all integers [2, 6–8, 11], as well as non-planar graphs whose chromatic roots are all real but are not all integers [4]. Motivated by these observations on integral and real chromatic roots, it is natural to consider the following question, which remains widely open. 

Problem 1 ( [3]) . Is there a planar graph G that has real chromatic roots only and contains non-integral chromatic roots? 

Clearly, for Problem 1, it suffices to consider non-chordal planar graphs. On the other hand, the flow polynomial was introduced by Tutte [14] in 1950 as a natural counterpart of the chromatic polynomial. For any graph G, the flow polynomial 

F (G, λ ) of G counts the number of nowhere-zero Γ-flows on any orientation D of G,where Γ is an additive Abelian group of order λ, for each positive integer λ. It is well known that F (G, λ ) is also a polynomial in λ with integer coefficients, as can be seen directly from the following deletion-contraction formula [15]:

Problem 2 ( [3,4]) . Is there a planar graph G that has real flow roots only and contains non-integral flow roots?

Problem 3 ( [3, 4]) . Is there a graph G that has real flow roots only and contains non-integral flow roots? 

2Before introducing our main results, we first review some relevant developments concerning Problems 1, 2, and 3. Note that we restrict our attention to bridgeless graphs when considering flow polynomials as F (G, λ ) is trivially zero if G has a bridge. In 2011, Kung and Royle have characterized the graphs whose flow roots are all integers [10]. 

Theorem 4 ( [10]) . If G is a bridgeless graph, then its flow roots are integral if and only if G is the dual of a chordal and plane graph. 

Inspired by Theorem 4, it is natural to ask whether every graph whose flow roots are all real must also be the dual of a chordal plane graph [3]. Moreover, Dong extended Theorem 4 by determining all possible flow roots of graphs with only integral flow roots as follows [4]. 

Theorem 5 ( [4]) . Let G be a graph with real flow roots only. The following statements are equivalent: 

(i) G is the dual of some chordal and plane graph; 

(ii) each flow root of G is in the set {1, 2, 3};

(iii) G has no flow roots in the interval (1 , 2) .

In this paper, building on the aforementioned results, we give negative answers to Problems 1, 2, and 3. 

Theorem 6. Let G be a bridgeless graph. Then G has only real flow roots if and only if G has only integral flow roots if and only if G is the dual of a chordal and plane graph. Moreover, every flow root of such a graph belongs to {1, 2, 3}.

The following corollary is then direct. 

Corollary 7. Let G be a loopless planar graph. Then G has only real chromatic roots if and only if G has only integral chromatic roots if and only if G is chordal. Moreover, every chromatic root of such a graph belongs to {0, 1, 2, 3}.

Proof of Theorem 6. By Theorems 4 and 5, it suffices to show that if G has only real flow roots, then G has only integral flow roots. Suppose that G is a counterexample to the above statement with the minimum number of edges. Then G has only real flow roots and contains a non-integer flow root x. Let |V (G)| = n, |E(G)| = m, and 

k = |{ v ∈ V (G) : dG(v) > 3}| .

Claim 1. G is loopless. Proof . Assume that G contains a loop e. Then by Lemma 8 (i), G − e has only real flow roots and contains the non-integer flow root x with |E(G−e)| < |E(G)|, a contradiction to the assumption of G. Hence G is loopless. ♮

Claim 2. G is connected. Proof . Assume that G is disconnected with components G1, G 2, . . . , G c, where c ≥ 2and |E(Gi)| > 0 for all 1 ≤ i ≤ c. Then by Lemma 8 (ii), each Gi has only real flow roots and some Gi has the non-integer flow root x, where each Gi contains less edges than G, a contradiction to the assumption of G. Hence G is connected. ♮

Claim 3. G is nonseparable with n ≥ 2.Proof . If n = 1, then m = 0 due to Claim 1. As a result, F (G, λ ) = 1, a contradiction to the assumption of G. Thus n ≥ 2. By Claims 1 and 2, it remains to show that G

contains no cut-vertices. Assume that G contains cut-vertices, which implies that G has blocks G1, G 2, . . . , G b,where b ≥ 2 and |E(Gi)| > 0 for all 1 ≤ i ≤ b. Then by Lemma 8 (iii), each Gi has only real flow roots and some Gi has the non-integer flow root x, where each Gi contains less edges than G, a contradiction. Hence Claim 3 holds. ♮
