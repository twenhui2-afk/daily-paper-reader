## Abstract
In this article, we show that for any bridgeless graph $G$, if its flow polynomial $F(G,x)$ has real zeros only, then $G$ is the dual of a chordal plane graph and each zero of $F(G,x)$ is an integer in the set $\{1,2,3\}$.
