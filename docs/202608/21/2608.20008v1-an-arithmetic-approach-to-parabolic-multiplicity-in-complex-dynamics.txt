AN ARITHMETIC APPROACH TO PARABOLIC MULTIPLICITY IN COMPLEX DYNAMICS 

XAVIER BUFF, VALENTIN HUGUIN, AND LIZ VIVAS 

Abstract. When ω is a primitive n-th root of unity, the quadratic polynomial F (z) = ωz (1 −z) and the entire map F (z) = ωz e−z both have a parabolic fixed point at 0. Their parabolic multiplicity is equal to 1, that is, F ◦n(z) = z(1 + cz n + O(zn+1 )) with c̸ = 0. The classical proof of this fact is transcendental. We present an arithmetic proof which may be extracted from [BST] in the transcendental case and requires working in Z/(n − 1) Z, and which is new in the polynomial case and requires working in the 

p-adic field Qp for a suitable prime p such that the order of 2 in ( Z/p Z)× is exactly n.

1. Introduction 

Assume n ⩾ 1 is an integer and let ω ∈ C be a primitive n-th root of unity. Let F : C → C be an entire map fixing 0 with derivative ω. If F is not a rotation, then there exists an integer ν ⩾ 1, called the parabolic multiplicity of F at 0, such that 

F ◦n(z) = z(1 + cz νn + O(zνn +1 )) with c̸ = 0 .

The parabolic multiplicity ν is closely related to the number of singular values of F . A point z ∈ C

is a regular value of F if there exists an open neighborhood V of z in C such that the restriction 

F : F −1(V ) → V is a covering map. The point z is a singular value of F otherwise. Denote by Sing( F ) the set of singular values of F . For example: 

• if F (z) = ωz (1 − z), then Sing( F ) = { ω

• if F (z) = ωz e−z , then Sing( F ) = {0; ω 

> e

}.The following theorem goes back to Fatou in the polynomial case [F1, F2] (see also [M, §10] for a modern exposition) and extends readily to entire maps (see [Be] for example). 

Theorem 1.1. If ω is a root of unity and if F is an entire map, not a rotation, fixing 0 with multiplier 

ω and parabolic multiplicity ν, then 0 attracts the orbit of at least ν singular values of F .

Corollary 1.2. If ω is a root of unity and F (z) = ωz (1 − z), then the parabolic multiplicity of F at 

0 is equal to 1.

Corollary 1.3. If ω is a root of unity and F (z) = ωz e−z , then the parabolic multiplicity of F at 0 is equal to 1.

The classical proof of Theorem 1.1 is transcendental. In this paper, we present arithmetic proofs of these two corollaries.
