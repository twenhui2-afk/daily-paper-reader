Abstract 

Phylogenetic networks are graphs that represent the evolutionary history of species. Recently, the class of orchard phylogenetic networks, which can be reduced by so-called 

cherry-picking sequences , has gained attention for its computational and biological as-pects. In this paper, we study a fundamental question on orchards and their cherry-picking sequences by considering the CoveringNumber problem: given an orchard network N , how many cherry-picking sequences are needed to reduce all subnetworks of N ? We initiate this study by considering the problem for trees. We then show that the covering number can be computed for binary trees recursively using a similar but more fine-grained notion of survival covering number . We also give a recursive formula for the survival covering number of non-binary trees. However, computing the covering number for non-binary trees appears to be considerably more challenging. For this case, we show that the covering number of star trees (whose root is adjacent to all leaves) is equivalent to the so-called SubsetConnectivity problem, which we introduce in this paper. Finally, we show that if there is no restriction on the sequence length, a single sequence of minimum length `n

> 2

˘ suffices to reduce all subtrees of a tree on n leaves. 

# 1 Introduction 

Phylogenetic trees have been used to represent the evolutionary history of species since Darwin [3]. These trees can represent speciation events (one lineage splits into two or more lineages); however, they fail to capture the merging of lineages due to reticulation events such as hybridization and horizontal gene transfer [1]. To bridge this gap, a group of mathematicians, computer scientists, and biologists introduced phylogenetic networks (see e.g. [8]). 

Motivation. It is usually the case that biologists can only construct the trees for small stretches of DNA, but not the entire evolutionary history of genomes and species [16]. Therefore, the evolutionary history of genomes must be inferred by combining the trees of the DNA sequence. This naturally gives rise to the TreeContainment problem [13], which asks whether a phylogenetic tree is displayed by a phylogenetic network. TreeCon-tainment is known to be NP-hard in general [14], but it can be solved in polynomial-time for certain classes of networks [5, 6, 13]. For example, TreeContainment , among other techniques, can be solved in linear time for tree-child networks using recently developed cherry-picking techniques [13]. # 7 Discussion 

We summarize our main contributions and outline several questions that remain open. 

Summary of results. In this paper, we sought to answer the following question. ‘Given a phylogenetic tree T , what is its covering number – the minimum number of cherry-picking sequences of T needed to reduce all subtrees of T ?’. A key notion used for this computation was the survival covering number c1pT q of a tree T . This is a variant of the covering number 

cpT q that imposes, in addition to the covering condition, the requirement that every subtree of T be a surviving subtree with respect to some sequence in the covering set. For binary trees, we gave a recursive formula for c1pT q (Theorem 3.10 and Corollary 3.11) and used it to derive a recursive formula for the covering number cpT q (Theorem 3.1). In the proof, we also gave an explicit construction for building an optimal covering set of sequences from optimal covers of the subtrees rooted at the children. For non-binary trees T , the survival covering number c1pT q remains tractable. Theo-rem 4.6 gives a recursive formula in terms of the leaf and non-leaf children of the root. In particular, one can compute c1pT q using an appropriately chosen binary refinement of T

(Lemmas 4.3 and 4.4). This allows the binary result to be generalized to the non-binary setting. By contrast, the (non-survival) covering number cpT q of a non-binary tree T appears to be more difficult even for star trees. In Section 5, we showed that determining cpT ˚pnqq 

is equivalent to a new combinatorial problem called SubsetConnectivity (Theorem 5.1). For this problem, we showed that at most one additional tree is needed if we increase n by one, i.e., cpn ` 1q P t cpnq, c pnq ` 1u (Theorem 5.3). In the case that cpn ` 1q “ cpnq, we also showed that the solution to SubsetConnectivity pnq must not contain an undirected star graph (Theorem 5.2). Finally, in Section 6, we considered the version of CoveringNumber , where there is no restriction on the length of the sequence. We used a topological ordering of the cherry order graph GT (Observation 6.1) to show that the set of all non-trivial subtrees of a tree 

T on n leaves can be reduced by a single cherry-picking sequence of length exactly `n

> 2

˘.

Open problems. Our work suggests several natural directions for further study. The most immediate open problem is to determine the covering number of general non-binary trees, beyond the surviving variant. For this problem, we have only loose bounds for when the input is a star phylogenetic tree. In this setting, we have verified computationally confirmed that cpnq “ n ´ 2 whenever 4 ď n ď 7 by using an exact algorithm based on a set cover solver. We wonder if this equality holds for larger n, or if the behavior changes for certain values of n. Equivalently, we ask whether cpn ` 1q “ cpnq for some n ě 4. In another direction, it is natural to ask whether the covering number framework extends from trees to networks. CoveringNumber has two inputs – a network class and a family of subnetworks. in this paper, we considered trees and the set of all subtrees. For future research, one can consider a generalization of either or both inputs. 18 We consider changing the first input from trees to networks. This has partially been addressed in Section A, where we asked the question for orchard networks and their subtrees and for tree-child networks and their subtrees. If N is an orchard, there may not be a cherry-picking sequence of N which reduces a given subtree (Figure 1); if N is tree-child, there may not be a tree-child sequence of N which reduces a given subtree (Figure 2). For the former, it would be interesting to characterize orchard networks with finite covering number. For the latter, one can ask if, for every subtree of N , there exists a cherry-picking sequence of N which reduces it (since cherry-picking sequences are more general than tree-child sequences). The example given in Figure 2 is not a counterexample to this question, as the sequence p2, 3qp 5, 2qp 3, 2qp 4, 3qp 1, 2qp 2, 3q of N reduces T . Moreover, whenever the covering number for the network inputs is known to be finite, can we still compute it in polynomial time? One can also modify the second input – instead of the set of all subtrees, one can consider any family of subnetworks such as the set of all tree-child subnetworks or the set of all orchard subnetworks. Here, we restrict to tree-child or orchard subnetworks as otherwise such subnetworks need not be reducible by cherry-picking sequences. Finally, it would be of great interest to consider different combinations for the two inputs, to determine whether CoveringNumber remains tractable or becomes intractable for general choices of an input network and a family of subnetworks.
