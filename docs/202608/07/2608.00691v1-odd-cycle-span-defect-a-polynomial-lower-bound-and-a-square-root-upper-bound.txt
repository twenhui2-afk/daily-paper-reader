# Odd-Cycle Span Defect: A Polynomial Lower Bound and a Square-Root Upper Bound 

Shuyan Chen ∗

June 2026 

Abstract 

For a graph G, let 

ψ(G) = max {χ(G[V (C)]) : C is an odd cycle of G},

with ψ(G) = 0 when G is bipartite. For positive integers N , set 

F (N ) = max {χ(G) − ψ(G) : |V (G)| ≤ N }.

The function F measures the finite-order additive gap arising from an open problem of Erdős and Hajnal. We prove 

N 1/6−o(1) ≤ F (N ) < √6N . 

The lower bound raises the finite-order scale supplied by the Cameron–Clow path-colour construction from log N/ log log N to a fixed power of N . Its proof constructs a palette–code graph from a binary covering code C ⊆ { 0, 1}p and establishes the exact identities 

χ(G) = 2 p + ℓ − ρ(C), ψ(G) = 2 p. 

Near-middle Hamming coverings yield the exponent 1/6. The upper bound combines Polavarapu’s connectivity theorem, the Chvátal–Erdős Hamiltonicity theorem, and maximum-independent-set stripping. 

Keywords. odd-cycle span defect; chromatic number; covering code; Hamiltonian graph; highly connected subgraph. 

# 1 Introduction 

A problem of Erdős and Hajnal, recorded by Gyárfás [ 14 ], asks whether for every integer k ≥ 3

there is a number f (k) such that every graph G with χ(G) ≥ f (k) contains an odd cycle C with 

χ(G[V (C)]) ≥ k. 

The question belongs to the broader programme of χ-boundedness initiated by Gyárfás [ 13 ]; see Scott and Seymour [ 21 ] for a survey. It remains open and is listed as Problem 640 in Bloom’s catalogue of Erdős problems [4].
