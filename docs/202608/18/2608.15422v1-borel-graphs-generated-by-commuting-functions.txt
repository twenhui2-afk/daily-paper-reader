BOREL GRAPHS GENERATED BY COMMUTING FUNCTIONS 

SU GAO, XIANGXI HU, AND JIE ZOU 

Abstract. In this paper we study Borel graphs generated by finitely many commuting Borel functions. We give a geometric analysis of the free part of such graphs based on marker sets and marker regions. Assuming the existence of r-forward-independent hitting sets with bounded syndeticity, we obtain marker decompositions of the free part into rootless and rooted regions with controlled geometry. As applications, we derive finite Borel asymptotic dimension and hyperfiniteness, and obtain upper bounds for Borel edge chromatic numbers which improve previously known results. For the case in which each of the commuting Borel functions is bounded-to-one, we verify the existence of r-forward-independent hitting sets with syndeticity 

Cr for some constant C. This gives another proof of a recent theorem of Naryshkin–Shinko– Weilacher–Yu, and is used to show that if one of the commuting Borel functions is injective and another one is bounded-to-one and exactly even-to-one, then the graph has a Borel perfect matching. 

1. Introduction 

Descriptive combinatorics studies classical combinatorial problems under constraints of de-finability, with a particular focus on Borel graphs whose connectedness relations are countable Borel equivalence relations. A central theme in this study is to understand how additional structure in a Borel graph can be used to obtain Borel colorings, Borel edge colorings, Borel matchings, and hyperfiniteness. A natural class of Borel graphs consists of graphs generated by finitely many Borel functions. If X is a Polish space or a standard Borel space, and f1, . . . , f n : X → X are Borel unary functions, then the graph Gf1,...,f n is defined as ( X, R ), where 

{x, y } ∈ R ⇐⇒ x̸ = y and ∃1 ≤ i ≤ n [ fi(x) = y or fi(y) = x ].

A systematic study of such graphs started with the seminal paper by Kechris–Solecki–Todorcevic [KST99]. The following results about the Borel chromatic numbers were shown in [KST99]: 

• When n = 1, the Borel chromatic number of Gf is either 1 , 2, 3 or ℵ0;

• In general, if Gf1,...,f n has finite Borel chromatic number, then it is at most 3 n;

• If each f1, . . . , f n is ≤ k-to-1, then the Borel chromatic number of Gf1,...,f n is at most min {(k + 1) n + 1 , 3n}.

They asked if the last bound can be improved to 2 n + 1; this problem is still open. When the generating functions commute with each other, the resulting graph has additional structure and often better results can be proved than in the general noncommuting setting. For example, it was shown in [Pal12, MP21] that, if f1, . . . , f n are commuting functions with no fixed points, the Borel chromatic number of Gf1,...,f n is indeed at most 2 n+1 if it is finite. In contrast, for general noncommuting functions, a known bound not involving k is only 12 (n + 1)( n + 2) − 2. In this paper, we study Borel edge colorings, Borel matchings, and hyperfiniteness of Borel graphs generated by finitely many commuting Borel functions. A general result from [KST99] implies that, for any ≤ k-to-1 functions f1, . . . , f n (not necessarily commuting), the Borel edge chromatic number of Gf1,...,f n is at most 2 n(k + 1) − 1. In this section we collect several standard tools from descriptive combinatorics that will be used throughout the paper. 2.1. Basics in descriptive set theory. We begin with some standard terminology from de-scriptive set theory. A standard reference is [Kec95]. A topological space X is Polish if it is separable and completely metrizable. A standard Borel space is a measurable space ( X, B) such that B is the σ-algebra generated by some Polish topology on X, and sets in B are called Borel sets .A function on a standard Borel space is said to be a Borel function if the preimage of every Borel set is also Borel. Let X be a standard Borel space. A Borel function f : X → X is 

countable-to-one (respectively, finite-to-one ) if for each x ∈ X, f −1(x) is countable (respectively, finite). Moreover, a finite-to-one function f : X → X is bounded-to-one if there is N ∈ N+ such that |f −1(x)| ≤ N for all x ∈ X. We work with the following refinements of the notion of bounded-to-one functions. 

Definition 2.1. Let X be a standard Borel space, k ∈ N+, and let f : X → X. We say that f

is k-to-1 (or ≤ k-to-1 as in [KST99]) if |f −1(x)| ≤ k for every x ∈ X. We say that f is exactly 

k-to-1 if |f −1(x)| = k for every x ∈ X. We say that f is exactly even-to-one if |f −1(x)| is a finite even number for every x ∈ X.An equivalence relation E on a standard Borel space X is called a countable (respectively, 

finite ) Borel equivalence relation if E is a Borel subset of X × X and each equivalence class is countable (respectively, finite). A countable Borel equivalence relation is said to be hyperfinite 

if it can be written as an increasing union of finite Borel equivalence relations. BOREL GRAPHS GENERATED BY COMMUTING FUNCTIONS 5

2.3. Borel asymptotic dimension. We next recall the notion of Borel asymptotic dimension and several consequences that will be used later. Our formulation follows the framework of [CJM +23]. Let X be a standard Borel space. A function ρ : X ×X → [0 , +∞] is called an extended metric 

if ρ can take the value + ∞ but otherwise satisfies the defining properties of a metric. If ( X, ρ ) is a standard Borel space equipped with an extended metric, then the finite-distance equivalence relation is defined as Eρ = {(x, y ) ∈ X × X : ρ(x, y ) < +∞} . For any graph G = ( X, R ), we define the graph metric ρG on X by letting ρG(x, y ) be the length of the shortest path in G

from x to y. The graph metric ρG is an extended metric and the finite-distance equivalence relation EρG is exactly the connectedness relation of G. If G is a Borel graph, then ρG is a Borel extended metric on X.A Borel extended metric ρ on X is called proper if, for every x ∈ X and every r < ∞, the ball Bρ(x, r ) := {y ∈ X : ρ(x, y ) ≤ r} is finite. In particular, if G is a locally finite Borel graph, then its graph metric is a proper Borel extended metric.
