# A Characterization of Level-k Realizability for Clustering Systems 

# Shilong Dai 1 and Yangjing Long 1* 1School of Mathematics and Statistics, Central China Normal University, No. 152, Luoyu Road, Wuhan, Hubei, PR China. *Corresponding author(s). E-mail(s): yangjing@ccnu.edu.cn; Contributing authors: daishilong@mails.ccnu.edu.cn; 

Abstract 

Rooted phylogenetic networks model evolutionary histories in which tree-like descent is supplemented by reticulate events. A basic invariant of such a network is its hardwired clustering system, consisting of the descendant leaf sets of all vertices. We give a complete Hasse-diagram characterization of when a clustering system C on a finite taxa set X is the hardwired clustering system of a rooted level-k network. For each non-trivial block B of the Hasse diagram H[C], we introduce a parameter μ(B), defined as the minimum size of a generating set for all overlap-intersections in B. Our main theorem states that a level-k realization exists if and only if μ(B) ≤ k for every non-trivial block B. The necessity direction shows that overlap-intersections force proper hybrid vertices in any realizing block. The sufficiency direction is constructive: starting from the Hasse diagram, we iteratively split redundant hybrid vertices, preserving the hardwired clustering system while reducing each block to the required level. 

Keywords: phylogenetic network, clustering system, hardwired cluster, level-k network, Hasse diagram, reticulation

# 1 Introduction 

Rooted phylogenetic networks provide a way to represent evolutionary histories in which tree-like descent is supplemented by reticulate events such as hybridization, recombination, or horizontal transfer; see, for example, [ 2 , 3]. One basic object associated 1

> arXiv:2605.21945v1 [q-bio.MN] 21 May 2026

with a rooted network N is its hardwired clustering system CN , the family of all sets of descendant leaves of vertices of N . For rooted phylogenetic trees, the corresponding cluster hierarchy determines the tree uniquely [ 11 ]. For rooted networks, this uniqueness fails in general [ 4 ], but the hardwired cluster set still records substantial structural information. Bounded-level networks are a standard way to control the complexity of reticulation: the level bounds, block by block, how many hybrid vertices may occur in a single non-tree-like region. This gives a useful middle ground between trees and unrestricted networks. In this setting, a level bound formalizes the biological assumption that reticulate events are locally limited, even when the whole evolutionary history is not tree-like. Related algorithmic work controls reticulation complexity through decompositions or explicit constructions [ 9 , 10 ], and many bounded-level results start from explicit network encodings such as triplets, trees, or clusters [ 6– 8]. Hardwired cluster realizability is subtler than the corresponding tree case, and also less direct than many triplet- or split-based settings: a hardwired cluster set records descendant leaf sets, but not the local ancestry by which those sets are produced. In particular, Hasse-hybrid vertices may be redundant, while overlap-intersections of clusters can force hybrid vertices in every realization. Several nearby lines of work address different aspects of this landscape. Cluster networks give a canonical way to summarize a set of clusters [ 5], but they are not intended as a criterion for whether the same cluster set has a realization of prescribed level. The constructions of van Iersel et al. focus on representing conflicting clusters with fewer reticulations [ 6], while Gambette and Huber study encodings of bounded-level networks [ 7]. These results show how bounded reticulation complexity can be represented or achieved by explicit constructions. They do not give a necessary-and-sufficient level-k cluster-realization test expressed solely in the Hasse diagram of an arbitrary clustering system. Results on regular networks and related network classes give uniqueness or reconstruction statements within restricted classes [ 12 – 14 ]; they likewise do not provide the block-wise hardwired level criterion considered here. This leads to the realizability problem considered in this paper: given a clustering system C on a finite taxa set X, when does there exist a rooted level-k network N

on X with CN = C? Our goal is to answer this question directly from the clustering system itself, without first constructing or guessing a realizing network. The Hasse diagram H[C] of a clustering system is a natural starting point for this problem. The closest predecessor of our work is the study of clustering systems of phylogenetic networks by Hellmuth, Schaller, and Stadler [ 1]. Their results show how structural properties of networks are reflected in the induced clustering systems, compare several well-studied classes of phylogenetic networks through their clusters, and provide block and overlap tools that we use. However, their results do not give a blockwise numerical invariant whose value is exactly the minimum level required for realizing a given clustering system. The parameter μ(B) introduced here fills this gap. More recently, Shanavas, Changat, Hellmuth, and Stadler studied the connections between clustering systems and unique least common ancestors in directed acyclic graphs, relating several classes of set systems to LCA-type properties [ 15 ]. Related devel-opments in the I-LCA framework further investigate how DAGs can be transformed 2while preserving relevant cluster/LCA structure [ 16 ]. These works are orthogonal to the present paper: they focus on LCA properties and induced set-system axioms, whereas we focus on exact hardwired realization under a level bound. Thus, although existing results provide important structural insight, they do not give, in the general setting considered here, a directly checkable block-wise criterion for when C is realizable by a rooted level-k network. In other words, one would like to replace the network-side condition “each non-trivial block has at most k proper hybrid vertices” by a condition that can be read directly from H[C]. The main contribution of this paper is a purely Hasse-theoretic criterion. For every non-trivial block B of H = H[C], we define a parameter μ(B) using generating sets for intersections of overlapping clusters inside B. Intuitively, μ(B) measures the minimum number of independent overlap-intersection regions that any realizing network block must encode. Our main theorem states that C is realizable by a rooted level-k network if and only if μ(B) ≤ k for every non-trivial block B of H[C]. Thus the obstruction to level-k realizability is purely Hasse-theoretic. The necessity direction shows that these overlap-intersection pieces force at least μ(B) proper hybrid vertices in any corresponding realizing block. The sufficiency direction is constructive: in contrast to the existence and correspondence results above, it gives an explicit procedure that transforms the Hasse diagram into a level-k realization without changing the hardwired clustering system. Figure 1 summarizes this route from the input clustering system to the level criterion. 

Proof strategy. 

The proof separates the two directions of the characterization. For necessity, we show that every overlap-intersection inside a non-trivial Hasse block must be represented, in any realizing network, by descendant clusters of proper hybrid vertices in a corre-sponding network block. This gives the lower bound μ(B) ≤ h(BN ). For sufficiency, we start from the Hasse diagram and iteratively split all redundant hybrid vertices. The split operation preserves the hardwired clustering system, while a lexicographic descent argument shows that the process terminates. In the final network, each block has at most μ(B) proper hybrid vertices. The paper is organized as follows. # 2 Preliminaries 

We fix notation for clustering systems, Hasse diagrams, rooted networks, and the block parameters used in the characterization. Let X be a finite nonempty set, let C be a clustering system on X, and write H := H[C]. 

Rooted networks and clusters. 

We use the standard terminology for rooted networks [ 1]. A rooted network is a finite directed acyclic graph N = ( V, E ) with a unique root ρN of indegree 0. A vertex 

v is a leaf if outdeg N (v) = 0, a hybrid vertex if indeg N (v) > 1, and a tree vertex if indeg N (v) ≤ 1. The leaf set is denoted by X(N ); if X(N ) = X, then N is a rooted network on X. Throughout, network means rooted network. For v ∈ V (N ), let 

σ(v) be the set of leaves reachable from v; the hardwired clustering system of N is 

CN := {σ(v) | v ∈ V (N )}.A cluster on X is a nonempty subset of X. A clustering system on X is a family 

C ⊆ 2X \ { ∅} such that X ∈ C and {x} ∈ C for every x ∈ X.

Hasse diagrams and order notation. 

The Hasse diagram H[C] is the directed acyclic graph with vertex set C and edge 

C → C′ precisely when C′ ⊊ C and there is no C′′ ∈ C with C′ ⊊ C′′ ⊊ C. For a rooted network N and vertices u, v , write v ⪯N u if there is a directed path from u to 

v, and write v ≺N u if v ⪯N u and v̸ = u. Vertices u and v are comparable if u ⪯N v

or v ⪯N u, and incomparable otherwise. If u → v is an edge of N , then u is a parent of v and v a child of u.4We freely identify a cluster A ∈ C with the corresponding vertex of H whenever convenient. Thus expressions such as A ∈ V (BH ), A ⊆ A′, and A ∈ C (BN ) refer to the same cluster viewed respectively as a vertex of the Hasse diagram, as a subset of X,and as an element of a cluster family. The graph H is connected, has X as its unique root, its inclusion-minimal vertices are exactly the singletons, and every non-singleton cluster C ∈ C satisfies outdeg H (C) ≥ 2; hence H is itself a rooted network. Later, for current networks arising in the splitting construction, λ(v) denotes the original Hasse-label of a current vertex v, so that λ(v) ∈ V (B) means that this original label belongs to the original non-trivial block B of H.

Overlap and blocks. 

Two clusters A, A ′ ∈ C overlap if A ∩ A′̸ = ∅, A̸ ⊆ A′, and A′̸ ⊆ A. A block of a rooted network is a maximal 2-connected subgraph of its underlying undirected graph. A block is non-trivial if it contains an undirected cycle, equivalently, if it is neither a single vertex nor a single edge. For a non-trivial block B of a rooted network, a vertex 

m ∈ V (B) is terminal if it is ⪯N -minimal in V (B). For a connected undirected graph G, its block-cut tree T (G) is the bipartite graph whose nodes are the blocks and cut vertices of G, with a block-node B adjacent to a cut-vertex-node c exactly when c ∈ V (B).

# 3 Comparison with Known Parameters 

We compare μ(B) with standard network-side measures of reticulation complexity. The key distinction is that μ(B) is defined on a non-trivial block B of the Hasse diagram 

H = H[C], while hybrid number, reticulation number, and level are defined only after a realizing network has been chosen. Let BH be a non-trivial block of H, and let N be a rooted network with CN = C.By Lemma 16, the block BH is represented inside some non-trivial block BN of N . The necessity argument gives μ(BH ) ≤ h(BN ). Thus μ(BH ) is a lower bound, depending only on the clustering system, for the number of proper hybrid vertices required in any realizing block. Intuitively, each overlap-intersection in BH must be explained in the network by descendant clusters of proper hybrid vertices; the generating set measures how many such pieces are forced. This inequality need not be an equality for a fixed realization. A realization may contain redundant hybrid vertices that do not create new hardwired clusters, and then one can have μ(BH ) < h (BN ). For instance, in Figure 2, the Hasse diagram itself has μ(B1) = h(B1) = 1. A non-minimal realization could contain additional hybrid vertices with the same descendant cluster, leaving the clustering system unchanged but increasing h(BN ). Nevertheless, the bound is sharp for level realizability. Theorem 36 states that a level-k realization exists exactly when μ(B) ≤ k for every non-trivial block B of H.Thus μ(B) gives the correct blockwise threshold, even though arbitrary realizations may contain more hybrid vertices than necessary. Thus μ(B) should not be interpreted as the number of hybrid vertices already visible in the Hasse diagram; rather, it counts the overlap-intersection regions that cannot be avoided in any realization. 

# 4 Necessity Tools 

The lemmas in this section serve one purpose: they allow us to compare a non-trivial block of the Hasse diagram with a non-trivial block in an arbitrary realizing network. We first localize overlapping clusters inside common network blocks, then show that an entire Hasse block can be represented inside one fixed network block, and finally transfer a generating set from the network block back to the Hasse block. This gives the lower bound μ(B) ≤ h(BN ), which is the key ingredient in the necessity proof. 

# 4.1 Overlap and intersection tools inside non-trivial blocks

# 4.2 Realizing a Hasse block inside one network block 

We now relate non-trivial blocks of the Hasse diagram to non-trivial blocks of a realizing network. The next lemmas provide the technical ingredients needed to pass from an edge of a non-trivial block in the Hasse diagram to a corresponding non-trivial block in a realizing network. 

Lemma 8 (Avoiding a fixed cut vertex: same-cluster representatives stay in one component) . Let a ∈ V (N ) be a cut vertex, and write A := σ(a). Thus x and

# 5 Splitting Construction 

The sufficiency direction is constructive. The Hasse diagram itself realizes the given clustering system, but its non-trivial blocks may contain too many proper hybrid vertices. The construction removes redundant hybrid vertices by splitting them into several copies. Since all copies have the same descendant leaf set as the original vertex, 17 the hardwired clustering system is unchanged. The main difficulty is to ensure that such local modifications do not create uncontrolled reticulation in other blocks. To control this process, we distinguish the hybrid vertices that are allowed to remain, namely those whose original labels lie in the chosen generating set KB , from the bad hybrid vertices that must be split.

# 6 Termination and Block Control 

It remains to prove that the splitting process stops and that it does not destroy the block-wise control needed for the level bound. The key observation is that new bad hybrid vertices can only appear deeper in the same original block or in descendant blocks of the original block-cut tree. Therefore, if bad hybrid vertices are always split in lexicographic order, the process admits a finite descent measure. Once no bad hybrid vertices remain, every proper hybrid vertex in a current block has a label belonging to the prescribed generating set KB , giving the desired level bound.
