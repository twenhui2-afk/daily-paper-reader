On the 0-Rotatability of Regular Spider Trees of Leg
Length 4
Abstract
A tree T on q edges is said to be 0-rotatable if for every vertex v ∈ V(T), there exists a graceful
labeling f : V(T) → {0, 1, …, q} such that f(v) = 0. Rofa proved that all regular (symmetric) spider
trees with leg length at most 3 are 0-rotatable and conjectured that the property holds for every leg
length. In this note, we settle the first open case of this conjecture by proving that every regular
spider tree T(k, 4) with k ≥ 1 legs of length 4 is 0-rotatable. Our proof combines Rofa’s algebraic
graceful labeling at the root with complementary labelings, an end-to-end leg-reversal construction
placing 0 at a leaf, and a two-leg reflection permutation placing 0 at distance 2 from the root. 
1 Introduction
Let G = (V, E) be a simple graph with q = |E| edges. A graceful labeling of G, introduced by Rosa [5] and
popularized by Golomb [2], is an injection f : V(G) → {0, 1, …, q} such that the induced edge weight
function wf : E(G) → {1, 2, …, q}, defined by
wf(uv) = |f(u) − f(v)|     for all uv ∈ E(G), 
is a bijection. The longstanding Ringel–Kotzig conjecture asserts that every tree admits a graceful
labeling.
To construct graceful labelings inductively by amalgamating smaller trees at designated root vertices,
Chung and Hwang [1] introduced the notion of k-rotatability: a tree T is 0-rotatable if for every vertex v
∈ V(T), there exists a graceful labeling f of T satisfying f(v) = 0. While several families of trees—
including paths, caterpillars, and stars—are known to be 0-rotatable, determining 0-rotatability for
general symmetric trees remains challenging because a separate graceful construction is required for each
automorphism orbit of vertices.
A regular spider tree T(k, ℓ) consists of a central root vertex v0 of degree k to which k pairwise
internally disjoint paths (legs) of uniform length ℓ are attached. Using an algebraic graceful labeling
framework for rooted symmetric trees [3], Rofa [4] established that T(k, ℓ) is 0-rotatable for all k ≥ 1
whenever ℓ ≤ 3, and conjectured that T(k, ℓ) is 0-rotatable for every ℓ ≥ 1. In this paper, we resolve the
case ℓ = 4 completely.

Lemma 1 (Complementary Labeling). If f : V(G) → {0, 1, …, q} is a graceful labeling of a graph G with
q edges, then the complementary labeling f : V(G) → {0, 1, …, q} defined by f(v) = q − f(v) is also
graceful.
Proof. Since v ↦ q − v is a bijection on {0, 1, …, q}, f is a bijection onto {0, 1, …, q}. Moreover, for
every edge uv ∈ E(G), 
wf(uv) = |f(u) − f(v)| = |(q − f(u)) − (q − f(v))| = |f(u) − f(v)| = wf(uv), 
so wf induces the identical bijection onto {1, 2, …, q}.
Because the automorphism group Aut(T(k, 4)) acts transitively on the set of legs {L1, …, Lk}, the
vertex set V(T(k, 4)) partitions into exactly five automorphism orbits indexed by distance from the root
v0:
O0 = {v0}     and     Od = {v1,d, v2,d, …, vk,d}     for d ∈ {1, 2, 3, 4}. 
Consequently, T(k, 4) is 0-rotatable if and only if there exist five graceful labelings f0, f1, f2, f3, f4
satisfying f0(v0) = 0 and fd(v1,d) = 0 for each d ∈ {1, 2, 3, 4}.
3 Main Result
Theorem 2. For every integer k ≥ 1, the regular spider tree T(k, 4) is 0-rotatable.
Proof. Let q = 4k. We construct a graceful labeling placing 0 in each of the five vertex orbits O0, O1, O4, 
O3, O2 in turn. 
Case 0: 0 at the Root (O0). Since T(k, 4) is a rooted symmetric tree of height 4, Rofa’s algebraic graceful
labeling function [3, 4] directly provides a graceful labeling f0 : V(T(k, 4)) → {0, 1, …, 4k} defined by
f0(v0) = 0 and, for each i ∈ {1, 2, …, k}, 
f0(vi,1) = 4(k − i + 1),
f0(vi,2) = 4i − 3,
f0(vi,3) = 4(k − i + 1) − 1,
f0(vi,4) = 4i − 2.
In particular, f0 is graceful with f0(v0) = 0 and f0(v1,1) = 4k. 
Case 1: 0 at Distance 1 (O1). Define f1(v) = 4k − f0(v) to be the complementary labeling of f0. By
Lemma 1, f1 is graceful, and 
f1(v1,1) = 4k − f0(v1,1) = 4k − 4k = 0. 
Case 4: 0 at a Leaf (O4). Define f4 : V(T(k, 4)) → {0, 1, …, 4k} piecewise by setting f4(v0) = 2,

f4(v1,2) = 1,
f4(v1,3) = 4k,

f4(vi,3) = 4(k − i + 1) + 1,
