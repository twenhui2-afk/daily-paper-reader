## Abstract
The quasi-TMDPDF in large-momentum effective theory is related to the TMDPDF through a soft factor, which has so far been constructed separately from the quasi beam function. We show that the soft factor is contained in the quasi beam function itself. Computing the one-loop quasi beam function and decomposing it by the method of regions, we find that the hard and collinear regions give the matching coefficient and the lightcone beam function. The soft region involves only one lightlike direction, yet, once the two hemispheres of the gluon momentum are folded onto each other, it reproduces the square root of the lightcone soft function together with the reduced soft function. The analysis leads to an operator definition of the soft factor, as the vacuum matrix element of the soft Wilson lines into which the quasi beam function turns. This definition provides the basis for an all-order analysis, and it shows that the Collins-Soper kernel is reproduced to all orders.
