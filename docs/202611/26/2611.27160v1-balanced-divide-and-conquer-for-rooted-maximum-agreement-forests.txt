# Balanced Divide and Conquer for Rooted Maximum Agreement Forests

Abstract 

We develop a balanced divide-and-conquer framework for the maximum agreement forest problem on rooted binary phylogenetic tree–forest instances. The goal is a common subforest with the fewest components; budget k bounds the increase relative to the input forest. We balance edges associated with an unknown optimum to obtain three subproblems with smaller budgets. Branching separates the inputs, while temporary marker leaves allow a global optimum to be recovered from independently computed optimal solutions. For any fixed 

B > φ = (1 + √5) /2, the framework converts a tree–forest solver running in O∗(Bk) time into one running in O∗(( √φB )k) time. Starting from an O∗(2 .3391 k)-time solver, two applications yield an O∗(1 .7743 k∗

)-time fixed-parameter algorithm for two trees, where k∗ is the number of components in a maximum agreement forest minus one. For every fixed ε > 0, a fixed number of applications yields O∗(( φ + ε)k∗

) time. Here O∗ suppresses polynomial factors, whose degree and constants may depend on ε.

Keywords: maximum agreement forest; fixed-parameter algorithm; phylogenetic tree; divide-and-conquer. 

# 1 Introduction 

Phylogenetic trees are widely used to represent evolutionary relationships among a set of extant species, or more generally taxa [19, 21, 45]. Each leaf represents an observed taxon, whereas internal vertices represent hypothetical common ancestors or evolutionary divergence events. A rooted phylogenetic tree additionally specifies an ancestral direction: the root represents a common ancestor and the paths from the root toward the leaves describe the direction of evolutionary descent. By contrast, an unrooted phylogenetic tree records relationships among the taxa without specifying which vertex should be interpreted as the common ancestor. Different parts of a genome need not support the same phylogenetic tree. In particular, evolutionary processes such as horizontal gene transfer, hybridization, and recombination may lead to different tree topologies for different homologous genomic regions [15, 16, 28]. Comparing phylogenetic trees and quantifying their structural disagreement is therefore an important problem in computational phylogenetics. A number of distance measures have been proposed for this purpose, including the Robinson–Foulds distance [30], nearest-neighbor interchange (NNI) distance [24], tree bisection and reconnection (TBR) distance, subtree prune and regraft (SPR) distance [6, 38], hybridization number [2], and maximum parsimony distance [20]. To compare two phylogenetic trees, we assume that their leaves represent the same set of taxa. Let X denote this common set of taxa (equivalently, leaf labels), where |X| = n, and let

1arXiv:2611.27160v1 [cs.DS] 20 Nov 2026 T1 and T2 be two rooted binary phylogenetic trees whose leaves are labeled by X. Informally, an agreement forest (AF ) describes evolutionary structure that can be found simultaneously in both trees after a number of edges have been removed. More precisely, its components partition the label set X, and for every component label set, the corresponding restricted subtree has the same topology in T1 and T2; moreover, the subtrees representing different components are vertex-disjoint in each input tree. Equivalently, one may view an AF as a common forest obtained from the two input trees by deleting edges and applying the usual reductions to the resulting unlabeled vertices. The order of a forest is the number of its components, and we denote it by ord( F ) for a forest F . A maximum agreement forest (MAF ) is an AF of minimum order [4]; we denote this minimum order for ( T1, T 2) by m(T1, T 2). Thus, despite the terminology “maximum”, the optimization objective is to minimize the number of components, or equivalently to preserve as much common structure of the two input trees as possible. Throughout the paper, MAF 

denotes a maximum agreement forest as a solution object; the corresponding computational problem is referred to as the MAF problem. Among the distance measures mentioned above, TBR and rooted SPR (rSPR) distances are particularly closely related to AFs . For two unrooted binary phylogenetic trees, the analogous unrooted notion of an MAF characterizes TBR distance: if an MAF has order m, then the TBR distance is exactly m − 1 [1]. For two rooted binary phylogenetic trees, the corresponding relationship holds for rSPR distance under the standard convention in which a new vertex labeled 

ρ is attached above the original root of each tree and becomes the new root. If an MAF of the resulting ρ-augmented pair has order m, then the rSPR distance of that pair is m − 1 [4]. Hence an MAF provides a combinatorial route to computing these edit distances, and algorithmic improvements for the MAF problem translate directly into improvements for the corresponding distance computation under the appropriate convention. The MAF problem is NP-hard for two rooted binary phylogenetic trees [4]; for two unrooted binary phylogenetic trees, it is both NP-hard and MAX SNP-hard [18]. This has motivated extensive research on approximation algorithms, fixed-parameter algorithms, kernelization, and practical decomposition techniques. In this paper we focus on the MAF problem for two rooted binary phylogenetic trees. Several related variants have also been studied, including the 

MAF problem for two unrooted binary trees [1, 17, 27, 42, 39], for two rooted multifurcating trees [32, 44], for two unrooted multifurcating trees [8, 36], for multiple binary trees [7, 9, 10, 34], and for multiple rooted multifurcating trees [37]. 

## 1.1 Related Work 

The literature considers rooted phylogenetic trees both with and without a distinguished root label ρ. The main design ideas behind the algorithms reviewed below are essentially independent of this choice. We therefore discuss these results together and specify the convention used in each paper where it matters for the comparison. 

Approximation Algorithms . The approximation guarantees below are stated for the cut-count objective, defined as the AF order minus one. The first correct constant-factor approximation algorithm for the MAF problem was given by Bonet et al. [3], who obtained an approximation ratio of 5. 1 Bordewich et al. Further progress focused on improving the approximation ratio. Shi et al. [35] obtained a 2 .5-approximation in O(n2) time, and Chen et al. [12] improved the ratio to 7 /3, again with quadratic running time. Building on the structural analysis underlying the 7 /3-approximation, Chen et al. [13] obtained a 2-approximation with cubic running time. Independently, Schalekamp et al. [33] derived a 2-approximation using LP duality. Although

Fixed-Parameter Algorithms . The MAF problem has been extensively studied from the viewpoint of parameterized complexity, with the order of an MAF , or equivalently, that order minus one, as the parameter. Throughout this overview, we use k to denote the minimum order minus one. The goal is to obtain algorithms with running time f (k) · nO(1) , where f is a computable function depending only on k [14]. We use O∗(·) to suppress factors polynomial in the input size. Most fixed-parameter algorithms for the MAF problem follow a branching paradigm. When the two input structures disagree locally, the algorithm identifies a small collection of edge-deletion alternatives such that at least one alternative is compatible with an MAF . It branches on these alternatives, decreases the remaining cut budget, and recursively solves the resulting instances. The exponential base is governed by the resulting branching recurrences, which depend on both the number of alternatives and the budget consumed by each alternative. Bordewich et al. [5] gave an O∗(4 k)-time algorithm. Whidden et al. [43] improved the bound to O∗(2 .42 k) through a refined analysis of local configurations, including sibling pairs and pendant subtrees. Chen et al. [11] further analyzed these configurations and their interactions, obtaining an O∗(2 .344 k) bound. These developments illustrate a central direction in earlier work: stronger branching rules and finer case analyses progressively reduce the exponential base. Whidden’s PhD thesis [41] also states an O∗(2 k) bound. Since we are not aware of a peer-reviewed publication establishing this bound, we do not use it in our subsequent analysis. Mestel et al. [27] developed a split-or-decompose algorithm for the MAF problem. On a tree–forest instance ( T, F ) with additional-cut budget κ, their algorithm seeks an AF of order at most ord( F ) + κ and runs in O∗(2 .3391 κ) time. It maintains one input as a reference tree T and represents the other by a forest F ′ obtained through edge deletions. When components of F ′

induce overlapping subtrees in T , these overlaps prevent a direct decomposition into independent subinstances. Splitting and branching rules are applied to resolve the overlaps and the remaining rooted configurations. Once the induced subtrees are pairwise vertex-disjoint, each component defines a separate subinstance, and solutions to these subinstances can be combined into a solution for the current input. The analysis also uses information about how the remaining work is distributed among the subinstances. A bounded-depth probing procedure tests each subinstance with a constant cut budget, solving those within that budget and obtaining lower bounds for the others. The cuts required by other subinstances can then be deducted from the budget supplied to a recursive call. This gives a running-time gain when several subinstances require nontrivial work, while additional branching rules handle the limiting configurations. The split-or-decompose framework is particularly relevant to our work because it shows that decomposition can contribute directly to the exponential analysis of the MAF problem, rather than serving only as a practical preprocessing technique. In that framework, however, decomposition becomes available only after branching has eliminated overlaps among the current forest components. Moreover, the framework does not impose a balance condition on the remaining budgets of the resulting subinstances. Consequently, a decomposition can in principle be highly unbalanced, with one subinstance retaining almost all of the remaining budget. 

Kernelization . A kernelization algorithm transforms an instance in polynomial time into an equivalent instance whose size is bounded by a function of the parameter. Although kernelization does not improve the exponential base of a fixed-parameter algorithm, it can bound the size of the instance passed to the exponential-time phase by a function of the parameter. For the standard ρ-augmented formulation with rSPR parameter d, Bordewich and Semple [4] obtained a kernel with at most 28 d taxa. For d ≥ 1, Kelk et al. [22] subsequently improved this bound to 9 d − 3 taxa using subtree, chain, and 3-2-chain reductions; the case d = 0 is trivial. In this paper, we use these reductions only as a preprocessing step on the original tree–tree instance. Their compatibility with the root convention used in our technical development, as well as the resulting size bound for the recursive instances, is established in Section 8. 3Cluster Partitioning . Linz and Semple [26] introduced cluster partitioning as a practical decomposition technique for the rooted MAF problem. A suitable cluster shared by the two input trees can be used to reduce the computation to smaller subproblems whose solutions are subsequently combined according to the cluster-reduction framework. This approach is effective in practice because phylogenetic instances often contain substantial common structure, allowing the exponential-time solver to operate on considerably smaller subproblems [25, 40]. Cluster partitioning, however, does not by itself guarantee an improvement in the worst-case exponential base. An input pair need not contain a useful common cluster, and even when such a decomposition exists, the parameter may be distributed arbitrarily unevenly among the resulting subproblems. 

## 1.2 Our Contributions 

Motivated by the split-or-decompose strategy [27] and cluster partitioning [26], we develop a balanced-center framework for the MAF problem on two rooted binary phylogenetic trees. The framework decomposes a tree–forest instance into three side instances, solves them independently, and reconstructs an MAF for the original instance. A subproblem on relatively few labels may still require most of the budget for additional components. We therefore seek a partition that balances the budgets needed to solve the three subproblems. Finding and enforcing such a partition presents two difficulties. The desired balance depends on an unknown optimal solution, and a component of the input forest or of that solution may contain labels from more than one part. The following three ingredients address these difficulties and yield an improved running-time bound. To state the balance guarantee, we use a refined parameterization for forest pairs. For ( F1, F 2), let m(F1, F 2) denote the minimum order of an AF . A set of labels is separating if every two distinct labels belong to different components in at least one input. Let σmax (F1, F 2) be the maximum size of such a set [37]; this is a lower bound on the order of every AF . Given a budget 

k, the task is to determine whether m(F1, F 2) ≤ σmax (F1, F 2) + k. For a fixed target AF G,define its gap by r = ord( G) − σmax (F1, F 2). Thus r ≤ k whenever G is feasible for the supplied budget. The algorithm uses k; the unknown target and its gap r guide only the analysis. On a tree–forest pair ( T, F ), we have σmax (T, F ) = ord( F ), so the gap is exactly the number of additional cuts needed to obtain the target from F .1. Finding a center that balances the remaining disagreement. Our first task is to identify where the unresolved disagreement lies. Fix a tree–forest instance ( T, F ) and a target AF G with gap r. We prove that this gap can be represented by a critical edge-deletion set of exactly r edges in T : deleting these edges and applying the greedy reduction process recovers G. The edges also admit an ordering in which each prefix of 

j deletions increases σmax by exactly j. This connects the numerical gap to specific edge locations and allows us to bound the gap on each side of a partition. For r ≥ 3, a weighted-centroid argument gives a nonroot internal vertex c whose removal from T gives three sides, each containing at most ⌊r/ 2⌋ critical edges. Consequently, each restricted side target has gap at most ⌊r/ 2⌋. Although the algorithm does not know G or its critical edges, it enumerates all O(n) possible centers and therefore includes a suitable choice. Thus we obtain a partition that balances the remaining disagreement, rather than merely the number of labels. Instances with gap at most two are handled by the auxiliary solver. 2. Separating the inputs without losing an optimal solution. A balanced center c

partitions T , but the same label partition need not separate F . Let X0 be the labels on the root side of c, and let X1, X 2 be the labels on the other two sides. We enforce this partition through two binary separations: first X1 | (X0 ∪ X2), and then X2 | X0, with 4these expressions referring to the inherited labels. At each stage, we can separate the inputs without branching if every component of the current forest has all its labels on one side of the split, either already or after deleting a single edge. Otherwise, we use a two-color branching procedure. A further difficulty is that a component of the target AF may contain labels from both sides of a separation. Keeping the sides permanently disconnected would split this component and could therefore exclude the target optimum. To preserve the possibility of recovering that solution, we introduce a pair of marker leaves to record each temporarily cut connector. After the sides have been solved, the components containing these markers determine whether the connector is restored. The two separation stages are reconstructed in reverse order. Preserving the option to reconnect is not sufficient by itself: the reconstructed forest must also have the required order. A target that uses a connector gains one component when that connector is cut. A target that omits it gains two singleton marker components instead. Reconstruction must compensate for both possibilities, even though a side solver may return an optimum different from the target restriction. We address this by trying the constant number of choices of singleton markers. For each choice we prepare ordinary tree–forest instances, so the solver needs no additional marker constraints. For a separation that preserves the fixed target AF G, the singleton-marker choice prescribed by the transformed target allows the returned side forests to be reconstructed into an AF of order at most ord( G). Taking G to be an MAF for the original instance establishes global optimality. 3. Turning balanced decomposition into faster algorithms. The balance guarantee must hold for the marked instances actually sent to the side solver. After singleton preparation, the child-side target gaps retain their original bounds, while the root-side gap can increase by at most one. Thus, on a target-compatible branch and for the target-induced singleton pattern, every prepared side target has gap at most ⌊r/ 2⌋ + 1. The remaining separation budget b gives an independent bound, so the algorithm uses κ = min {⌊ k/ 2⌋ + 1 , b } as the supplied budget for each side call. Since every side is a tree–forest instance, κ is exactly the additional-cut budget used by standard solvers. The key to the running-time analysis is to account for separation and side solving together: a branch that spends more deletions enforcing the partition leaves less work for the side solver. Let φ = (1 + √5) /2. We prove that a compatible side solver with running time 

O∗(Bκ), where B > φ , yields an overall algorithm with exponential base √φB . The extra unit in the side budget bound ⌊k/ 2⌋ + 1 covers the possible increase in the root-side gap due to the markers. Marker operations also add at most two units to the separation budget. If the framework is applied a fixed number of times, these extra units affect only the constant factor in the running-time bound. By Theorem 39, applying the framework with the O∗(2 .3391 κ) solver of Mestel et al. [27] gives an O∗(1 .9455 k)-time algorithm. This algorithm satisfies the same input and output guarantees as the original side solver. Applying the framework again with the new algorithm as the side solver gives O∗(1 .7743 k) time. For every fixed ε > 0, repeating this process a suitable fixed number of times gives an O∗(( φ + ε)k)-time algorithm. # 2 Preliminaries and Problem Formulations 

We follow the conventions for rooted trees and forests used by Mestel et al. [27]. Let X be a nonempty finite set of labels. For |X| ≥ 2, a rooted binary phylogenetic tree on X, or an 

X-tree , is a directed tree whose leaves are bijectively labeled by X. Its root has in-degree 0 and out-degree 2, every other internal vertex has in-degree 1 and out-degree 2, and every leaf has in-degree 1 and out-degree 0. For |X| = 1, the unique X-tree consists of the single labeled vertex. All edges are directed away from the root and hence induce an ancestor–descendant relation. We identify a label with its leaf. Two vertices are siblings if they have the same parent. A pair of sibling leaves is called a cherry .An X-forest is a collection of rooted binary phylogenetic trees whose label sets form a partition of X. Equivalently, an X-forest can be obtained from an X-tree by deleting edges and applying forced contraction . Forced contraction consists of the following two operations [5, 17]: (1) delete an unlabeled isolated vertex or an unlabeled vertex of undirected degree 1; and (2) suppress an unlabeled vertex of in-degree 1 and out-degree 1, replacing its two incident edges by one directed edge. These operations are applied repeatedly until neither applies. Every remaining component contains at least one label. A singleton component consists of a single labeled vertex; in every other component, the root has in-degree 0 and out-degree 2. A forest is irreducible if neither operation applies. We regard forests that differ only by forced contraction as the same forest. The order ord( F ) of a forest F is its number of components. 6For a vertex v of a forest H, the subtree rooted at v consists of v, all its descendants, and the edges joining these vertices. We call a subtree of this form a pendant subtree . We allow the whole component when v is its root. If v is not the root, the pendant subtree is attached to the rest of its component by the edge entering v.For a subgraph H of an X-forest, denote by L(H) the labels occurring in H. ## 2.2 Problem Formulations 

The MAF problem asks for an MAF for an X-forest pair, where each input may have several components. The parameterized version of the problem can be formulated in several ways, depending on the lower bound from which the order of the desired AF is measured. The most direct formulation uses the order of the desired AF as the parameter. 

Parameterized MAF Version 1 (abbr. p-MAF 1). Given ( F1, F 2) and an integer k1, decide whether m(F1, F 2) ≤ k1 and, if so, return an AF of order at most k1.An alternative parameter measures the gap above a lower bound on the AF order. Define ord( F1, F 2) = max {ord( F1), ord( F2)}. Since every AF for ( F1, F 2) is a subforest of both inputs, its order is at least ord( F1, F 2). We therefore measure the allowed order above this bound, rather than using the total order as the parameter. 

Parameterized MAF Version 2 (abbr. p-MAF 2). Given ( F1, F 2) and an integer k2, decide whether m(F1, F 2) ≤ ord( F1, F 2) + k2 and, if so, return an AF of order at most ord( F1, F 2) + k2.This formulation also has an edge-deletion interpretation. Assume, without loss of generality, that ord( F1) ≤ ord( F2). Then p-MAF 2 asks whether F2 has an ee-set E with |E| ≤ k2 such that 

F2 \ E is an AF for ( F1, F 2). Indeed, ord( F2 \ E) = ord( F2) + |E| = ord( F1, F 2) + |E|. Thus 

k2 is a budget for additional cuts in the input forest of larger order. This viewpoint is used by existing branching algorithms for the problem [11, 27, 41, 43]. However, the lower bound ord( F1, F 2) is not always tight, as it does not capture separations that are already forced jointly by the pair. We account for these separations through the following lower bound of Shi et al. [37]. A subset S of the label set X is a separating set for an X-forest pair (F1, F 2) if, for any two distinct labels l1, l 2 ∈ S, the labels l1 and l2 are in different components of at least one of F1 and F2. A maximum separating set for ( F1, F 2) is a separating set of maximum size. The size of a maximum separating set for ( F1, F 2) is denoted by σmax (F1, F 2). As shown below, σmax (F1, F 2) is a computable lower bound on the order of any AF for ( F1, F 2), and this lower bound is at least ord( F1, F 2). Thus it gives a potentially sharper parameter for the problem. For later use, define the component-pair partition 

P(F1, F 2) = {L(A) ∩ L(B) : A ∈ F1, B ∈ F2, L (A) ∩ L(B)̸ = ∅}.

Here A ∈ F1 and B ∈ F2 range over components. Two labels lie in the same block of this partition exactly when they belong to the same component in each input.

A separating set contains at most one label from each block of P(F1, F 2), since labels in the same block belong to the same component in both inputs. Conversely, choosing one label from each block gives a separating set: labels from distinct blocks belong to different components in at least one input. This proves the equality. To construct such a set, traverse both forests to assign an integer index to each component. Group the labels by their pairs of component indices using radix sorting, and choose one label from each group. ## 3.2 Critical ee-sets 

The balanced decomposition requires us to represent the refined gap by edge locations in one input. directly into F requires ord( F ) − 1 edges. These cuts can instead be made by Reduction Rule 0. 12 We therefore consider edge sets whose deletion allows the greedy reductions to recover the target. # 5 Easy Binary Separation and Optional Reconstruction 

Let ( T, F ) be a tree–forest pair on X, and let e = ( w, v ) be an edge of T , where w is the parent of v. Let Tv and Tw be the two connected components of T − e containing v and w, respectively. Let Xv = L(Tv) and Xw = L(Tw). Thus Xv = L(v) is the descendant label set of v, whereas 

Xw = X \ Xv is the label set on the root side. The edge e induces the label bipartition ( Xv, X w)of X. An X-forest H admits (Xv, X w) if every component of H has all of its labels in one side of the bipartition. Equivalently, Xv is the union of the label sets of some components of H. We call the bipartition easy for H if H admits it or if there is an edge e′ of H such that H \ { e′}

admits it. These conditions can be tested in linear time. 16 We show how to realize an easy bipartition while retaining the information needed for reconstruction. The separated sides are kept for further separation or side solving in the balanced-center algorithm. Parameter balance and the overall running-time analysis are deferred to Section 7. 

## 5.1 Direct separation 

If F already admits ( Xv, X w), then Xv is a union of component label sets of F , so Reduction Rule 0 applies to e in T . Lemmas 6 and 7 give the following lemma. No marker is needed in this case. 

Lemma 18. If F admits (Xv, X w), then (T, F ) and (T \ { e}, F ) have the same AFs and the same value of σmax . Both forests in the latter pair admit (Xv, X w). The two independent side instances are (T [Xv], F [Xv]) and (T [Xw], F [Xw]) .

## 5.2 Local marker operation

## 5.5 Separation states and temporary budgets

# 6 Difficult Binary Separation 

The easy constructions apply when at most one edge deletion from the second input separates the prescribed sides. We now consider the remaining case. Let T and F be the tree and forest for the current separation, with temporary budget b ≥ 0. We write ( T, F ; b) for this input, omitting the reconstruction stack as in Section 5.5. # 7 The Balanced-Center Algorithm 

For a fixed target, a balanced center gives three label sides whose restricted target gaps satisfy the bounds of Section 4. These restrictions are taken before fresh markers are added. To use them in the algorithm, we separate the inputs along the same sides, solve the resulting instances, and reconstruct an AF of order no larger than the target. Since the target and its critical edge set are unknown, the algorithm enumerates all nonroot internal vertices as candidate centers. At a candidate center, the algorithm performs two binary separations. It stores both child connectors, separates along the first, and sets the separated side aside. It then separates the remaining side along the second connector. Only after both stages have finished does it solve the three side instances and reconstruct their solutions. The two stages use the same budget and count of charged deletions, and create at most two new reconstruction records. The fresh markers also affect the side gaps; this effect must be included when bounding the parameters passed to the side solvers. The first separation may change the edge representing the second connector. The following lemma identifies it using its descendant labels, as described in Subsection 5.5.

## 7.3 The algorithm and its running time 

Algorithm 2 gives the balanced-center algorithm BC-Alg-MAF 3 for tree–forest instances (T, F ; k). It tries every candidate center and both separation stages before making any side call. Each state carries its reconstruction stack R, even when it is not shown. The descendant set for the second connector is stored before the first separation. The budget is shared across the two stages: b = k + t − i, where t is the number of records created at this level and i is the total 35 number of charged deletions at this level. Neither count is reset after the first separation. The total forest order includes the side already set aside. The algorithm does not know the target G or its singleton markers. It therefore tries every subset of the fresh markers. There are at most four such markers, so there are at most 16 subsets. A failed side call rejects only the current singleton subset. ## 7.4 Recursive composition 

The algorithm above takes the same type of input as its side solver and gives the same output guarantee. We can therefore replace the side solver with this algorithm and apply the framework again. Let A0 denote Alg-MAF M , and put β0 = 2 .3391. For j ≥ 0, define Aj+1 by Algorithm 2, with 

Aj as its side solver. The initial constant-budget call is always Alg-MAF M . The composition depth fixes which solver is used: a call to Aj+1 calls only Aj on its sides, and A0 invokes the auxiliary solver directly. Moreover, separation is reached only when k ≥ 3, and its side budgets are at most ⌊k/ 2⌋ + 1 < k . Thus every side call also has a smaller supplied budget. After the selected common singletons are stripped, every side input is a tree–forest pair, so its refined parameter and additional-cut parameter agree. Markers inherited from an outer call are treated as ordinary labels by the inner solver. Only the markers selected to be singleton are removed before that call and restored as singletons afterward. An inner call removes all markers created by its own records before it returns. It retains every inherited marker in its input. Thus, after the stripped markers have been restored, the returned forest contains every marker needed by an outer record. The record can read whether each marker is singleton and, otherwise, its current neighbor. Reconstruction then applies Lemma 21 in reverse record order.

# 8 Kernelization without the Extra Root Label 

Kelk et al. [22] studied the kernelization for the MAF problem on X-trees with an extra root labeled ρ. Our algorithms use X-trees without this extra label. Before using their kernelization, we show that its reduction rules are also safe for our setting. We prove this for the subtree, chain, and 3-2-chain reductions. We then derive a size bound for the reduced input and apply it to our running-time bounds. 

## 8.1 Reduction rules on the ordinary labels 

We apply the following rules to the unaugmented pair. All labels mentioned in the rules are ordinary taxa. We use the chain order of Section 5 of [22]. Let ( x1, . . . , x ℓ) be a sequence of distinct labels, with ℓ ≥ 2, and let ui be the parent of xi. The sequence is a chain if u1 = u2

## 8.3 Recursive sizes and running time 

The preprocessing is performed once, on the original tree pair. Recursive calls inherit its ordinary labels. Edge deletion, restriction, and decomposition do not introduce new ordinary taxa. Each fixed composition level adds only a constant number of marker labels.

Every successful reduction removes at least one ordinary taxon, so there are fewer than n

We store the type, labels, and attachment information for each reduction and process the records in reverse order to recover the original solution. To undo a subtree reduction, expand the representative label into the original common subtree. To undo a 3-2-chain reduction, add the deleted label as a singleton component. Each of these operations takes O(n) time. To undo a chain reduction, compute the minimal representation of each component in each tree. One traversal per component takes O(n2) in total. Scan these representations at the two ends of the retained chain, including components with no chain label whose representations pass through the chain. For two input trees, the constructive normalization in Lemma 48 uses a constant number of splits and merges. At most two splits are needed in the case that requires repeated splitting. Each label set update and the restoration of the deleted chain labels take 

O(n) time. Thus undoing one chain reduction takes O(n2) time. Processing all the records to recover the original solution takes O(n3) time. If the optimum budget is unknown, preprocess once and retain the number s of 3-2-chain reductions. A trial budget q for the original pair corresponds to K = q − s on the reduced pair. Trials with q < s fail immediately. For each later trial, apply the size test with this K and, if it passes, run the solver. At the first successful trial, undo the recorded reductions in reverse order to recover a MAF for the original pair. The geometric sum over trial budgets preserves the exponential base. We developed a balanced divide-and-conquer framework for the maximum agreement forest problem on two rooted binary phylogenetic trees. For k∗ = m(T1, T 2) − 1, two composition levels give an O∗(1 .7743 k∗

)-time algorithm. More generally, for every fixed ε > 0, a suitable fixed number of compositions gives O∗(( φ + ε)k∗

) time, where φ = (1 + √5) /2. The polynomial degree and hidden constant may depend on ε. The compatibility of the reduction rules with our unaugmented root convention also allows one-time kernelization to control the polynomial dependence on the input size. The main contribution is a constructive way to use structure defined by an unknown optimum. The critical-edge representation connects the optimum gap to locations in the input tree, making it possible to balance the unresolved disagreement. Target preservation and marker reconstruction then allow the resulting sides to be solved independently without losing optimality. A shared deletion count connects the cost of enforcing separation with the work left for the side solver. Together, these properties give an explicit transformation of exponential bases: a compatible tree–forest solver with base B > φ yields an algorithm with base √φB . Since the resulting algorithm provides the same input and output guarantees, this improvement can be applied repeatedly. The framework therefore provides a reusable method for improving MAF algorithms while keeping the side solver separate from the decomposition and reconstruction procedures. An important next question is what determines the limiting base φ. In the present analysis, it comes from the weighted cost of binary separation. Understanding whether this cost is inherent to the separation requirements, or can be reduced by a different procedure, would clarify the scope for further exponential improvements. More broadly, the trade-off between separation cost and side-gap balance deserves a systematic analysis. Such an analysis could also identify decompositions that achieve a given exponential bound with fewer composition levels and a smaller polynomial factor. Another direction is to identify sufficient conditions for similar solver improvements in other agreement-forest models. The central questions are whether the optimum gap admits a small structural witness that can be balanced, and whether the resulting boundaries can be recorded and reconstructed with controlled changes in forest order. Establishing these properties for unrooted, multifurcating, or multiple-tree inputs would determine how far the composition principle developed here can be extended.
