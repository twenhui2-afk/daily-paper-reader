## Abstract
We develop a balanced divide-and-conquer framework for the maximum agreement forest problem on rooted binary phylogenetic tree--forest instances. The goal is a common subforest with the fewest components; budget $k$ bounds the increase relative to the input forest. We balance edges associated with an unknown optimum to obtain three subproblems with smaller budgets. Branching separates the inputs, while temporary marker leaves allow a global optimum to be recovered from independently computed optimal solutions. For any fixed $B>\varphi=(1+\sqrt5)/2$, the framework converts a tree--forest solver running in $O^*(B^k)$ time into one running in $O^*((\sqrt{\varphi B})^k)$ time. Starting from an $O^*(2.3391^k)$-time solver, two applications yield an $O^*(1.7743^{k^*})$-time fixed-parameter algorithm for two trees, where $k^*$ is the number of components in a maximum agreement forest minus one. For every fixed $\varepsilon>0$, a fixed number of applications yields $O^*((\varphi+\varepsilon)^{k^*})$ time. Here $O^*$ suppresses polynomial factors, whose degree and constants may depend on $\varepsilon$.
