## Abstract
Long-lived secure channels for embedded and cyber-physical systems (CPSs) must resist quantum attacks and failures in endpoint randomness. While several post-quantum key exchange protocols exist, their security assumes reliable randomness at the endpoint, but this assumption is not always true in embedded devices. In this paper, we introduce the Entropy Attack Suite (EAS) to evaluate secure channels facing endpoint randomness failures, such as low-entropy boot and Random Number Generation (RNG) path subversion. As a case study, we design and implement APQKE-DR, a post-quantum secure channel. Its handshake uses ML-KEM [1] and ML-DSA [2], producing a root key for an X25519 Double Ratchet. We assess the performance of APQKE-DR and security for smart grid communication, and integrate it beneath ANSI C12.22 and DNP3 without altering payload formats.   On a Raspberry Pi Compute Module 5, the APQKE handshake exchanges 9,610 bytes with median latencies of 1.99 ms (node) and 0.82 ms (server). The ratcheted channel adds 31 bytes per message. With fresh randomness and ideal cryptographic primitives, ProVerif verifies the modeled secrecy and authentication properties. If randomness fails, EAS can recover the RNG stream and root key from public transcripts. Under RNG-path subversion, a weak generator exposes the root key across sessions. If subversion also affects X25519 keys, attackers may access ratchet keys and plaintexts. TPM seeding prevents early-boot attacks but not later subversion, while measured boot can block modified firmware. Secure deployment thus requires integrity along the entire entropy path, not just strong cryptographic primitives.
